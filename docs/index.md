## 作るもの

タスク管理ツールの一覧画面と登録フォームの2画面です。

![タスク一覧画面。左にサイドバー、右に統計カード3枚、フィルタチップ、優先度タグ付きのタスクカードが並ぶ](/lessons/4-4/task-list-final.png)

![タスク登録フォーム画面。ラベル付きの入力欄が5つ並び、右下にキャンセルとタスクを登録のボタン](/lessons/5-2/task-form-components.png)

要素を減らした見本ではなく、実務並みの情報量で組みます。1〜3章はプロフィールカードで操作に慣れ、4章から本番の2画面に取りかかります。

## 準備と所要時間

1〜5章はFigmaアカウント（無料）とブラウザだけで始められます。6章からClaude Code CLIとFigma MCPサーバーが要ります（セットアップ手順は6-1に書いています）。

実際にFigmaを操作する時間を含めて、全体で約11時間です。
