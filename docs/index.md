## この研修でやること

シンプルなタスク管理ツールを題材に、一覧画面と登録フォームの2画面をFigmaでデザインします。仕上げに、そのデザインをFigma MCPとClaude Codeでコードに変換します。

1レッスンは15分で、読むだけでなく実際にFigmaを操作しながら進めます。各レッスンの最後にゴール確認があるので、できたかどうかを自分で確かめられます。

## カリキュラム

全7章・18レッスンで構成しています。

### Day1

| 章 | 内容 |
| --- | --- |
| 1章 Figmaを開いてみる | 画面構成を知り、フレームの作成やズームなどの基本操作に慣れる |
| 2章 基本要素を作る | シェイプ・テキストの配置、Auto Layout、整列とリサイズ挙動をサンプル題材で練習する |
| 3章 デザインの基礎知識 | カラーとタイポグラフィのルール化、コンポーネントとバリアント、レイヤー命名を学ぶ |
| 4章 実践: タスク一覧画面を作る | 学んだ手順を使って、タスク一覧画面をゼロからデザインする |

### Day2

| 章 | 内容 |
| --- | --- |
| 5章 実践: タスク登録フォームを作る | 入力欄とボタンを備えたフォームをデザインし、一覧画面とトンマナを揃える |
| 6章 Figma MCP + Claude Codeでコード化 | MCPサーバーをセットアップし、2画面をコード生成する |
| 7章 まとめ・ふりかえり | 2日間で学んだことをふりかえる |

## 進め方

- 自習形式です。上から順にレッスンを進めてください
- 1〜3章は練習用のサンプル題材、4章からは本番のタスク管理ツールを作ります
- 練習で身につけた手順を、本番では自分の手で一から適用します
