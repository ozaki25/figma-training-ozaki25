## 作るもの

タスク管理ツールの一覧画面と登録フォームの2画面です。デザインができたら、Figma MCPとClaude Codeを組み合わせて、そのデザインからコードを生成するところまでやります。

![完成する2画面](/lessons/5-3/two-screens-side-by-side.png)

デザインは実務でよくある密度で、余白と装飾に逃げないUIを目指しています。1〜3章はプロフィールカードで手を動かして操作に慣れ、4章から本番の2画面に取りかかります。

## 準備と所要時間

1〜5章はFigmaアカウント（無料）とブラウザさえあれば始められます。6章に入るタイミングでClaude Code CLIとFigma MCPサーバーを追加で用意します（セットアップ手順は6-1で説明します）。

1レッスンは15分・読むだけの時間で、全18レッスンで約4.5時間です。実際にはFigmaで手を動かす時間が同じくらいかかるので、まとまった時間が取れるなら丸1日×2日、業務の隙間で進めるなら2週間ほどを見込んでください。

## 進め方

本サイトをブラウザで開き、隣にFigmaのウィンドウを並べて、上から順に進めるのが基本の使い方です。1〜3章は練習用のサンプル題材、4章から本番のタスク管理ツールに取りかかります。練習で身につけた手順を、本番では自分の手で一から適用します。

各レッスンの最後にゴール確認のチェックリストがあり、次に進む前に自分の状態を残せます。章の最終レッスンには「この章はここまで」という短い節を置いてあるので、章の切り替わりで一息つけます。
