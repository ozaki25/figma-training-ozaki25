## この研修でやること

シンプルなタスク管理ツールを題材に、一覧画面と登録フォームの2画面をFigmaでデザインします。仕上げに、そのデザインをFigma MCPとClaude Codeでコードに変換します。

1レッスンは15分で、読むだけでなく実際にFigmaを操作しながら進めます。各レッスンの最後にゴール確認があるので、できたかどうかを自分で確かめられます。

## 学習時間の目安

下記はレッスン本文を読み進める時間の目安です。実際にはFigmaで手を動かす時間が別途必要になるため、実所要時間は目安の約2倍を想定してください（まとまった時間が取れるなら丸1日×2日、業務の隙間で進めるなら2週間ほど）。

| まとまり | 内訳 | 読む時間の目安 |
| --- | --- | --- |
| 全体 | 全18レッスン × 15分 | 約4.5時間 |
| Day1 | 1〜4章の11レッスン | 約2.5時間 |
| Day2 | 5〜7章の7レッスン | 約2時間 |

## 準備するもの

- Figmaアカウント（無料。[figma.com](https://www.figma.com/) から作成できます）
- ブラウザ（Chrome・Edge・Safariの最新版）またはFigmaデスクトップアプリ

6章に入るタイミングで、以下も追加で用意します。

- Claude Code CLI（インストール済みであること）
- Figma MCPサーバー（セットアップ手順は6-1で説明します）

1〜5章はFigmaだけで完結します。Claude Code関連の準備は6章の直前で整えても間に合います。

## 進め方

- 上から順にレッスンを進めてください
- 1〜3章は練習用のサンプル題材、4章からは本番のタスク管理ツールを作ります
- 練習で身につけた手順を、本番では自分の手で一から適用します
- 本サイトをブラウザで開き、その隣にFigmaのウィンドウを並べて進めると効率的です
- 各レッスン末尾のゴール確認で、次に進む前に自分の状態をチェックできます
- 章の最終レッスンには「この章はここまで」節があり、次章への切り替わりを確認できます
