# ショートカット早見表

このハンズオンで使うショートカットの一覧です。作業中に思い出せなくなったら、このページを開いたままFigmaと並べて使ってください。

単独のアルファベットキーは小文字1つで押します（Shiftは不要）。

## ツールの切り替え

| 操作 | Mac | Windows |
| --- | --- | --- |
| フレームツール | `f` | `f` |
| 四角形ツール | `r` | `r` |
| 楕円ツール | `o` | `o` |
| テキストツール | `t` | `t` |

図形を描くとき `Shift` を押しながらドラッグすると、正方形・正円になります。

## キャンバスの移動・表示

| 操作 | Mac | Windows |
| --- | --- | --- |
| パン（表示位置の移動） | `Space` + ドラッグ | `Space` + ドラッグ |
| ズーム | `Cmd` + スクロール | `Ctrl` + スクロール |
| 全体を表示 | `Shift + 1` | `Shift + 1` |
| 選択中の要素にズーム | `Shift + 2` | `Shift + 2` |
| 100%表示に戻す | `Shift + 0` | `Shift + 0` |

## 選択・編集

| 操作 | Mac | Windows |
| --- | --- | --- |
| 複数選択 | `Shift` + クリック | `Shift` + クリック |
| コピー | `Cmd + C` | `Ctrl + C` |
| 複製 | `Cmd + D` | `Ctrl + D` |
| 削除 | `Delete` | `Delete` |
| 名前を変更 | `Cmd + R` | `Ctrl + R` |
| 選択解除・入力終了 | `Esc` | `Esc` |
| 前面へ移動 | `Cmd + ]` | `Ctrl + ]` |
| 背面へ移動 | `Cmd + [` | `Ctrl + [` |

## オートレイアウト・コンポーネント

| 操作 | Mac | Windows |
| --- | --- | --- |
| オートレイアウトを追加 | `Shift + A` | `Shift + A` |
| オートレイアウトを削除 | `Shift + Option + A` | `Shift + Alt + A` |
| コンポーネントを作成 | `Cmd + Option + K` | `Ctrl + Alt + K` |
