# 2-3 整列とリサイズ挙動（Hug/Fill）を理解する

Auto Layoutを付けたプロフィールカード（正円と縦並びテキストの横並び、padding 24、白背景・角丸16）を使って、要素のサイズがどう決まるかを整えます。ここを押さえると、テキストが長くなっても崩れないカードになります。

## リサイズ挙動は3種類

Auto Layoutの世界では、要素の幅と高さは「数値」ではなく「振る舞い」で決めます。設定は幅・高さそれぞれに3種類です。

| 設定 | 意味 | CSSでいうと |
| --- | --- | --- |
| Hug contents | 中身に合わせて縮む | `width: fit-content` |
| Fixed | 指定した数値で固定 | `width: 320px` |
| Fill container | 親いっぱいに広がる | `flex: 1` |

Hugは「中身が決める」、Fixedは「自分が決める」、Fillは「親が決める」と考えると区別しやすいです。

## どこで設定するか

要素を選択すると、右サイドバーに W（幅）と H（高さ）の入力欄があります。この入力欄のドロップダウンを開くと、Fixed / Hug contents / Fill container から選べます。項目にカーソルを乗せると、選んだらどうなるかがキャンバス上にガイド線で表示されます。

ただし、3つ全部がいつでも選べるわけではありません。

- **Hug contents** が選べるのは、Auto Layoutフレームとテキストだけ。中身がないと「中身に合わせる」ができないからです
- **Fill container** が選べるのは、**親がAuto Layoutのときだけ**。CSSの `flex: 1` が flexコンテナの子でしか効かないのと同じ理屈です

Auto Layoutを付けた直後のフレームは、幅も高さもHugになっています。2-2でテキストを1行足すとカードが自動で広がったのは、この設定のおかげです。

## 整列は「余った空間のどこに置くか」

2-2で触れた9マスの整列ボックスは、フレーム内の要素をどこに寄せるかの設定です。カードの幅を固定して中身より広くすると、余った空間ができます。その余りに対して左に寄せるか、中央に置くか、右に寄せるかを9マスで選びます。

つまり整列が効くのは、フレームが中身より大きいときだけです。幅も高さもHugだと余りがないので、どこをクリックしても見た目は変わりません。子要素をFillにした場合も、その方向の余りがなくなるので整列の出番はなくなります。

## 演習: カードを崩れないようにする

2-2で作ったカードで試します。手元にない場合は、正円1つとテキスト2つ（名前・肩書き）をAuto Layoutで横並びにし、パディング24・白背景・角丸16のカードを作ってから始めてください。

### 1. カードの幅を固定する

1. カードのフレームを選択する
2. W のドロップダウンを Fixed にして、320 と入力する
3. H は Hug contents のままにしておく

幅を固定すると右側に余白ができます。整列ボックスをいくつかクリックして、中身の寄り方が変わるのを見てから、左中央（上下中央・左寄せ）に戻してください。

### 2. 名前テキストをFillにする

1. 名前のテキストを選択する
2. W のドロップダウンを Fill container にする
3. 肩書きのテキストも同じように Fill container にする

テキストの幅が、カードの余白を埋めるところまで広がりました。まだ見た目はほとんど変わりませんが、次の手順で差が出ます。

### 3. 長い名前で折り返しを確認する

1. 名前のテキストをダブルクリックして、長い名前に書き換える（例: 山田タロウ左衛門之介）
2. さらに長くして、1行に収まらない長さにする

Fillにしたテキストは幅が親で決まっているので、収まらない分は自動で折り返されます。もしFixedのままだったら、テキストはカードからはみ出していたはずです。

### 4. 高さが自動で伸びるのを確認する

折り返して名前が2行になると、カード全体の高さも伸びています。カードの H が Hug contents なので、中身の高さに追従するからです。そして正円は W・H とも Fixed のままなので、80×80のまま変わりません。

「外枠はFixedで固定、伸縮してほしいテキストはFill、高さはHugで追従」。この組み合わせが、中身が変わっても崩れないカードの基本形です。
