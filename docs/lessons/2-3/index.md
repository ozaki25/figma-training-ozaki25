# 2-3 整列とリサイズ挙動（内包/拡大/固定）を理解する

オートレイアウトを付けたプロフィールカード（正円と縦並びテキストの横並び、パディング 24、白背景・角丸16）を使って、要素のサイズがどう決まるかを整えます。ここを押さえると、テキストが長くなっても崩れないカードになります。

## リサイズ挙動の3種類

オートレイアウトの中では、要素の幅と高さは「数値」ではなく「振る舞い」で決めます。設定は幅・高さそれぞれに3種類です。

| 設定（W/Hのドロップダウン） | 意味 | CSSでいうと |
| --- | --- | --- |
| コンテンツを内包 | 中身に合わせて縮む | `width: fit-content` |
| 幅（高さ）を固定 | 指定した数値で固定 | `width: 320px` |
| コンテナに合わせて拡大 | 親いっぱいに広がる | `flex: 1` |

内包は「中身が決める」、固定は「自分が決める」、拡大は「親が決める」と考えると区別しやすいです。本文ではこの3つを**内包・固定・拡大**と略します。英語表示のFigmaや海外の記事では順に Hug、Fixed、Fill と呼ばれるので、対応だけ頭の隅に置いておいてください。

## どこで設定するか

要素を選択すると、右サイドバーに W（幅）と H（高さ）の入力欄があります。この入力欄のドロップダウンを開くと、「幅を固定」「コンテンツを内包」「コンテナに合わせて拡大」から選べます。項目にカーソルを乗せると、選んだらどうなるかがキャンバス上にガイド線で表示されます。

ただし、3つ全部がいつでも選べるわけではありません。

- **コンテンツを内包**が選べるのは、オートレイアウトフレームとテキストだけ。中身がないと「中身に合わせる」ができないからです
- **コンテナに合わせて拡大**が選べるのは、**親がオートレイアウトのときだけ**。「親の空きに合わせて広がる」設定なので、親が並べ方を管理していないと広げようがないからです

オートレイアウトを付けた直後のフレームは、幅も高さも内包になっています。2-2でテキストを1行足すとカードが自動で広がったのは、この設定のおかげです。

## 整列が効く条件

2-2で触れた9マスの整列ボックスは、フレーム内の要素をどこに寄せるかの設定です。カードの幅を固定して中身より広くすると、余った空間ができます。その余りに対して左に寄せるか、中央に置くか、右に寄せるかを9マスで選びます。

つまり整列が効くのは、フレームが中身より大きいときだけです。幅も高さも内包だと余りがないので、どこをクリックしても見た目は変わりません。子要素を拡大にした場合も、その方向の余りがなくなるので整列の出番はなくなります。

## 演習: カードを崩れないようにする

2-2で作ったカードで試します。

### 1. カードの幅を固定する

1. カードのフレームを選択する
2. W のドロップダウンを「幅を固定」にして、320 と入力する
3. H は「コンテンツを内包」のままにしておく

幅を固定すると右側に余白ができます。整列ボックスをいくつかクリックして、中身の寄り方が変わるのを見てから、左中央（上下中央・左寄せ）に戻してください。

### 2. テキストの縦並びグループごと拡大にする

1. 名前と肩書きを包んでいる縦並びグループ（2-2の演習1で作ったフレーム）を選択し、W のドロップダウンを「コンテナに合わせて拡大」にする
2. 中の名前のテキストを選択し、同じように W を「コンテナに合わせて拡大」にする
3. 肩書きのテキストも同じようにする

拡大は「親から幅をもらう」設定なので、外側から順に拡大にしていきます。途中のグループが内包のままだと連鎖がそこで切れて、テキストは狭い幅のままになります。

これで、テキストの幅がカードの余白を埋めるところまで広がりました。見た目はほとんど変わりませんが、次の手順で差が出ます。

### 3. 長い名前で折り返しを確認する

1. 名前のテキストをダブルクリックして、`山田タロウ左衛門之介三郎` に書き換える

拡大にしたテキストは幅が親で決まっているので、収まらない分は自動で折り返されます。名前が2行になり、カードの幅は320のままです。もし固定のままだったら、テキストはカードからはみ出していたはずです。

![長い名前を入れたプロフィールカード。カードの幅は320のまま、名前のテキストが2行に折り返している](/lessons/2-3/resizing-hug-fixed-fill.png)

### 4. 高さが内包で伸びるのを確認する

名前が2行になっても、カードの高さは変わっていません。内包は「一番高い中身に合わせる」設定で、いまは正円のほうがテキストの縦積みより高いからです。テキストの側が正円より高くなるまで、名前をさらに長くしてみます。

1. 名前を `あ` の連打などで、どんどん長くしていく
2. 行数が増えてテキストの縦積みが正円を追い越したところで、カードの高さが伸び始めるのを確認する
3. 名前を元の名前に戻す

正円は W・H とも固定なので、名前が何行になっても80×80のまま変わりません。伸びるのはカードの高さだけです。

幅は固定だから広がらない、その中で拡大のテキストが折り返す、あふれたぶんは内包の高さが受け止める。この3つが噛み合っているので、中身が増えてもカードは崩れません。
