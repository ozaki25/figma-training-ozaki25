# 4-3 配色・タイポグラフィを仕上げて完成させる

4-2でタスクカードを3枚並べたところまで進んでいるはずです。ここでは色とテキストのスタイルを登録して各要素に適用し、統計行・フィルタ・セクション分け・サイドバーの装飾・完了状態まで一気に仕上げます。これで4章のタスク一覧画面が完成します。

このレッスンは4章の集大成なので手順が多めです。スタイルの登録と適用のやり方は3-1と同じで、要素を選んで「塗り」や「タイポグラフィ」の4点アイコンから操作します。

## 使うスタイル

3-1で予告したとおり、実践では色が6〜8個に増えることがあります。この画面では罫線用の `border` とサイドバーのアクティブ背景 `bg-active` を追加して**色スタイル7つ**、テキストスタイル5つを使います。

色スタイルは7つです。

| スタイル名 | 用途 | 値 |
| --- | --- | --- |
| `brand` | チェック済みの印・アクセント | 紫 `#7C3AED` |
| `text/main` | タスク名・見出しの文字 | 濃いグレー `#2A2A31` |
| `text/sub` | 説明・期限などの補助テキスト | 薄いグレー `#6E6E76` |
| `bg` | contentエリアの背景 | 薄グレー `#F5F5F5` |
| `surface` | ヘッダー・カード・サイドバーの地色 | 白 `#FFFFFF` |
| `border` | 罫線・枠線 | `#E5E5EA` |
| `bg-active` | サイドバーのアクティブ項目背景 | `#F3EEFF` |

テキストスタイルは5つです。

| スタイル名 | 用途 | 指定 |
| --- | --- | --- |
| `app-title` | ヘッダーのアプリ名 | 18 SemiBold |
| `page-title` | 「今日のタスク」の見出し | 24 Bold |
| `card-title` | カードのタスク名 | 14 Medium |
| `card-desc` | 説明・チップ・統計ラベルなどの小さい文字 | 12 Regular |
| `card-due` | カードの期限 | 12 Regular |

`card-desc` と `card-due` は同じ指定ですが、意味が違うので別名で残します。

色7つのうち `surface`・`text/main`・`text/sub` は3-1で登録済みです。`surface` はそのまま使い回し、`text/main` と `text/sub` は定義を本番の値に更新します。新しく登録するのは残りの色4つとテキスト5つです。

## 仕上げの順序

1. スタイルをそろえる（3-1ぶんの更新と、残りの新規登録）
2. 既存の要素にスタイルを適用する
3. content上部に `stat-row`（統計カード3枚）を作る
4. その下に `filter-bar`（フィルタチップ4個）を作る
5. TaskCardをセクション（Today / This Week / Later）に分けて8枚にする
6. サイドバーを仕上げる（ブランド・nav-item・ユーザーブロック）
7. 完了タスクを1枚、色と装飾で表現する

## 演習

### 1. スタイルをそろえる

1. 3-1で登録済みの `text/main` と `text/sub` を本番の値に更新する。何も選択していない状態で右サイドバーの「スタイル」セクションを開き、調整アイコンから値を表のとおり（`#2A2A31` / `#6E6E76`）に変える。3-1で練習した「定義を1か所変えれば適用先すべてに反映」を、本番でそのまま使う場面です（プロフィールカードの文字色も一緒に変わりますが、練習用サンプルなのでそのままで構いません）
2. `surface` は3-1で登録済みのものをそのまま使う
3. `bg` は `content` を選んで、「塗り」の4点アイコンから新規登録すると早い
4. `brand`・`border`・`bg-active` はまだ使っている要素がないので、キャンバスの空いた場所に `r` で小さな四角形を3つ描いて登録に使う。1つ目の塗りを `#7C3AED` にして4点アイコンから `brand` を登録、2つ目を `#E5E5EA` にして `border`、3つ目を `#F3EEFF` にして `bg-active` を登録する。3つ登録できたら四角形は消してよい。スタイルは残る
5. テキストスタイル5つは、表の用途に当たるテキスト（`app-title`・`page-title`・`task-title`・`task-desc`・`task-due`）をそれぞれ選んで、「タイポグラフィ」の4点アイコンから登録する

### 2. 既存要素にスタイルを適用する

当て方はどれも同じです。要素を選んで「塗り」や「タイポグラフィ」の4点アイコンを開き、一覧から登録済みのスタイルを選びます。

1. `header` の背景を `surface`、`app-title` のテキストに `app-title` スタイルと `text/main` を当てる
2. `content` の背景を `bg`、`page-title` に `page-title` と `text/main` を当てる
3. `TaskCard` の**メインコンポーネント**を編集し、地色に `surface`、カード全体に枠線1px `border` を追加する
4. 同じメインコンポーネントの中で、`task-title` に `card-title` と `text/main` を当てる
5. `task-desc` に `card-desc` と `text/sub`、`task-due` に `card-due` と `text/sub` を当てる
6. `CategoryBadge` は背景に `bg`、文字に `card-desc` と `text/sub` を当てる
7. メインコンポーネントに当てれば、画面上の全カードのインスタンスに一斉に反映される

### 3. stat-rowを作る

contentの上（`page-title` の下）に、統計カードを3枚横に並べます。

1. content内に空の横オートレイアウトフレームを作り（4-1と同じく `f` で描いて `Shift + A`）、名前を `stat-row`、間隔 16、幅は**拡大**、高さは内包、パディング 0 にする
2. `stat-row` の中に、統計カードを1枚だけ組む: 空の縦オートレイアウトフレームを作り、間隔 8、パディング 20、角丸12、背景 `surface`、枠線1px `border`、幅は拡大、高さは内包
3. `t` でテキストを3つ作って中に入れる。上からラベル `今日のタスク`（`card-desc` + `text/sub`）、数値 `8`（28 Bold + `text/main`）、補足 `未完了`（`card-desc` + `text/sub`）
4. 名前を `StatCard` にする（コンポーネント化はしなくてよい）
5. `Cmd + D` で3枚に複製し、中身を「完了 / 12 / 今週」「遅延 / 2 / 要対応」に書き換える

3枚が幅の拡大でcontentの横いっぱいに広がります。

### 4. filter-barを作る

`stat-row` の下に、フィルタ用のチップを4個並べます。

1. content内に空の横オートレイアウトフレームを作り、名前を `filter-bar`、間隔 8、幅は拡大、高さは内包、パディング 0
2. `t` でテキスト `すべて`（`card-desc`）を中に作り、`Shift + A` で包む。高さ32、パディング 4/12、角丸16、幅は内包、背景 `brand`、文字色は白に上書き
3. 名前を `chip-active` にする
4. `Cmd + D` で3個複製し、それぞれ「未完了 / 完了 / 優先高」に書き換える。3個は背景 `surface`、枠線1px `border`、文字 `text/main` に変える。名前は `chip` でよい

### 5. セクション分けとTaskCardを8枚に増やす

いまcontentにTaskCardのインスタンスが3枚あります。これをセクション分けし、5枚追加します。

1. content内に空の縦オートレイアウトフレームを3つ作り、それぞれ名前を `section-today`・`section-week`・`section-later`、間隔 12、幅は拡大、高さは内包、パディング 0
2. 各セクションの先頭に `t` でラベル用のテキストを入れる: `今日`・`今週`・`後で`（14 SemiBold、`text/sub`）
3. 既存のTaskCard 3枚を `section-today` の中へ移動する
4. `section-week` と `section-later` にもTaskCardインスタンスをアセットパネルから追加する。`section-week` は3枚、`section-later` は2枚
5. 上のダミータスク表のとおりに各カードのタイトル・説明・カテゴリ・担当・期限・PriorityTagの色を上書きする

これでTaskCardが合計8枚並びます。

### 6. サイドバーを仕上げる

4-1で置いたプレースホルダーのnav-itemを、装飾込みに仕上げます。

1. `sidebar` の背景に `surface` を当て、`app-brand` テキストに `app-title` スタイルと `text/main` を当てる
2. `r` で 24×24 の正方形（紫 `#7C3AED`、角丸6）を作ってアイコン代わりにする。`app-brand` のテキストと2つ選択して `Shift + A` で横に並べ、間隔 8 にする
3. nav-itemを1個、テキスト付きに作り直す。空の横オートレイアウトフレーム（高さ40、パディング 4/12、角丸8、間隔 12）を作り、20×20の四角形（薄グレー `#E5E5EA`、アイコン代わり）と `t` でテキスト `受信箱`（14、`text/main`）を入れる
4. 作ったものを `sidebar` の中の元の四角形の位置へドラッグで入れ、幅を**拡大**にする（sidebarの中に入れてからでないと拡大は選べない）。`Cmd + D` で5個に増やし、ラベルを `受信箱`・`今日`・`今週`・`完了`・`アーカイブ` に書き換える。元の四角形5個は消す
5. `今日` の nav-item だけ背景を `bg-active` に上書きする
6. `今日` の nav-item にバッジを付ける。`t` で白文字テキスト `8`（12px）を作って `Shift + A` で包み、パディング 2/6、角丸8、塗り `brand` にして、`今日` の nav-item の中の右端に入れる。ラベルのテキストの幅を**拡大**にすると、バッジが右端に押し出される
7. ユーザーブロックを作る。`t` で `YO`（14）と `Designer`（12、`text/sub`）の2つのテキストを作り、選択して `Shift + A` で縦に積む。その縦積みと `o` で描いた 24×24 の正円（薄グレー `#E5E5EA`）を選択して、もう一度 `Shift + A` で横に並べる（パディング 8、間隔 8）。名前を `user-block` にして、サイドバーの一番下に入れ、幅を**拡大**にする
8. `nav-item` の5個と `user-block` の間に、空の縦オートレイアウトフレームを1つ作り、名前を `spacer`、高さを**拡大**にする。この `spacer` が余った縦スペースを吸収し、`user-block` がサイドバーの下端へ押し出される（オートレイアウトでは特定の1か所だけ間隔を空けられないので、高さを拡大にしたスペーサーで間を開ける）

### 7. 完了タスクを1件仕上げる

1. 好きなTaskCardのインスタンスを1つ選ぶ
2. `checkbox` の塗りを `brand` に上書きする
3. `task-title` の色を `text/sub` に上書きし、「タイポグラフィ」の装飾で打ち消し線を付ける

完了と未完了はバリアントにしてもよいですが、いまは色と装飾の上書きだけで十分です。バリアントは5-2のButtonで扱います。
