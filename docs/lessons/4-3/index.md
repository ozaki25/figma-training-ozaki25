# 4-3 配色・タイポグラフィを仕上げて完成させる

4-2でタスクカードを並べたタスク一覧画面を、色と文字のスタイルを当てて仕上げます。ここまでは黒い文字と白いカードだけの素っ気ない見た目でしたが、色スタイルとテキストスタイルを適用すると、画面全体に一貫性が出ます。これで4章のタスク一覧画面が完成します。

このレッスンも操作は逐一書きません。仕様を示すので、スタイルの登録と適用は既習の手順（Fill・Typographyの4点アイコンから登録）でやってください。

## 使うスタイル

先に、この画面で使う色とテキストのスタイルを決めます。3-1でやったように、数を絞るのがコツです。

色スタイルは5つです。

| スタイル名 | 用途 | 値の目安 |
| --- | --- | --- |
| `brand` | チェック済みの印、アクセント | 紫 `#7C3AED` |
| `text/main` | タスク名・見出しの文字 | 濃いグレー `#2A2A31` |
| `text/sub` | 期限などの補助テキスト | 薄いグレー `#8A8A93` |
| `bg` | contentエリアの背景 | 薄グレー `#F5F5F5` |
| `surface` | ヘッダーとカードの地色 | 白 `#FFFFFF` |

テキストスタイルは4つです。

| スタイル名 | 用途 | 指定 |
| --- | --- | --- |
| `app-title` | ヘッダーのアプリ名 | 18 SemiBold |
| `page-title` | 「今日のタスク」の見出し | 24 Bold |
| `card-title` | カードのタスク名 | 14 Medium |
| `card-due` | カードの期限 | 12 Regular |

## 仕上げの順序

1. 色スタイルを5つ登録する
2. テキストスタイルを4つ登録する
3. 画面の各要素にスタイルを適用する
4. 完了タスクの見せ方を整える
5. 余白と角丸を微調整する

色やサイズは4-1・4-2で作ったときに近い値を使っているはずなので、いまの値を確認しながら登録すれば、見た目を大きく変えずにスタイル化できます。

## 演習: スタイルを当てて仕上げる

### 1. 色スタイルとテキストスタイルを登録する

1. まだ登録していなければ、上の表の色5つ・テキスト4つをスタイルとして登録する。登録は要素を選び、Fill または Typography の4点アイコンから行う
2. `brand` は `checkbox` を選んで登録するのが早い。`bg` は `content`、`surface` は `header` かカードから登録する

### 2. 各要素にスタイルを適用する

1. `header` の背景を `surface`、`app-title` のテキストに `app-title` スタイルと `text/main` を当てる
2. `content` の背景を `bg`、`page-title` に `page-title` スタイルと `text/main` を当てる
3. `TaskCard` の**メインコンポーネント**を編集する。地色を `surface`、`task-title` に `card-title` と `text/main`、`task-due` に `card-due` と `text/sub` を当てる
4. メインコンポーネントに当てれば、画面上の全カードのインスタンスに一斉に反映されます。カードの一括反映とスタイルの一括反映が同時に効きます

### 3. 完了タスクを表現する

1. 一覧のインスタンスを1枚選び、完了したタスクに見立てる
2. `checkbox` の塗りを `brand` に上書きする
3. `task-title` の色を `text/sub` に上書きし、打ち消し線（Typographyの装飾で strikethrough）を付ける

完了の状態はバリアントにしてもよいのですが、いまは色と装飾の上書きだけで十分伝わります。バリアントは登録フォームのボタンで改めて扱います。

### 4. 余白と角丸を整える

1. カードのpaddingやgap、角丸が揃っているか見直す
2. 画面を `Shift + 1` で全体表示にして、詰まりすぎ・空きすぎがないか眺める
3. 気になる箇所だけ数値を調整する

ここはスタイルではなく目で見て整える作業です。少し離れて画面全体のバランスを見るのがコツです。

## できたこと

ゼロから作り始めたタスク一覧画面が、これで完成しました。フレームで骨組みを作り、Auto Layoutで並べ、カードをコンポーネント化し、スタイルで色と文字をそろえる。1〜3章で練習した手順を、そのまま本番の画面に積み上げた結果です。次の章では、この画面と同じ部品づかいで、もう1つの画面である登録フォームを作ります。
