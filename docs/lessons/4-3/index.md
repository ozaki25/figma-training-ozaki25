# 4-3 タスクカードと優先度バリアント

4-2でトークンとスタイルがそろいました。ここからは、それを使ってこの画面の中心になるタスクカードを作ります。優先度・タスク名・説明・カテゴリ・担当者・期限が載ったカードを組み、コンポーネント化して3枚並べます。

## 完成イメージ

![タスク一覧画面のcontentにTaskCardのインスタンスが3枚縦に並ぶ。各カードは左からチェック用の正円、優先度タグ、タスク名と説明の縦2行、カテゴリバッジ、担当者アイコン、右端に期限](/lessons/4-3/task-list-cards.png)

作るのはTaskCardとPriorityTagの2つです。

```
TaskCard
├─ checkbox
├─ PriorityTag
├─ task-body
│  ├─ task-title
│  └─ task-desc
├─ category-badge
├─ assignee
└─ task-due
```

| 部品 | 役割 | 仕様 |
| --- | --- | --- |
| `TaskCard` | カード本体（コンポーネント） | 横オートレイアウト、間隔 `space/16`、パディング `space/16`、背景 `surface`、角丸 `radius/12`、上下中央揃え |
| `checkbox` | 完了チェック | 20×20の正円。塗り `surface`、枠線1px `border` |
| `PriorityTag` | 優先度タグ（別コンポーネント） | `priority=high/mid/low` の3バリアント |
| `task-body` | タイトルと説明の縦積み | 縦オートレイアウト、間隔 `space/4`、幅は拡大 |
| `task-title` | タスク名 | テキストスタイル `card-title`、色 `text/main` |
| `task-desc` | 説明 | テキストスタイル `caption`、色 `text/sub` |
| `category-badge` | カテゴリ | 左右パディング `space/8`、上下パディング `space/4`、角丸 `radius/4`、背景 `bg`、テキストスタイル `caption`、色 `text/sub` |
| `assignee` | 担当者 | 24×24、角丸 `radius/full`、背景 `placeholder`、テキストスタイル `caption`、色 `text/main` |
| `task-due` | 期限 | テキストスタイル `caption`、色 `text/sub` |

カード全体は横方向のオートレイアウトですが、真ん中の `task-body` だけは自分の中で縦方向のオートレイアウトを持ち、タイトルと説明を縦に積みます。2-2で作った入れ子と同じ構造で、向きだけが違います。

`task-body` の幅を拡大にしておくと、余った幅をここが全部引き受けるので、右側の3要素（カテゴリ・担当者・期限）は自然と右端に押し出されます。

## 優先度はバリアントにする

優先度タグは「High / Mid / Low」の3種類の決まった状態を持ちます。3-2で練習したとおり、こういう部品は状態ごとに色を上書きするのではなく、1つのコンポーネントのバリアントにします。カードに置いたあとは、ドロップダウンで切り替えるだけで色も文字も一緒に変わります。

## 演習

### 1. PriorityTagを作る

まずHigh状態を1つ作ります。

1. `task-list` フレームの外の空いた場所に、`t` を押してクリックし、テキスト `High`（テキストスタイル `caption`、色 `priority/high/text`）を作る
2. テキストを選択して `Shift + A` でオートレイアウトにする
   - 左右パディング `space/8`、上下パディング `space/4`
   - 角丸 `radius/4`、背景 `priority/high/bg`
   - 幅は**内包**
3. `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）でコンポーネント化する
4. 名前を `PriorityTag` にする

### 2. バリアントを3種類にする

1. `PriorityTag` を選択して、右サイドバー上部の「バリアントの追加」アイコンを2回クリックする。同じタグが3枚、紫の破線枠のコンポーネントセットに入る
2. 右サイドバーの「現在のバリアント」で、`プロパティ1` を `priority` に変える
3. 1枚目の値を `high`、2枚目を `mid`、3枚目を `low` にする。値を変えるときは、変えたいタグ自身をキャンバスで選び直してから書き換える（まとめては変えられない）
4. 2枚目（mid）を書き換える: テキストを `Mid` に、文字色を `priority/mid/text` に、背景を `priority/mid/bg` にする
5. 3枚目（low）も同じように、`Low`・`priority/low/text`・`priority/low/bg` にする

レイヤーパネルで `PriorityTag` の下に `high`・`mid`・`low` の3つが並んでいれば完成です（プロパティ名は表示されず、値だけが出ます）。

### 3. TaskCardを組む

部品は「カードの外で作って、できたらカードの中へドラッグで入れる」を繰り返します。

1. 完了チェックの丸を作る。PriorityTagを作ったのと同じ、`task-list` の外の空いた場所に `o` で 20×20 の正円を描き、塗り `surface`、枠線1px `border`、名前を `checkbox` にする
2. `checkbox` を選択して `Shift + A` で横のオートレイアウトにする。`checkbox` を囲む新しいフレームができるので、その名前を `TaskCard` にする
   - 間隔 `space/16`、パディング `space/16`、配置は上下中央
   - 背景 `surface`、角丸 `radius/12`
   - 幅は**固定600**、高さは**内包**
3. 優先度タグを入れる。アセットパネルから `PriorityTag` のインスタンスを、カードの中、`checkbox` の右へ入れる
4. タスク名と説明のブロックを入れる
   1. カードの外に、`t` を押してクリックし、テキスト `デザインレビューの準備`（テキストスタイル `card-title`、色 `text/main`）を作り、名前を `task-title` にする
   2. `t` を押してクリックし、テキスト `一覧画面のデザインを共有`（テキストスタイル `caption`、色 `text/sub`）を作り、名前を `task-desc` にする
   3. 2つを選択して `Shift + A` で縦のオートレイアウトにして、間隔 `space/4`、名前を `task-body` にする
   4. カードの中、PriorityTagの右へ入れる
5. カテゴリのバッジを入れる
   1. カードの外に、`t` を押してクリックし、テキスト `デザイン`（テキストスタイル `caption`、色 `text/sub`）を作り、`Shift + A` でオートレイアウトにして、名前を `category-badge` にする
      - 左右パディング `space/8`、上下パディング `space/4`
      - 角丸 `radius/4`、背景 `bg`
      - 幅は**内包**
   2. カードの中、`task-body` の右へ入れる
6. 担当者のアイコンを入れる。イニシャル入りの丸にしたいが、正円の図形の中にはテキストを入れられないので、角丸のフレームで円形を作る
   1. カードの外に、`t` を押してクリックし、イニシャルのテキスト `TY`（テキストスタイル `caption`、色 `text/main`）を作り、`Shift + A` でオートレイアウトにして、名前を `assignee` にする
      - パディング 0、配置は中央
      - 角丸 `radius/full`、背景 `placeholder`
      - 幅・高さを**固定24**にすると、円形のアイコンになる
   2. 中の `TY` の幅が固定になっていたら**内包**にする。固定のままだと丸の中でイニシャルの位置がずれる
   3. カードの中、`category-badge` の右へ入れる
7. 期限を入れる
   1. カードの外に、`t` を押してクリックし、テキスト `今日`（テキストスタイル `caption`、色 `text/sub`）を作り、名前を `task-due` にする
   2. カードの中の右端へ入れる
8. 並び順を確認する。左から `checkbox`・`PriorityTag`・`task-body`・`category-badge`・`assignee`・`task-due`。違っていたら、カードの中で要素をドラッグして入れ替える
9. `task-body` の幅を**拡大**にして、カテゴリ・担当者・期限が右端に寄るのを確認する

### 4. コンポーネント化する

1. `TaskCard` のフレームを選択して `Cmd + Option + K` でコンポーネント化する
2. レイヤーパネルのアイコンがひし形4つに変わったのを確認する

### 5. インスタンス3枚を並べて書き換える

1. `content` の中の `placeholder` をすべて選択して `Delete` で消す
2. 左サイドバーの**アセットパネル**から `TaskCard` を `content` の中へドラッグする
3. インスタンスの幅を**拡大**、高さを**内包**にする
4. `Cmd + D` で3枚にする

3枚を、次のダミータスクのとおりに書き換えます。全8件のうちこのレッスンで使うのは3件で、残りは4-4で並べます。

| 優先度 | タイトル | 説明 | カテゴリ | 担当 | 期限 |
| --- | --- | --- | --- | --- | --- |
| high | デザインレビューの準備 | 一覧画面のデザインを共有 | デザイン | TY | 今日 |
| mid | 会議資料の作成 | 定例向けサマリ | ドキュメント | HK | 今日 |
| high | APIエラーの調査 | 500系の再現手順 | 開発 | ST | 今日 |

担当の列は架空のメンバーのイニシャルです。`TY` は Taro Yamada の略で、本人は4-4で作るサイドバー下部のアカウント表示に登場します。

5. タイトル・説明・カテゴリ・担当のイニシャル・期限を書き換える。カードの中の要素は、ダブルクリックするたびに1階層ずつ中に入って選べる。テキストまでたどり着いたら、もう一度ダブルクリックすると編集できる
6. 2枚目のカードの `PriorityTag` インスタンスを選び、右サイドバーの `priority` ドロップダウンを `mid` に切り替える。文字も色も一緒に変わる

最後に、画面の外のTaskCardの原本でパディングや角丸を少し変えてみてください。画面の中の3枚すべてが一斉に変わり、書き換えたタイトルはそのまま残ります。確認できたら元に戻します。

## ゴール確認

- [ ] `TaskCard` をトークンとスタイルだけで組み、コンポーネント化できた
- [ ] インスタンス3枚を並べ、テキストの上書きと優先度の切り替えができた
