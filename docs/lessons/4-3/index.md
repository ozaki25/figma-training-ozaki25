# 4-3 配色・タイポグラフィを仕上げて完成させる

4-2でタスクカードを3枚並べたところまで進んでいるはずです。ここでは色とテキストのスタイルを登録して各要素に適用し、統計行・フィルタ・セクション分け・サイドバーの装飾・完了状態まで一気に仕上げます。これで4章のタスク一覧画面が完成します。

このレッスンは4章の集大成なので手順が多めです。スタイルの登録と適用のやり方は3-1と同じで、要素を選んで「塗り」や「タイポグラフィ」の4点アイコンから操作します。

## 完成イメージ

![仕上げ後のタスク一覧画面。左は装飾済みsidebar（ブランド、nav-item 5個、下端にユーザーブロック）、右はheaderとcontent。contentには見出し、stat-row 3枚、filter-bar 4個、3セクションに合計8枚のTaskCardが並ぶ。1枚は完了状態](/lessons/4-3/task-list-final.png)

## 仕上げの順序

1. スタイルをそろえる（3-1ぶんの更新と、残りの新規登録）
2. 既存の要素にスタイルを適用する
3. content上部に `stat-row`（統計カード3枚）を作る
4. その下に `filter-bar`（フィルタチップ4個）を作る
5. TaskCardをセクション（今日・今週・あとで）に分けて8枚にする
6. サイドバーを仕上げる（ブランド・nav-item・ユーザーブロック）
7. 完了タスクを1枚、色と装飾で表現する

## 演習

### 1. スタイルをそろえる

3-1で予告したとおり、実践では色が6〜8個に増えることがあります。この画面では罫線用の `border` とサイドバーのアクティブ背景 `bg-active` を追加して**色スタイル7つ**、テキストスタイル5つを使います。

色スタイルは7つです。

| スタイル名 | 用途 | 値 |
| --- | --- | --- |
| `brand` | チェック済みの印・アクセント | 紫 `#7C3AED` |
| `text/main` | タスク名・見出しの文字 | 濃いグレー `#2A2A31` |
| `text/sub` | 説明・期限などの補助テキスト | 薄いグレー `#6E6E76` |
| `bg` | contentエリアの背景 | 薄グレー `#F5F5F5` |
| `surface` | ヘッダー・カード・サイドバーの地色 | 白 `#FFFFFF` |
| `border` | 罫線・枠線 | `#E5E5EA` |
| `bg-active` | サイドバーのアクティブ項目背景 | `#F3EEFF` |

テキストスタイルは5つです。

| スタイル名 | 用途 | 指定 |
| --- | --- | --- |
| `app-title` | ヘッダーのアプリ名 | 18 SemiBold |
| `page-title` | 「今日のタスク」の見出し | 24 Bold |
| `card-title` | カードのタスク名 | 14 Medium |
| `card-desc` | 説明・チップ・統計ラベルなどの小さい文字 | 12 Regular |
| `card-due` | カードの期限 | 12 Regular |

`card-desc` と `card-due` は同じ指定ですが、意味が違うので別名で残します。

色7つのうち `surface`・`text/main`・`text/sub` は3-1で登録済みです。`surface` はそのまま使い回し、`text/main` と `text/sub` は定義を本番の値に更新します。新しく登録するのは残りの色4つとテキスト5つです。

1. 3-1で登録済みの `text/main` と `text/sub` を、本番の値に更新する
   1. 何も選択していない状態で、右サイドバーの「スタイル」セクションを開く
   2. `text/main` の調整アイコンを開き、値を `#2A2A31` に変える
   3. 同じように、`text/sub` の値を `#6E6E76` に変える
   4. 3-1で練習したとおり、定義を変えると適用先すべてに反映される。プロフィールカードの文字色も一緒に変わるが、練習用サンプルなのでそのままで構わない
2. `surface` は3-1で登録済みのものをそのまま使う
3. `bg` は `content` を選んで、「塗り」の4点アイコンから新規登録すると早い
4. `brand`・`border`・`bg-active` はまだ使っている要素がないので、要素を選ばずに直接登録する
   1. 何も選択していない状態で、右サイドバーの「スタイル」セクション右上の「+」から色スタイルの作成を選ぶ
   2. 名前を `brand`、色を `#7C3AED` にして作成する
   3. 同じように、`border` = `#E5E5EA`、`bg-active` = `#F3EEFF` を作成する
5. テキストスタイル5つは、表の用途に当たるテキスト（`app-title`・`page-title`・`task-title`・`task-desc`・`task-due`）をそれぞれ選んで、「タイポグラフィ」の4点アイコンから登録する

### 2. 既存要素にスタイルを適用する

当て方はどれも同じです。要素を選んで「塗り」や「タイポグラフィ」の4点アイコンを開き、一覧から登録済みのスタイルを選びます。

1. `header` の背景を `surface`、`app-title` のテキストに `app-title` スタイルと `text/main` を当てる
2. `content` の背景を `bg`、`page-title` に `page-title` と `text/main` を当てる
3. `TaskCard` の**メインコンポーネント**を編集し、地色に `surface`、カード全体に枠線1px `border` を追加する
4. 同じメインコンポーネントの中で、`task-title` に `card-title` と `text/main` を当てる
5. `task-desc` に `card-desc` と `text/sub`、`task-due` に `card-due` と `text/sub` を当てる
6. `CategoryBadge` は背景に `bg`、文字に `card-desc` と `text/sub` を当てる
7. メインコンポーネントに当てれば、画面上の全カードのインスタンスに一斉に反映される

### 3. stat-rowを作る

contentの上（`page-title` の下）に、統計カードを3枚横に並べます。

1. 統計カードを1枚組む
   1. キャンバスの空いた場所に `t` でテキストを3つ作る。ラベル `今日のタスク`（`card-desc` + `text/sub`）、数値 `8`（28 Bold + `text/main`）、補足 `未完了`（`card-desc` + `text/sub`）
   2. 3つを選択して `Shift + A` で縦に包み、次のとおりにする
      - 間隔 8、パディング 20、角丸12
      - 背景 `surface`、枠線1px `border`
      - 高さは内包
   3. 名前を `StatCard` にする（コンポーネント化はしなくてよい）
2. `StatCard` を選択して、もう一度 `Shift + A` で包み、名前を `stat-row` にする
3. `stat-row` を間隔 16、パディング 0 にして、`content` の中、`page-title` の下へ入れる
4. `stat-row` の幅を**拡大**、高さは内包にする
5. `StatCard` の幅を**拡大**にする
6. `StatCard` を `Cmd + D` で3枚にし、中身を「完了 / 12 / 今週」「遅延 / 2 / 要対応」に書き換える

3枚が幅の拡大でcontentの横いっぱいに広がります。

### 4. filter-barを作る

`stat-row` の下に、フィルタ用のチップを4個並べます。

1. チップを1個作る
   1. `t` でテキスト `すべて`（`card-desc`）を作り、`Shift + A` で包む
   2. 高さ32、パディング 4/12、角丸16、幅は内包にする
   3. 背景を `brand` に、文字色を白に上書きする
   4. 名前を `chip-active` にする
2. `chip-active` を選択して、もう一度 `Shift + A` で包み、名前を `filter-bar` にする
3. `filter-bar` を間隔 8、パディング 0 にして、`content` の中、`stat-row` の下へ入れる
4. `filter-bar` の幅は拡大、高さは内包にする
5. チップを `Cmd + D` で4個にし、増えた3個を「未完了 / 完了 / 優先高」に書き換える
6. その3個の背景を `surface`、枠線1px `border`、文字を `text/main` にする。名前は `chip` でよい

### 5. セクション分けとTaskCardを8枚に増やす

いまcontentにあるTaskCardのインスタンス3枚を、次の表のとおり「今日・今週・あとで」の3セクションに分け、5枚追加して合計8枚にします。

| セクション | 優先度 | タイトル | 説明 | カテゴリ | 担当 | 期限 |
| --- | --- | --- | --- | --- | --- | --- |
| 今日 | High | デザインレビューの準備 | 一覧画面のデザインを共有 | デザイン | TY | 今日 |
| 今日 | Mid | 会議資料の作成 | 定例向けサマリ | ドキュメント | HK | 今日 |
| 今日 | High | APIエラーの調査 | 500系の再現手順 | 開発 | ST | 今日 |
| 今週 | Mid | リリースノートの下書き | v2.3ぶん | ドキュメント | TY | 明日 |
| 今週 | Low | 依存ライブラリ更新 | patch差分のみ | 開発 | HK | 木曜 |
| 今週 | Mid | ユーザーヒアリング日程調整 | 3社 | 企画 | KM | 金曜 |
| あとで | Low | ドキュメントの誤字修正 | Issue #142 | ドキュメント | ST | 来週 |
| あとで | High | 本番デプロイ手順の見直し | 手順書v3化 | 運用 | TY | 来週 |

優先度の色は4-2と同じです。

| 値 | 背景 | 文字 |
| --- | --- | --- |
| High | `#FEE2E2` | `#B91C1C` |
| Mid | `#FEF3C7` | `#B45309` |
| Low | `#EEEEEE` | `#4B5563` |

1件（好きな行）を完了状態にしますが、それは演習7でやります。

1. `t` でセクション見出しのテキスト `今日`（14 SemiBold、`text/sub`）を作り、`Shift + A` で包む。このフレームが1つ目のセクションになる
2. 間隔 12、パディング 0 にして、名前を `section-today` にする
3. `content` の中、`filter-bar` の下へ入れ、幅は拡大、高さは内包にする
4. `Cmd + D` で3つにし、名前を `section-week`・`section-later` に、ラベルを `今週`・`あとで` に書き換える
5. 既存のTaskCard 3枚を `section-today` の中へ移動する
6. `section-week` と `section-later` にもTaskCardインスタンスをアセットパネルから追加する。`section-week` は3枚、`section-later` は2枚
7. 上のダミータスク表のとおりに各カードのタイトル・説明・カテゴリ・担当・期限・PriorityTagの色を上書きする

レイヤーパネルで、各セクションの中が「ラベル → TaskCard×枚数」の縦並びになっていれば正解です（例: `section-today` の中は `今日`・TaskCard・TaskCard・TaskCard）。画面全体ではTaskCardが合計8枚並びます。

### 6. サイドバーを仕上げる

4-1で置いたプレースホルダーのnav-itemを、装飾込みに仕上げます。

1. `sidebar` の背景に `surface` を当て、`app-brand` テキストに `app-title` スタイルと `text/main` を当てる
2. サイドバー上部をロゴの形にする
   1. アイコン代わりに、`r` で 24×24 の正方形（紫 `#7C3AED`、角丸6）を作る
   2. 正方形と `app-brand` のテキストを選択して `Shift + A` で横に包み、名前を `logo` にする
   3. 間隔 8、配置は左の中央にする
3. nav-itemを1個、テキスト付きに作り直す
   1. キャンバスの空いた場所に、アイコン代わりの20×20の四角形（薄グレー `#E5E5EA`）と、`t` でテキスト `受信箱`（14、`text/main`）を作る
   2. 2つを選択して `Shift + A` で横に包み、名前を `nav-item` にする
   3. 高さ40、間隔 12、パディング 4/12、角丸8、配置は左の中央にする。背景が透明のうちは角丸もパディングも見えないが、手順5で `今日` に `bg-active` を敷いたとき、この角丸が効いてアクティブ項目の帯になる
4. 作ったnav-itemで、元の四角形5個を置き換える
   1. `sidebar` の中の元の四角形の位置へドラッグで入れ、幅を**拡大**にする（sidebarの中に入れてからでないと拡大は選べない）
   2. `Cmd + D` で5個にし、ラベルを `受信箱`・`今日`・`今週`・`完了`・`アーカイブ` に書き換える
   3. 元の四角形5個を消す
5. `今日` の nav-item だけ背景を `bg-active` に上書きする
6. `今日` の nav-item に未完了数のバッジを付ける
   1. `t` で白文字テキスト `8`（12px）を作り、`Shift + A` で包んで名前を `badge` にする
   2. パディング 2/6、角丸8、塗りを `brand` にする
   3. `今日` の nav-item の中の右端に入れる
   4. ラベルのテキストの幅を**拡大**にする。余った幅をラベルが引き受けるので、バッジが右端に押し出される
7. サイドバー下端のアカウント表示 `user-block` を作る
   1. `t` でテキスト `Taro Yamada`（14、`text/main`）と `Designer`（12、`text/sub`）を作り、2つを選択して `Shift + A` で縦に包み、間隔 0 にする
   2. `o` で 24×24 の正円（薄グレー `#E5E5EA`）を作り、縦積みと2つ選択してもう一度 `Shift + A` で横に包む
   3. パディング 8、間隔 8、配置は左の中央にする
   4. 名前を `user-block` にして、サイドバーの一番下に入れ、幅を**拡大**にする
8. `nav-item` の5個と `user-block` の間に、中身のない空のフレームを1つ入れる。`f` で小さなフレームを描いて `Shift + A` でオートレイアウトにし（中身のない唯一の部品なので、ここだけは空のフレームを直接作る）、名前を `spacer` にしてサイドバーの中へ入れる
9. `spacer` の高さを**拡大**にする。余った縦スペースをspacerが吸収して、`user-block` が下端へ押し出される（オートレイアウトでは特定の1か所だけ間隔を空けられないので、スペーサーで間を開ける）

### 7. 完了タスクを1件仕上げる

1. 好きなTaskCardのインスタンスを1つ選ぶ
2. `checkbox` の塗りを `brand` に上書きする
3. `task-title` の色を `text/sub` に上書きし、「タイポグラフィ」の装飾で打ち消し線を付ける

完了と未完了はバリアントにしてもよいですが、いまは色と装飾の上書きだけで十分です。バリアントは5-2のButtonで扱います。
