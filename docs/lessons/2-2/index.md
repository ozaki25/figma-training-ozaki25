# 2-2 Auto Layoutで並べる

練習用のプロフィールカード（角丸の下地・正円・名前・肩書きを目分量で置いたもの）を、自動配置に切り替えます。使うのはオートレイアウト（Auto Layout）という機能です。

手動配置には弱点があります。要素を1つ足すたびに、他の要素を全部ずらして間隔を測り直すことになります。オートレイアウトを付けたフレームは、中の要素を決めたルール（方向・間隔・余白）で自動的に並べ直してくれます。CSSのflexboxをGUIで操作している、と考えるとほぼそのままです。

## オートレイアウトを付ける

1. 並べたい要素を複数選択する（`Shift` を押しながらクリックで追加選択）
2. `Shift + A` を押す（MacもWindowsも同じ）

これだけで、選択した要素がオートレイアウト付きのフレームにまとまります。右クリックメニューの「オートレイアウトを追加」でも同じことができます。

適用した瞬間、要素は等間隔にピタッと整列します。並び方向（縦か横か）はFigmaが要素の位置関係から推測しますが、後からいつでも変えられます。

解除したいときは `Shift + Option + A`（Windowsは `Shift + Alt + A`）です。

## 「オートレイアウト」セクションで調整する

オートレイアウトを付けたフレームを選択すると、右サイドバーの**「オートレイアウト」セクション**で並べ方を調整できます。flexboxで書くならこう、という対応で覚えるのが早いです。

| Figmaの設定 | CSSでいうと | 内容 |
| --- | --- | --- |
| フロー（縦/横のアイコン） | `flex-direction` | 縦に並べるか横に並べるか |
| 間隔 | `gap` | 隣り合う要素の間隔 |
| パディング | `padding` | フレームの内側の余白 |
| 配置（9マスのボックス） | `align-items` など | 要素をどこに寄せるか |

パディングは水平・垂直をまとめて入れられます。上下左右を個別に指定したいときは、入力欄の右のアイコンから切り替えます。

## 演習: プロフィールカードをオートレイアウト化する

2-1で作ったカード（下地の四角形・正円・名前・肩書き）を使います。手元にない場合は、正円1つとテキスト2つ（名前・肩書き）をフレーム内に適当に置いてから始めてください。

### 1. 名前と肩書きを縦に並べる

1. 名前と肩書きのテキスト2つを選択して `Shift + A`
2. フローが縦になっているか、「オートレイアウト」セクションで確認する
3. 間隔を 4 にする

2つのテキストが、間隔4の縦並びグループになりました。

### 2. 円とテキストグループを横に並べる

1. いま作ったグループと正円を選択して、もう一度 `Shift + A`
2. フローを横にする
3. 間隔を 16 にする
4. 配置の9マスで上下中央に揃える（左中央をクリック）

これがネストです。オートレイアウトの中にオートレイアウトを入れて、「縦に並べたものを横に並べる」といった構造を作ります。flexboxを入れ子にするのと同じ発想です。

### 3. カードにパディングを付ける

1. 外側のオートレイアウトフレームを選択する
2. パディングを 24 にする
3. 「塗り」を白、「角の半径」を 16 にして、カードの見た目にする

外側のフレーム自体がカードになるので、下地の四角形（2-1から持ち込んだ場合）はもう不要です。あれば削除してください。

### 4. 自動で並び直るのを確かめる

肩書きのテキストを選択して `Cmd + D`（Windowsは `Ctrl + D`）で複製し、中身を好きな技術（例: React / TypeScript）に書き換えてみてください。3行目が追加された分、カード全体が自動で広がり、間隔も保たれたままです。手動配置なら測り直していたところが、何もしなくて済みます。
