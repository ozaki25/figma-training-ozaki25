# 2-2 オートレイアウトで並べる

練習用のプロフィールカード（角丸の下地・正円・名前・肩書きを目分量で置いたもの）を、自動配置に切り替えます。使うのはオートレイアウト（Auto Layout）という機能です。

目分量で置いていると、要素を1つ足すたびに他の要素を全部ずらして間隔を測り直すことになります。

オートレイアウトを付けたフレームは、中の要素を決めたルール（方向・間隔・余白）で自動的に並べ直してくれます。CSSのflexboxを使ったことがあれば、それをGUIで操作しているものと考えて構いません。

## オートレイアウトを付ける

1. 並べたい要素を複数選択する（`Shift` を押しながらクリックで追加選択）
2. `Shift + A` を押す（MacもWindowsも同じ）

これだけで、選択した要素がオートレイアウト付きのフレームにまとまります。右クリックメニューの「オートレイアウトを追加」でも同じことができます。この教材では、この操作を「`Shift + A` でオートレイアウトにする」と書きます。

適用した瞬間、要素は等間隔にピタッと整列します。並び方向（縦か横か）はFigmaが要素の位置関係から推測しますが、後からいつでも変えられます。

解除したいときは `Shift + Option + A`（Windowsは `Shift + Alt + A`）です。

## 「オートレイアウト」セクションで調整する

オートレイアウトを付けたフレームを選択すると、右サイドバーの「オートレイアウト」セクションで並べ方を調整できます。

| Figmaの設定 | 内容 | CSSでいうと |
| --- | --- | --- |
| フロー（縦/横のアイコン） | 縦に並べるか横に並べるか | `flex-direction` |
| 間隔 | 隣り合う要素の間隔 | `gap` |
| パディング | フレームの内側の余白 | `padding` |
| 配置（9マスのボックス） | 要素をどこに寄せるか | `align-items` など |

パディングは水平・垂直をまとめて入れられます。上下左右を個別に指定したいときは、入力欄の右のアイコンから切り替えます。

## 演習: プロフィールカードをオートレイアウト化する

2-1で作ったカード（下地の四角形・正円・名前・肩書き）を使います。

### 1. 名前と肩書きを縦に並べる

1. 名前と肩書きのテキスト2つを選択して `Shift + A` で縦のオートレイアウトにする
2. フローが縦になっているか、「オートレイアウト」セクションで確認する
3. 間隔を 4 にする

2つのテキストが、間隔4の縦並びグループになりました。

### 2. 円とテキストグループを横に並べる

1. いま作った縦並びのグループと正円を選択して、もう一度 `Shift + A` でオートレイアウトにする
2. フローを横にする
3. 間隔を 16 にする
4. 配置の9マスで上下中央に揃える（左中央をクリック）

これがネストです。オートレイアウトの中にオートレイアウトを入れて、「縦に並べたものを横に並べる」といった構造を作ります。

### 3. カードにパディングを付ける

1. 外側のオートレイアウトフレームを選択する
2. パディングを 24 にする
   - 入力欄は水平と垂直の2つ。両方に 24 を入れると、上下左右すべてが 24 になる
3. 「塗り」を白（`#FFFFFF`）、「角の半径」を 16 にする

外側のフレーム自体がカードになるので、2-1で作った下地の四角形は削除してください。

![オートレイアウト適用後のプロフィールカード。名前と肩書きの縦並びと正円が間隔16の横並びに整列し、パディング24の白いカードにまとまっている](/lessons/2-2/auto-layout-before-after.png)

### 4. 自動で並び直るのを確かめる

1. 肩書きのテキストを選択して `Cmd + D`（Windowsは `Ctrl + D`）で複製する
2. 複製したテキストを好きな技術（例: React / TypeScript）に書き換える

3行目は間隔4を保ったまま下に追加され、他の要素を自分でずらす必要はありません。目分量で置いていたら、ここで全部測り直していたところです。
