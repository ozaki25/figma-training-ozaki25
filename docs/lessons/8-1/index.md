# 8-1 2日間のふりかえり

タスク管理ツールの2画面（一覧と登録フォーム）を、ゼロからデザインし、Figma MCPでコードに変換するところまで進めました。

## 2日間で通ったルート

![Day1で1〜3章、Day2で4〜7章を進めた流れの俯瞰図。1〜3章の練習で覚えた手順を4章と6章の本番に当てはめ、5章と7章でそれぞれコード生成につなぐ積み上がりを示す](/lessons/8-1/two-day-overview.svg)

各章でやったことを一言でまとめると次のとおりです。

- [1章 Figmaを開いてみる](/lessons/1-1/): 画面構成、フレームの作成、ズーム・パンといった基本操作
- [2章 基本要素を作る](/lessons/2-1/): シェイプ・文字の配置、オートレイアウト、内包/拡大/固定の3つのリサイズ挙動
- [3章 デザインの基礎知識](/lessons/3-1/): 色とテキストのスタイル化、コンポーネントとバリアント、コード生成を見据えた命名、バリアブルによるデザイントークン管理
- [4章 タスク一覧画面を作る](/lessons/4-1/): 骨組み、デザイントークンの定義、TaskCardと優先度バリアント、一覧画面の仕上げ
- [5章 一覧画面をコード化](/lessons/5-1/): MCPのセットアップ、タスク一覧のコード生成
- [6章 タスク登録フォームを作る](/lessons/6-1/): フォームの骨組み、TextFieldとButtonのコンポーネント化、2画面の見た目の統一
- [7章 フォームをコード化](/lessons/7-1/): バリアントをpropsに落とすコード生成

1〜3章は同じサンプル（プロフィールカード）で手順だけを身につけ、4章以降は「画面を作って、その画面をコードにする」を2画面ぶん繰り返す構成でした。デザインの整い具合が生成結果に出るのを、2回とも確かめられました。

## 身についたことの確認

- [ ] Figmaでフレーム・オートレイアウト・内包/拡大/固定を使い、実装しやすい構造でUIを組める
- [ ] 色・テキストのスタイル化とコンポーネント/バリアントを使い、部品を再利用可能な形に切り出せる
- [ ] Figma MCP + Claude Codeに対して、URL・スタック・分割・命名反映を含む指示を出してコードに変換できる

3つのどれかにひっかかるなら、対応する章のレッスンをもう一度手を動かして通すとよいです。
