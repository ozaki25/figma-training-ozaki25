# 3-1 カラーとタイポグラフィのルール化

この章では、練習用のプロフィールカード（正円と名前・肩書きをAuto Layoutで並べ、幅を320に固定したもの）を題材に、デザインの基礎知識を身につけます。最初のテーマは、色と文字の「ルール化」です。

## なぜルール化するのか

カラーピッカーで毎回その場の感覚で色を選ぶと、画面ごとに微妙に違う紫、微妙に違うグレーが増えていきます。フォントサイズも同じで、13と14と15が混ざった画面は理由もなくちぐはぐに見えます。

CSSで経験があるはずです。`#7C3AED` をあちこちに直書きすると変更が地獄になるので、`--color-brand` のような変数にまとめます。デザインでも発想は同じで、先に使う色とサイズを決めておき、そこからだけ選ぶようにします。

目安はかなり少なくて大丈夫です。

- **色**: メインの色1つ、テキストの濃いグレーと薄いグレー、背景色。この4つ程度で小さな画面は成立します
- **フォントサイズ**: 12 / 14 / 16 / 24 のような4段階を決めて、その中からだけ選びます

小さな画面は4色で十分です。実践のアプリでは、罫線用のグレーやアクティブ状態の背景色などが加わり、6〜8色になることもあります。数を増やすときも「使う色を先に決めて、そこからだけ選ぶ」考え方は同じです。

## Figmaのスタイル機能

決めたルールをFigmaに登録する仕組みが「スタイル」です。色を保存する色スタイルと、フォント・サイズ・ウェイトをセットで保存するテキストスタイルがあります。CSS変数と同じで、定義を1か所変えれば使っている全要素に反映されます。

### 色スタイルを登録する

1. 色を付けた要素を選択する
2. 右サイドバーの Fill セクション右上にある、点が4つ並んだアイコンをクリックする（ホバーすると「Apply styles and variables」と出ます）
3. 開いたパネル右上の「+」から Color style を選ぶ
4. 名前を付けて Create style を押す

これで、その要素の塗りが登録した色スタイルに置き換わります。名前に `/` を入れると、`text/main` と `text/sub` が text グループにまとまるようにグループ化できます。

### テキストスタイルを登録する

手順はほぼ同じです。テキストを選択して、Typography セクション右上の4点アイコン →「+」→ 名前を付けて Create style。フォント・サイズ・ウェイト・行間がまとめて保存されます。

### 適用と編集

- **適用**: 別の要素を選択して同じ4点アイコンを開くと、登録済みのスタイル一覧が出ます。クリックすれば適用されます
- **編集**: 何も選択していない状態にすると（`Esc` を押すか、キャンバスの空白をクリック）、右サイドバーに「Local styles」としてこのファイルのスタイル一覧が出ます。スタイル名にホバーすると出る調整アイコンから、定義を編集できます

なお、2026年時点のFigmaには色や数値を保存できる **Variables** という機能もあります。ライト/ダーク切り替えのような高度な使い方をするための仕組みで、色とテキストをそろえるだけならスタイルで十分です。このハンズオンでは名前の紹介にとどめます。

## 演習: プロフィールカードをスタイル化する

2章で作ったカード（紫の正円・名前・肩書き、幅Fixed 320）を使います。手元にない場合は、正円1つとテキスト2つをAuto Layoutで横並びにしたカードを作ってから始めてください。

![プロフィールカードの各要素とスタイルの対応。円にはbrand、名前にはtext/mainとname、肩書きにはtext/subとcaptionのスタイルが割り当てられている](/lessons/3-1/styles-mapping.svg)

### 1. 色スタイルを3つ登録する

1. 正円を選択し、Fill を `#7C3AED` にしてから4点アイコン →「+」で `brand` という名前で登録する
2. 名前のテキストを選択し、文字色を濃いグレー（例: `#333333`）にして `text/main` として登録する
3. 肩書きのテキストを選択し、薄いグレー（例: `#777777`）にして `text/sub` として登録する

登録すると、右サイドバーの色の表示がカラーコードからスタイル名に変わります。

### 2. テキストスタイルを2つ登録する

1. 名前のテキストを選択し、サイズ 16・Bold になっているのを確認して、Typography の4点アイコン →「+」で `name` として登録する
2. 肩書きのテキストを、サイズ 12・Regular で `caption` として登録する

### 3. 一括反映を体験する

1. `Esc` を押して選択を解除し、右サイドバーの Local styles を表示する
2. `brand` の調整アイコンを開き、色を別の色（例: 緑 `#0ACF83`）に変えてみる
3. 正円の色が、要素を触っていないのに変わるのを確認する
4. 同じように `name` のサイズを 24 に変えて、名前のテキストが大きくなるのを確認する
5. 確認できたら、色を `#7C3AED`、サイズを 16 に戻す

いまはカードが1枚なのでありがたみが薄いですが、この後の実践編でスタイルを何十個もの要素に適用すると、この一括反映が効いてきます。

## ゴール確認

- [ ] 色は4つ程度・サイズは4段階程度に絞る、というルール化の考え方を説明できた
- [ ] 4点アイコンから色スタイルとテキストスタイルを登録・適用できた
- [ ] Local stylesでスタイルの定義を変えると、適用先が一括で変わるのを確認できた
