# 3-1 カラーとタイポグラフィのルール化

この章では、練習用のプロフィールカード（正円と名前・肩書きをオートレイアウトで並べ、幅を320に固定したもの）を題材に、デザインの基礎知識を身につけます。最初のテーマは、色と文字の「ルール化」です。

## ルール化の狙い

カラーピッカーで毎回その場の感覚で色を選ぶと、画面ごとに微妙に違う紫、微妙に違うグレーが増えていきます。フォントサイズも同じで、13と14と15が混ざった画面は理由もなくちぐはぐに見えます。

コードで同じ色をあちこちに直書きすると、変えたいときに全部探して直すはめになります。だから `--color-brand` のような変数に1か所でまとめます。デザインでも発想は同じで、先に使う色とサイズを決めておき、そこからだけ選ぶようにします。

目安はかなり少なくて大丈夫です。

- **色**: メインの色1つ、テキストの濃いグレーと薄いグレー、背景色。この4つ程度で小さな画面は成立します
- **フォントサイズ**: 12 / 14 / 16 / 24 のような4段階を決めて、その中からだけ選びます

実践のアプリでは、罫線用のグレーやアクティブ状態の背景色などが加わり、6〜8色になることもあります。数を増やすときも「使う色を先に決めて、そこからだけ選ぶ」考え方は同じです。

::: tip 文字色と背景色のコントラスト比
文字が背景に対して読みやすいかは、コントラスト比という数値で判断できます。Figmaならプラグインなしで、テキストを選択して「塗り」の色をクリックすると、カラーピッカーの中に背景とのコントラスト比とWCAG基準（AA / AAA）の判定が出ます。薄いグレーの文字色を決めるときに一度見ておくと、読みにくい配色を避けられます。
:::

## Figmaのスタイル機能

決めたルールをFigmaに登録する仕組みが「スタイル」です。色を保存する色スタイルと、フォント・サイズ・ウェイトをセットで保存するテキストスタイルがあります。定義を1か所変えれば、使っている全要素に反映されます。

### 色スタイルを登録する

1. 色を付けた要素を選択する
2. 右サイドバーの「塗り」セクション右上にある、点が4つ並んだアイコンをクリックする（ホバーすると「スタイルとバリアブルを適用」と出ます）
3. 開いたパネル右上の「+」（新しいスタイルまたはバリアブル）から色スタイルを選ぶ
4. 名前を付けて「スタイルの作成」を押す

これで、その要素の塗りが登録した色スタイルに置き換わります。名前に `/` を入れるとグループ化され、たとえば `text/main` と `text/sub` は text グループにまとまります。

### テキストスタイルを登録する

手順はほぼ同じです。

1. テキストを選択し、「タイポグラフィ」セクション右上の4点アイコン（ホバーすると「スタイルを適用」と出ます）をクリックする
2. パネル右上の「+」から名前を付けて「スタイルの作成」を押す

フォント・サイズ・ウェイト・行間がまとめて保存されます。

### 適用と編集

- **適用**: 別の要素を選択して同じ4点アイコンを開くと、登録済みのスタイル一覧が出ます。クリックすれば適用されます
- **編集**: 何も選択していない状態にすると（`Esc` を押すか、キャンバスの空白をクリック）、右サイドバーの「スタイル」セクションにこのファイルのスタイル一覧が出ます。スタイル名にホバーすると出る調整アイコンから、定義を編集できます

なお、Figmaには色や数値を「値そのもの」として保存できる**バリアブル**（Variables）という機能もあります。デザイントークンの管理に使う仕組みで、スタイルとの使い分けも含めて3-4で演習し、4章の本番では色の管理をバリアブルでやります。まずはスタイルで「ルール化して一括反映する」感覚をつかんでください。

## 演習: プロフィールカードをスタイル化する

2章で作ったカード（正円・名前・肩書き、幅は固定320）を使います。正円は単色でも画像でも構いません。

![プロフィールカードの各要素とスタイルの対応。カードの白い背景にはsurface、名前にはtext/mainとname、肩書きにはtext/subとcaptionのスタイルが割り当てられている](/lessons/3-1/styles-mapping.svg)

### 1. 色スタイルを3つ登録する

1. カードのフレーム（白背景）を選択し、「塗り」の4点アイコンをクリックする
2. パネル右上の「+」を押し、名前に `surface` を入力して「スタイルの作成」を押す。カードのような面の地色には surface という名前がよく使われます
3. 名前のテキストを選択し、文字色を濃いグレー（例: `#333333`）にして、同じ流れで `text/main` として登録する
4. 肩書きのテキストを選択し、薄いグレー（例: `#666666`）にして `text/sub` として登録する

登録すると、右サイドバーの色の表示がカラーコードからスタイル名に変わります。

### 2. テキストスタイルを2つ登録する

1. 名前のテキストを選択し、サイズ 16・Bold になっているのを確認する
2. 「タイポグラフィ」の4点アイコンから、同じ流れで `name` として登録する
3. 肩書きのテキストを、サイズ 12・Regular で `caption` として登録する

### 3. 一括反映を体験する

1. `Esc` を押して選択を解除し、右サイドバーの「スタイル」セクションを表示する
2. `surface` の調整アイコンを開き、色を薄い緑（例: `#DFF7EC`）に変えてみる
3. カードの背景が、要素を触っていないのに変わるのを確認する
4. 同じように `name` のサイズを 24 に変えて、名前のテキストが大きくなるのを確認する
5. 確認できたら、色を `#FFFFFF`、サイズを 16 に戻す

いまはカードが1枚なのでありがたみが薄いですが、部品が何十個にもなる実践では、この一括反映が設計の前提になります。4章の本番では色をスタイルではなくバリアブル（3-4）で管理しますが、「定義を1か所直せば全部に反映される」という考え方はまったく同じです。

## ゴール確認

- [ ] 色は4つ程度・サイズは4段階程度に絞る、というルール化の考え方を説明できた
- [ ] 4点アイコンから色スタイルとテキストスタイルを登録・適用できた
- [ ] 「スタイル」セクションで定義を変えると、適用先が一括で変わるのを確認できた
