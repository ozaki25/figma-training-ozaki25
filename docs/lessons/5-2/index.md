# 5-2 入力欄・ボタンを作る

5-1で置いた仮のプレースホルダーを、本物の入力欄とボタンに入れ替えます。コンポーネント化してからインスタンスをフォームに並べる、4-2と同じ流れです。

今回はボタンにバリアントを付けます。3-2で練習したバリアントを、2画面目のこの場面で初めて本番のデザインに使います。

このレッスンでも操作は逐一書きません。仕様（サイズ・色・スタイル）を示すので、既習の操作（`Shift + A`、Hug/Fill、コンポーネント化、Assetsパネル、Add variant）で組み立ててください。

## 完成イメージ

![TextFieldとButtonの構造と、form-cardにインスタンスを並べた完成イメージ。TextFieldはラベルと入力欄の縦Auto Layout。Buttonはprimaryとsecondaryの2バリアント。form-cardにタスク名・期限・メモの入力欄と登録ボタンが縦に並ぶ](/lessons/5-2/task-form-components.svg)

作るのはTextFieldとButtonの2つです。仕様は次のとおり。

| 部品 | 役割 | 仕様 |
| --- | --- | --- |
| `TextField` | ラベル付き入力欄 | 縦Auto Layout、gap 8、幅Hug（親でFillにする） |
| └ `label` | ラベルテキスト | 12px、色スタイル `text/sub` |
| └ `input` | 入力ボックス | 高さ44、padding 12、角丸8、白背景、枠線 `#D9D9E0`、テキスト14px |
| `Button` | ボタン | 高さ44、padding H 20、角丸8、幅Hug（親でFillにする） |
| └ `label` | ボタンラベル | 14px SemiBold |

Buttonにはバリアントを2つ用意します。プロパティ名は `variant`、値は `primary` と `secondary` です。

| バリアント | 背景 | 文字 | 枠線 |
| --- | --- | --- | --- |
| `primary` | `brand`（紫） | 白 | なし |
| `secondary` | 白 | `brand` | `brand` 1px |

登録フォームで使うのはprimaryだけです。それでも2バリアント作っておくと、後から「キャンセル」を並べたくなったときに、コンポーネント側は触らずインスタンスのドロップダウン切り替えだけで済みます。3-2でやったバリアントの練習が、こういう場面で効いてきます。

## 作る順序

外側から中身を作った5-1・4-2とは順序が違います。今回は部品を先に作り、あとでフォームに差し込みます。

1. 画面フレームの外の空いた場所で `TextField` を組み、コンポーネント化する
2. 同じ場所で `Button`（primary）を組み、コンポーネント化してから `secondary` バリアントを追加する
3. 5-1のform-cardに戻り、プレースホルダーを削除してインスタンスに置き換える

4-2と同じで、原本は画面フレームの外に置き、画面にはインスタンスだけを並べます。原本の幅はFixedで作り、フォームに入れたインスタンス側でFillにします。

## 演習

### 1. TextFieldを作る

1. `task-form` フレームの外の空いた場所で、テキスト `タスク名`（12px）と、`R` で作った四角形（幅Fixed 320、高さ44、角丸8、白塗り、枠線 `#D9D9E0`）を用意する
2. 四角形の中に、プレースホルダー用のテキスト `例: 会議資料の作成`（14px、薄いグレー）を置いてもよい。空のままでも構わない
3. ラベルと入力ボックスを選択して `Shift + A` で縦Auto Layoutにする。gap 8、パディング 0
4. `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）でコンポーネント化する
5. `Cmd + R`（Windowsは `Ctrl + R`）で名前を付ける: コンポーネントは `TextField`、中の部品は `label` と `input`
6. ラベルには4-3で登録した色スタイル `text/sub` を当てておく

これで、ラベル付きの入力欄が1つの部品としてまとまりました。

### 2. Buttonを作ってバリアントを追加する

1. 同じ場所でテキスト `登録`（14px、SemiBold、白）を作り、`Shift + A` でAuto Layoutにする
2. 仕様どおりに設定する: 高さ44、左右padding 20、角丸8、背景は色スタイル `brand`、幅Fixed 200（原本のうちだけ）
3. `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）でコンポーネント化する
4. `Cmd + R`（Windowsは `Ctrl + R`）で名前を付ける: コンポーネントは `Button`、中のテキストは `label`
5. コンポーネントを選択して、右サイドバーの **Add variant** をクリックする。同じ見た目の2枚目が紫の破線枠に入る
6. 右サイドバーの Current variant でプロパティ名を `variant`、1枚目の値を `primary`、2枚目の値を `secondary` に変える
7. `secondary` の方の背景を白、枠線を `brand` の1px、テキスト色を `brand` に変える。テキストは「キャンセル」に変えてもよい

`primary` と `secondary` の2バリアントが並んだコンポーネントセットができました。

### 3. フォームにインスタンスを差し込む

5-1で作った `form-card` に戻ります。

1. カードの中の `input-placeholder` 3つを選択して `Delete` で消す
2. 左サイドバーの **Assets パネル**から `TextField` を form-card の中へドラッグする。これを3つ並べる
3. 3つのインスタンスの幅をそれぞれ **Fill** にする。カードの幅いっぱいに揃うはず
4. 各インスタンスの `label` をダブルクリックして書き換える: `タスク名`、`期限`、`メモ`
5. `button-placeholder` を消し、Assetsパネルから `Button` をドラッグする。variantは `primary` のまま、幅を **Fill** にし、`label` を `登録` にする

インスタンスの幅Fillは、親（form-card）がAuto Layoutだから選べます。原本側で幅Fixedにしていても、インスタンスに入れた瞬間に切り替えられる、というのが4-2で確認した挙動です。

最後にform-cardの余白（padding 32・gap 20）どおりに入力欄とボタンが並び、フォーム全体の見た目が整っていれば完成です。原本のTextFieldの角丸を12に変えてみて、3つのインスタンスがまとめて追従することを確認したら、8に戻しておきます。
