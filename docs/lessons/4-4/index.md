# 4-4 一覧画面を仕上げて完成させる

4-3でタスクカードが3枚並びました。このレッスンで統計・フィルタ・セクション分け・サイドバーの装飾・完了状態まで仕上げて、タスク一覧画面を完成させます。4章の集大成なので手順は多めですが、操作はどれも既習の繰り返しです。

## 完成イメージ

![仕上げ後のタスク一覧画面。左は装飾済みsidebar（ロゴ、nav-item 5個、下端にユーザーブロック）、右はheaderとcontent。contentには見出し、統計カード3枚、フィルタチップ4個、3セクションに合計8枚のTaskCardが並ぶ。1枚は完了状態](/lessons/4-4/task-list-final.png)

## 仕上げの順序

1. 統計カード `StatCard` をコンポーネントで作り、3枚並べる
2. フィルタチップを4個並べる
3. サイドバーの項目を `NavItem` コンポーネントに置き換える
4. ロゴとユーザーブロックでサイドバーを仕上げる
5. TaskCardをセクションに分けて8枚にする
6. 完了状態を `done` バリアントにする

## 演習

### 1. StatCardを作って3枚並べる

数値つきの統計カードです。3枚とも同じ構造なので、コンポーネントにしてから複製します。

1. キャンバスの空いた場所に `t` でテキストを3つ作る。ラベル `今日のタスク`（`caption` + `text/sub`）、数値 `8`（`stat-value` + `text/main`）、補足 `未完了`（`caption` + `text/sub`）
2. 3つを選択して `Shift + A` で縦に包む
   - 間隔 `space/8`、パディング `space/20`
   - 背景 `surface`、枠線1px `border`、角丸 `radius/12`
   - 高さは**内包**
3. `Cmd + Option + K` でコンポーネント化して、名前を `StatCard` にする
4. アセットパネルから `StatCard` のインスタンスを1つキャンバスへ出し、選択して `Shift + A` で包み、名前を `stat-row` にする
5. `stat-row` を間隔 `space/16`、パディング 0 にして、`content` の中、`page-title` の下へ入れる
6. `stat-row` の幅を**拡大**、高さは内包にする
7. 中のインスタンスの幅を**拡大**にして、`Cmd + D` で3枚にする
8. 2枚目・3枚目の中身を「完了 / 12 / 今週」「遅延 / 2 / 要対応」に書き換える

3枚が幅の拡大でcontentの横いっぱいに広がります。

### 2. filter-barを作る

フィルタ用のチップを4個並べます。チップも切り替えの状態を持つのでコンポーネントにする手はありますが、NavItemと手順が重なるのでここではコンポーネントにしません。余裕があれば章末の任意課題で試せます。

1. チップを1個作る
   1. `t` でテキスト `すべて`（`caption` + `text/inverse`）を作り、`Shift + A` で包む
      - 上下パディング `space/4`、左右パディング `space/12`
      - 角丸 `radius/full`、背景 `brand`
      - 高さは**固定32**、幅は**内包**
   2. 名前を `chip-active` にする
2. `chip-active` を選択して、もう一度 `Shift + A` で包み、名前を `filter-bar` にする
3. `filter-bar` を間隔 `space/8`、パディング 0 にして、`content` の中、`stat-row` の下へ入れる
4. `filter-bar` の幅は拡大、高さは内包にする
5. チップを `Cmd + D` で4個にし、増えた3個を「未完了 / 完了 / 優先高」に書き換える
6. その3個の背景を `surface`、枠線1px `border`、文字を `text/main` にする。名前は `chip` でよい

### 3. NavItemを作ってサイドバーの四角形と置き換える

サイドバーの項目は「通常」と「アクティブ」の2状態を持つ部品なので、バリアント付きのコンポーネントにします。

1. NavItemの中身を作る
   1. キャンバスの空いた場所に、アイコン代わりの20×20の四角形（塗り `placeholder`、角丸 `radius/4`）と、`t` でテキスト `受信箱`（`body` + `text/main`）を作る
   2. 2つを選択して `Shift + A` で横に包む
      - 間隔 `space/12`、上下パディング `space/4`、左右パディング `space/12`、配置は左中央
      - 角丸 `radius/8`、高さは**固定40**
2. `Cmd + Option + K` でコンポーネント化して、名前を `NavItem` にする
3. バリアントを追加する
   1. 右サイドバー上部の「バリアントの追加」アイコンをクリックする
   2. 「現在のバリアント」で `プロパティ1` を `active` に、1枚目の値を `false`、2枚目を `true` にする
4. `true` の方をアクティブの見た目にする
   1. 背景を `bg-active` にする。薄紫の角丸の背景が付いて、アクティブな項目の見た目になる
   2. 未完了数のバッジを足す。`t` で白文字テキスト `8`（`caption` + `text/inverse`）を作り、`Shift + A` で包んで名前を `badge` にする
   3. `badge` を上下パディング `space/4`、左右パディング `space/8`、角丸 `radius/full`、背景 `brand` にする
   4. `badge` を `true` の方のNavItemの中、ラベルの右へ入れる
   5. ラベルのテキストの幅を**拡大**にする。余った幅をラベルが引き受けるので、バッジが右端に押し出される
5. サイドバーの四角形と置き換える
   1. アセットパネルから `NavItem` のインスタンスを `sidebar` の中の四角形の位置へ入れ、幅を**拡大**にする
   2. `Cmd + D` で5個にし、ラベルを `受信箱`・`今日`・`今週`・`完了`・`アーカイブ` に書き換える
   3. 仮置きだった四角形5個を消す
6. `今日` のインスタンスを選択し、右サイドバーの `active` トグルをオンにする。背景とバッジが一緒に切り替わる

### 4. ロゴとユーザーブロックでサイドバーを仕上げる

1. サイドバー上部をロゴの形にする
   1. アイコン代わりに、`r` で 24×24 の正方形（塗り `brand`、角丸 `radius/8`）を作る
   2. 正方形を `sidebar` の中、`app-brand` の上へ入れる
   3. 正方形と `app-brand` を選択して `Shift + A` で横に包み、名前を `logo` にする
   4. 間隔 `space/8`、配置は左中央にする
2. サイドバー下端のアカウント表示 `user-block` を作る
   1. `t` でテキスト `Taro Yamada`（`body` + `text/main`）と `Designer`（`caption` + `text/sub`）を作り、2つを選択して `Shift + A` で縦に包み、間隔 0 にする
   2. `o` で 24×24 の正円（塗り `placeholder`）を作り、正円と縦積みの2つを選択してもう一度 `Shift + A` で横に包む
   3. パディング `space/8`、間隔 `space/8`、配置は左中央にする
   4. 名前を `user-block` にして、サイドバーの一番下に入れ、幅を**拡大**にする
3. `NavItem` の5個と `user-block` の間に、空のフレームを1つ入れる
   1. `f` で小さなフレームを描き、`Shift + A` でオートレイアウトにする（中身のない唯一の部品なので、ここだけは空のフレームを直接作る）
   2. 名前を `spacer` にして、サイドバーの中、`user-block` の上へ入れる
4. `spacer` の高さを**拡大**にする
   - 余った縦スペースをspacerが吸収して、`user-block` が下端へ押し出される。オートレイアウトでは特定の1か所だけ間隔を空けられないので、スペーサーで間を開ける

### 5. セクション分けとTaskCardを8枚に増やす

いまcontentにあるTaskCardのインスタンス3枚を、次の表のとおり「今日・今週・あとで」の3セクションに分け、5枚追加して合計8枚にします。

| セクション | 優先度 | タイトル | 説明 | カテゴリ | 担当 | 期限 |
| --- | --- | --- | --- | --- | --- | --- |
| 今日 | high | デザインレビューの準備 | 一覧画面のデザインを共有 | デザイン | TY | 今日 |
| 今日 | mid | 会議資料の作成 | 定例向けサマリ | ドキュメント | HK | 今日 |
| 今日 | high | APIエラーの調査 | 500系の再現手順 | 開発 | ST | 今日 |
| 今週 | mid | リリースノートの下書き | v2.3ぶん | ドキュメント | TY | 明日 |
| 今週 | low | 依存ライブラリ更新 | patch差分のみ | 開発 | HK | 木曜 |
| 今週 | mid | ユーザーヒアリング日程調整 | 3社 | 企画 | KM | 金曜 |
| あとで | low | ドキュメントの誤字修正 | Issue #142 | ドキュメント | ST | 来週 |
| あとで | high | 本番デプロイ手順の見直し | 手順書v3化 | 運用 | TY | 来週 |

1. `t` でセクション見出しのテキスト `今日`（`section-title` + `text/sub`）を作り、`Shift + A` で包む。このフレームが1つ目のセクションになる
2. 間隔 `space/12`、パディング 0 にして、名前を `section-today` にする
3. `content` の中、`filter-bar` の下へ入れ、幅は拡大、高さは内包にする
4. `Cmd + D` で3個にし、増えた2個の名前を `section-week`・`section-later` に、見出しを `今週`・`あとで` に書き換える
5. 既存のTaskCard 3枚を `section-today` の中へ移動する
6. `section-today` のカードを1枚選んで `Cmd + D` で複製し、`section-week` へ3枚、`section-later` へ2枚移す。複製なら幅の拡大がそのまま引き継がれる
7. 表のとおりに各カードのテキストを書き換え、`PriorityTag` の `priority` をドロップダウンで切り替える

レイヤーパネルで、各セクションの中が「見出し → TaskCard×枚数」の縦並びになっていれば正解です（例: `section-today` の中は `今日`・TaskCard・TaskCard・TaskCard）。

### 6. 完了状態をdoneバリアントにする

完了は「タスクカードのもうひとつの状態」なので、これもバリアントにします。

1. 画面の外にある `TaskCard` の原本を選択し、「バリアントの追加」をクリックする
2. 「現在のバリアント」で `プロパティ1` を `done` に、1枚目の値を `false`、2枚目を `true` にする
3. `true` の方を完了の見た目にする
   1. `checkbox` の塗りを `brand` にする
   2. `task-title` の色を `text/sub` にして、「タイポグラフィ」の詳細設定（`⋯`）を開き、装飾で打ち消し線を付ける
4. 画面に戻り、好きなTaskCardのインスタンスを1枚選んで、`done` トグルをオンにする

これでタスク一覧画面は完成です。優先度も完了も、色の上書きではなくプロパティの切り替えで表現できるようになりました。

::: tip 任意課題: チップのコンポーネント化
フィルタチップも「通常とアクティブの2状態を持つ部品」です。NavItemとまったく同じ手順で `Chip`（`active=true/false`）をコンポーネント化できます。余裕があれば、手順を見ずに挑戦してみてください。
:::
