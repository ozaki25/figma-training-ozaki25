# 4-4 統計・フィルタ・ナビの部品を作る

4-3でタスクカードが3枚並びました。このレッスンでは、contentに統計カードとフィルタを足し、サイドバーに残っている仮置きの四角形をナビ項目に置き換えます。操作はどれも既習の繰り返しです。

## 完成イメージ

![仕上げ後のタスク一覧画面。左は装飾済みsidebar（ロゴ、nav-item 5個、下端にユーザーブロック）、右はheaderとcontent。contentには見出し、統計カード3枚、フィルタチップ4個、3セクションに合計5枚のTaskCardが並ぶ。1枚は完了状態](/lessons/4-4/task-list-final.png)

これが4章の完成形です。このレッスンで作るのは、contentの上半分にある統計カード3枚とフィルタチップ4個、それにサイドバーのナビ項目5個です。セクション分けとサイドバーの装飾は4-5で仕上げます。

## 演習

### 1. StatCardを作って3枚並べる

数値つきの統計カードです。3枚とも同じ構造なので、コンポーネントにしてから複製します。

1. キャンバスの空いた場所に、カードの中身になるテキストを3つ作る
   1. `t` を押してクリックし、ラベルのテキスト `未完了`（テキストスタイル `caption`、色 `text/sub`）を作る
   2. `t` を押してクリックし、数値のテキスト `8`（テキストスタイル `stat-value`、色 `text/main`）を作る
   3. `t` を押してクリックし、補足のテキスト `今日`（テキストスタイル `caption`、色 `text/sub`）を作る
2. 3つを選択して `Shift + A` で縦のオートレイアウトにする
   - 間隔 `space/8`、パディング `space/20`、配置は左上
   - 背景 `surface`、枠線1px `border`、角丸 `radius/12`
   - 幅は**固定220**、高さは**内包**（`content` に並べたあと、インスタンス側で拡大にする）
3. 中の3つのテキストを選択して、幅を**拡大**、行揃えを左にする
4. `Cmd + Option + K` でコンポーネント化して、名前を `StatCard` にする
5. アセットパネルから `StatCard` のインスタンスを1つキャンバスへ出し、選択して `Shift + A` で横のオートレイアウトにして、名前を `stat-row` にする
6. `stat-row` を間隔 `space/16`、パディング 0 にして、`content` の中、`page-title` の下へ入れる
7. `stat-row` の幅を**拡大**、高さは内包にする
8. 中のインスタンスの幅を**拡大**にして、`Cmd + D` で3枚にする
9. 2枚目・3枚目の中身を「完了 / 12 / 今週」「遅延 / 2 / 要対応」に書き換える

3枚が幅の拡大でcontentの横いっぱいに広がります。

### 2. filter-barを作る

フィルタ用のチップを4個並べます。チップも切り替えの状態を持つのでコンポーネントにする手はありますが、NavItemと手順が重なるのでここではコンポーネントにしません。余裕があればこのレッスン末尾の任意課題で試せます。

1. チップを1個作る
   1. `t` を押してクリックし、テキスト `すべて`（テキストスタイル `caption`、色 `text/inverse`）を作り、`Shift + A` でオートレイアウトにする
      - 左右パディング `space/12`、上下パディング `space/4`
      - 角丸 `radius/full`、背景 `brand`
      - 高さは**固定32**、幅は**内包**
   2. 名前を `chip-active` にする
2. `chip-active` を選択して、もう一度 `Shift + A` で横のオートレイアウトにして、名前を `filter-bar` にする
3. `filter-bar` を間隔 `space/8`、パディング 0 にして、`content` の中、`stat-row` の下へ入れる
4. `filter-bar` の幅は拡大、高さは内包にする
5. チップを `Cmd + D` で4個にし、増えた3個を「未完了 / 完了 / 優先高」に書き換える
6. その3個の背景を `surface`、枠線1px `border`、文字を `text/main` にする。名前は `chip` でよい

### 3. NavItemを作ってサイドバーの四角形と置き換える

サイドバーの項目は「通常」と「アクティブ」の2状態を持つ部品なので、バリアント付きのコンポーネントにします。

1. NavItemの中身を作る
   1. キャンバスの空いた場所に、アイコン代わりの20×20の四角形（塗り `placeholder`、角丸 `radius/4`）を `r` で作る
   2. `t` を押してクリックし、テキスト `受信箱`（テキストスタイル `body`、色 `text/main`）を作る
   3. 2つを選択して `Shift + A` で横のオートレイアウトにする
      - 間隔 `space/12`、左右パディング `space/12`、上下パディング `space/4`、配置は左中央
      - 角丸 `radius/8`
      - 幅は**固定240**、高さは**固定40**（サイドバーに入れたあと、インスタンス側で拡大にする）
2. `Cmd + Option + K` でコンポーネント化して、名前を `NavItem` にする
3. バリアントを追加する
   1. 右サイドバー上部の「バリアントの追加」アイコンをクリックする
   2. 「現在のバリアント」で `プロパティ1` を `active` に、1枚目の値を `false`、2枚目を `true` にする
4. `true` の方をアクティブの見た目にする
   1. 背景を `bg-active` にする。薄紫の角丸の背景が付いて、アクティブな項目の見た目になる
   2. 未完了数のバッジを足す。`t` を押してクリックし、白文字テキスト `8`（テキストスタイル `caption`、色 `text/inverse`）を作り、`Shift + A` でオートレイアウトにして、名前を `badge` にする
      - 左右パディング `space/8`、上下パディング `space/4`
      - 角丸 `radius/full`、背景 `brand`
      - 幅は**内包**。拡大になっているときれいな丸にならない
   3. `badge` を `true` の方のNavItemの中、ラベルの右へ入れる
   4. ラベルのテキストの幅を**拡大**にする。余った幅をラベルが引き受けるので、バッジが右端に押し出される
5. サイドバーの四角形と置き換える
   1. アセットパネルから `NavItem` のインスタンスを `sidebar` の中の四角形の位置へ入れ、幅を**拡大**にする
   2. `Cmd + D` で5個にし、ラベルを `受信箱`・`今日`・`今週`・`完了`・`アーカイブ` に書き換える
   3. 仮置きだった四角形5個を消す
6. `今日` のインスタンスを選択し、右サイドバーの `active` トグルをオンにする。背景とバッジが一緒に切り替わる

::: tip 任意課題: チップのコンポーネント化
フィルタチップも「通常とアクティブの2状態を持つ部品」です。NavItemとまったく同じ手順で `Chip`（`active=true/false`）をコンポーネント化できます。余裕があれば、手順を見ずに挑戦してみてください。
:::
