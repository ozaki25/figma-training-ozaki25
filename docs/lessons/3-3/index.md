# 3-3 コード生成を見据えたレイヤー命名

コンポーネント化まで済ませたプロフィールカードを使って、3章の仕上げにレイヤーの名前と構造を整えます。見た目は何も変わらない地味な作業ですが、このハンズオンの最終ゴールである「Figma MCP + Claude Codeによるコード生成」の品質に直結します。

## 命名を整える理由

Figmaは作った要素に「種類 + 連番」で自動的に名前を付けます。四角形なら Rectangle 1、フレームなら Frame 2 という具合です。テキストだけは例外で、入力した文字がそのまま名前になります。

放っておくと、レイヤーパネルは Rectangle 42 や Frame 13 だらけになります。HTMLに例えると、すべての要素を `div` で書いて `class` を1つも付けていない状態です。どれが何なのか、後で見た自分にも、他人にも、そしてコードを生成するAIにも読み取れません。

## リネームの方法

- レイヤーパネルの名前を**ダブルクリック**して書き換える
- レイヤーを選択して `Cmd + R`（Windowsは `Ctrl + R`）。右クリック →「名前を変更」でも同じ

複数のレイヤーを選択して `Cmd + R`（Windowsは `Ctrl + R`）を押すと、一括リネームのダイアログが開きます。共通の名前を入れて連番を付けたり、名前の一部だけを検索・置換したりできます。同じ種類のレイヤーが大量にあるときに便利なので、あることだけ覚えておいてください。

なお、AIに名前を提案させる機能もありますが、ここでは自分の手で付けます。名前を考えること自体が、構造を見直すきっかけになるからです。

## 命名の指針

難しいルールは要りません。次の3点だけ意識します。

- **役割が分かる名前にする**: `avatar`、`user-name`、`card` のように、それが何なのかを書く。`purple-circle` のような見た目由来の名前は、色を変えた瞬間に嘘になるので避ける
- **英語で付ける**: 生成されるコードのクラス名やコンポーネント名の種になるため、コードに合わせて英語にしておく
- **形式は好みでよい**: `user-name`（kebab-case）でも `UserName`（PascalCase）でも、チームで揃っていれば問題ない。このハンズオンでは、部品の中身はkebab-case、コンポーネント名はPascalCaseで統一します

## 構造もセットで整える

名前と合わせて、レイヤーの構造も見直します。チェックするのは2点です。

- **意味のまとまりごとにオートレイアウトフレームでグループ化されているか**: 名前と肩書きが `user-info` という1つのフレームにまとまっている、という状態がHTMLの入れ子構造にそのまま対応します
- **不要なレイヤーが残っていないか**: 空のフレーム、非表示にしたまま忘れている要素、下書きに使った図形などは削除します。残っていると、読む側（人もAIも）が「これは意味があるのか」と迷います

## コード生成にどう効くか

6章で使うFigma MCPは、レイヤー名と構造も手がかりにしてコードを生成します。カードが `profile-card` という名前なら、生成されるコードのクラス名やコンポーネント名にもその意図が反映されます。Frame 13 のままなら、AIは中身から役割を推測するしかなく、生成結果もそれなりになります。詳しくは6章で体験するので、ここでは「良い名前は良いコードの種」とだけ覚えておけば十分です。

## 演習: プロフィールカードのレイヤーを整理する

コンポーネント化まで済ませたカード（正円・名前・肩書きの横並び、幅は固定320）を使います。手元にない場合は、正円1つとテキスト2つをオートレイアウトで横並びにしてコンポーネント化したものを作ってから始めてください。

### 1. 現状の名前を確認する

1. レイヤーパネルでカードのコンポーネントを展開する
2. Ellipse 1 や Frame 3 のような自動の名前が並んでいるのを確認する

### 2. 役割ベースの名前に付け直す

各レイヤーを選択して `Cmd + R`（Windowsは `Ctrl + R`）で、次のように付け直します。

| 対象 | 変更前の例 | 変更後 |
| --- | --- | --- |
| カード全体（コンポーネント） | Component 1 | `ProfileCard` |
| 正円 | Ellipse 1 | `avatar` |
| テキストの縦並びフレーム | Frame 3 | `user-info` |
| 名前のテキスト | 山田太郎 | `user-name` |
| 肩書きのテキスト | フロントエンドエンジニア | `user-title` |

バリアントを作ってある場合は、紫の破線枠（コンポーネントセット）を選択して `ProfileCard` に変えます。オンラインバッジの緑の正円があれば `online-badge` にします。

テキストレイヤーは、リネームすると「入力内容がそのまま名前になる」挙動が止まり、付けた名前が固定されます。中身を書き換えても役割の名前が残るので、テキストこそ付け直す価値があります。

### 3. 不要なレイヤーを掃除する

1. 非表示のレイヤーや空のフレームが残っていないか、レイヤーパネルを上から見る
2. あれば選択して `Delete` で消す

### 4. ビフォー/アフターを見比べる

リネーム後のレイヤーパネルを眺めて、「初めてこのファイルを開いた人が、レイヤーパネルだけでカードの構造を説明できるか」を自問してください。ProfileCardの中にavatarとuser-infoがあり、user-infoの中に名前と肩書きがある。そう読めたら合格です。4章からの本番制作では、この命名を作りながら最初から実践します。
