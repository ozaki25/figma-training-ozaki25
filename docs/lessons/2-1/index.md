# 2-1 シェイプとテキストを配置する

この章では、練習用の題材として「プロフィールカード」を作ります。図形とテキストを置き、並べ方を整え、少しずつ完成に近づけていきます。作るのは練習用のサンプルで、後半で作るタスク管理ツールには使いません。学ぶのは部品の作り方そのものです。

このレッスンでは、まずカードの部品をキャンバスに置くところまでやります。

## 図形を描く

下部ツールバーの四角形アイコンがシェイプツールです。長押しすると楕円や直線などに切り替えられますが、ショートカットの方が速いです。

| 図形 | ショートカット |
| --- | --- |
| 四角形 | `R` |
| 楕円 | `O` |

ツールを選んだら、キャンバス上でドラッグすると描けます。このとき `Shift` を押しながらドラッグすると縦横比が固定され、四角形なら正方形、楕円なら正円になります。CSSで `aspect-ratio: 1` を指定するのと同じ効果を、ドラッグ中のキー1つで得られます。

## 角丸と塗りを変える

描いた図形を選択すると、右サイドバーで見た目を変えられます。

- **角丸**は「Appearance」セクションの Corner radius に数値を入れる。CSSの `border-radius` にあたる
- **塗り**は「Fill」セクションの色スウォッチをクリックし、カラーピッカーで選ぶ。CSSの `background-color` にあたる

角丸の入力欄は選択している対象によって表示位置が少し変わることがあります。見つからないときは Appearance セクションの中を探してください。

## テキストを置く

1. `T` キーを押す（ツールバーのテキストツールでも同じ）
2. キャンバスをクリックして、そのまま文字を入力する
3. `Esc` で入力を終える

テキストを選択すると、右サイドバーの「Typography」セクションでフォント・サイズ・ウェイトを変えられます。ウェイトはフォント名の下のドロップダウンで Regular や Bold を選ぶ方式です。

## レイヤーの重なり順

図形やテキストは、後から描いたものが手前に重なります。重なり順は左サイドバーのレイヤー一覧に対応していて、一覧の上にあるものほど手前です。

順番を変えたいときは、左サイドバーでレイヤーをドラッグして並べ替えます。ショートカットなら `Cmd + ]`（Windowsは `Ctrl + ]`）で前面へ、`Cmd + [`（`Ctrl + [`）で背面へ動かせます。HTMLの `z-index` を並び順で管理している、と考えると分かりやすいです。

## 演習: プロフィールカードの部品を並べる

ここまでの操作を使って、プロフィールカードの部品を1つのフレームに置きます。完成イメージはこうです。

![プロフィールカードの完成イメージ。角丸の白いカードの中に、紫の正円のアバター、太字の名前、小さめの肩書きが縦に並んでいる](/lessons/2-1/profile-card-parts.svg)

1. `F` キーでフレームツールを選び、キャンバスをドラッグして400×300くらいのフレームを作る
2. `R` キーで四角形を描き、カードの下地にする。フレームより少し小さいサイズにして、Corner radius を 16、Fill を白にする
3. `O` キーで `Shift` を押しながらドラッグし、正円を1つ描く。アバター画像を置くつもりの円なので、80×80くらいにして好きな色を付ける
4. `T` キーで名前のテキストを置く（例: 山田太郎）。サイズ 16、ウェイトを Bold にする
5. もう1つテキストを置いて肩書きにする（例: フロントエンドエンジニア）。サイズは 12 のままでよい
6. 円と2つのテキストが下地の四角形より手前にあるか、左サイドバーで重なり順を確認する。隠れていたら並べ替える

位置は目分量で構いません。きれいな整列はこの後のレッスンで、自動で並べる方法と合わせて扱います。今は「部品が全部フレームの中にある」ことだけ確認できれば十分です。
