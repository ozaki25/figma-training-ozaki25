# 2-1 シェイプとテキストを配置する

この章では、練習用の題材として「プロフィールカード」を作ります。図形とテキストを置き、並べ方を整え、少しずつ完成に近づけていきます。作るのは操作に慣れるための練習用サンプルで、このあとの実践で作る画面には使いません。学ぶのは部品の作り方そのものです。

このレッスンでは、まずカードの部品をキャンバスに置くところまでやります。

## 図形を描く

下部ツールバーの四角形アイコンがシェイプツールです。長押しすると楕円や直線などに切り替えられますが、ショートカットの方が速いです。

| 図形 | ショートカット |
| --- | --- |
| 四角形 | `r` |
| 楕円 | `o` |

ツールを選んだら、キャンバス上でドラッグすると描けます。このとき `Shift` を押しながらドラッグすると縦横比が固定され、四角形なら正方形、楕円なら正円になります。

## 角丸と塗りを変える

描いた図形を選択すると、右サイドバーで見た目を変えられます。

- **角丸**は「外見」セクションの「角の半径」に数値を入れる。CSSの `border-radius` にあたる
- **塗り**は「塗り」セクションの色の四角（スウォッチ。塗り色を表す小さな四角）をクリックし、開いたカラーピッカーで選ぶ。CSSの `background-color` にあたる

角丸の入力欄は選択している対象によって表示位置が少し変わることがあります。見つからないときは「外見」セクションの中を探してください。

## テキストを置く

1. `t` キーを押す（ツールバーのテキストツールでも同じ）
2. キャンバスをクリックして、そのまま文字を入力する
3. `Esc` で入力を終える

テキストを選択すると、右サイドバーの「タイポグラフィ」セクションでフォント・サイズ・ウェイトを変えられます。ウェイトはフォント名の下のドロップダウンで Regular や Bold を選ぶ方式です。

## レイヤーの重なり順

図形やテキストは、後から描いたものが手前に重なります。重なり順は左サイドバーのレイヤー一覧に対応していて、一覧の上にあるものほど手前です。

順番を変えたいときは、左サイドバーでレイヤーをドラッグして並べ替えます。ショートカットなら `Cmd + ]`（Windowsは `Ctrl + ]`）で前面へ、`Cmd + [`（`Ctrl + [`）で背面へ動かせます。

## 演習: プロフィールカードの部品を並べる

ここまでの操作を使って、プロフィールカードの部品を1つのフレームに置きます。完成イメージはこうです。

![プロフィールカードの完成イメージ。グレーの下地フレームの上に角丸の白いカードがあり、紫の正円のアバターの右に太字の名前と小さめの肩書きが並んでいる](/lessons/2-1/profile-card-parts.png)

1. `f` キーでフレームツールを選び、キャンバスをドラッグして400×300くらいのフレームを作る。フレームの「塗り」をグレー（`#E0E0E0`）にする。この上に白いカードを置くので下地を白のままにすると見分けがつかなくなる。キャンバスの背景がライトモードの既定値（`#F5F5F5`）のままだと、フレームをそれと同じ色にしてもキャンバスに溶けて境界が見えなくなるので、少し濃いめのグレーにする
2. `r` キーで四角形を描き、カードの下地にする。フレームより少し小さいサイズにして、「角の半径」を 16、「塗り」を白（`#FFFFFF`）にする
3. `o` キーで `Shift` を押しながらドラッグし、正円を1つ描く。アバター画像を置くつもりの円なので、80×80くらいにして好きな色を付ける（顔写真などを入れたい場合は、円を選んだ状態で画像ファイルを右サイドバーの「塗り」にドラッグ＆ドロップすると、円の中に画像が敷き込まれる）
4. `t` キーを押し、キャンバスを**クリックして**名前のテキストを入力する（例: 山田太郎）。サイズ 16、ウェイトを Bold にする。ドラッグで箱を描いてから入力すると幅が固定になり、文字が箱の幅で折り返されるようになる。この教材ではテキストは常にクリックで作る
5. もう1つテキストを置いて肩書きにする（例: フロントエンドエンジニア）。サイズを 12 にする
6. 円と2つのテキストが下地の四角形より手前にあるか、左サイドバーで重なり順を確認する。隠れていたら並べ替える

位置は目分量で構いません。きれいな整列はこの後のレッスンで、自動で並べる方法と合わせて扱います。今は「部品が全部フレームの中にある」ことだけ確認できれば十分です。
