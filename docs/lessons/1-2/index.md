# 1-2 フレームを作って操作する

Figmaでは、デザインする画面1枚ごとに「フレーム」という土台を作ります。Webページのデザインならフレームがブラウザの表示領域、つまりviewportやbodyにあたります。この中に部品を置いていくのが基本の流れです。

## フレームと四角形の違い

どちらもキャンバス上では四角く見えますが、役割が違います。

![フレームと四角形の違い。フレームは中に要素を入れる土台で名前が付く。四角形はただの図形](/lessons/1-2/frame-vs-rectangle.svg)

- フレームは中に他の要素を入れられる「入れ物」。HTMLでいうコンテナ要素に近く、左上に名前が表示されます
- 四角形（Rectangle）はただの図形。ボタンの下地など、部品の一部として使います

画面を作り始めるときはフレーム、と覚えておけば十分です。

## フレームを作る

1. `F` キーを押す（下部ツールバーのフレームツールでも同じ）
2. 右サイドバーにプリセットサイズの一覧が表示される
3. 「Desktop」を開いて選ぶと、1440×1024のフレームがキャンバスに置かれる

プリセットにはPhone・Tablet・Desktopなどのカテゴリがあり、iPhoneの各機種といった実際のデバイスサイズが並んでいます。プリセットを使わず、`F` キーのあとキャンバスをドラッグして好きなサイズで描くこともできます。

## キャンバスを動き回る

キャンバスは事実上無限に広く、フレームが増えると1画面に収まらなくなります。移動と拡大縮小の操作は今後ずっと使うので、ここで手に馴染ませておきます。

| 操作 | やり方 |
| --- | --- |
| パン（表示位置の移動） | `Space` を押しながらドラッグ |
| ズーム | `Cmd`（Windowsは `Ctrl`）を押しながらスクロール |
| 全体を表示 | `Shift + 1` |
| 選択中の要素にズーム | `Shift + 2` |
| 100%表示に戻す | `Shift + 0` |

迷子になったら `Shift + 1`。これだけ覚えておけば、キャンバスのどこにいても全体が見える位置に戻れます。

## ページを切り替える

1つのファイルの中に、キャンバスを複数枚持てます。これが「ページ」です。本番のデザインと練習用の下書きを分ける、といった使い方をします。

- 左サイドバー上部にあるページ名をクリックすると、ページの一覧が開く
- 一覧の「+」で新しいページを追加できる
- ページ名を右クリックして「Rename」を選ぶと名前を変えられる

ページを切り替えるとキャンバスが丸ごと入れ替わりますが、レイヤーが消えたわけではありません。元のページに戻れば、そのまま残っています。

## 演習: フレーム2つとページ1枚

1. `F` キーを押し、右サイドバーのプリセットから「Desktop」を選んでフレームを1つ置く
2. もう一度 `F` キーを押し、Phoneカテゴリから好きなiPhoneを選んで2つ目のフレームを置く
3. `Cmd/Ctrl + スクロール` でズームし、`Space + ドラッグ` で2つのフレームを行き来する
4. `Shift + 1` で全体表示に戻り、2つのフレームが並んでいるのを確認する
5. 左サイドバーのページ名をクリックし、「+」でページを1枚追加して切り替えてみる

追加したページは空のキャンバスになります。元のページに戻って、フレーム2つが残っていることも確認してください。
