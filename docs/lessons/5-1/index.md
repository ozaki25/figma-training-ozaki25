# 5-1 フォームのレイアウトを組む

ここからは2画面目、タスク登録フォームを作ります。4章のタスク一覧画面と同じトンマナ、同じスタイルでそろえます。

手順は4章と同じです。フレームで骨組みを作り、Auto LayoutとFill/Hugで並べ、4-3で登録した色スタイル・テキストスタイルをそのまま当てます。

このレッスンで作るのは画面の骨組みと、入力欄を入れる「器」までです。入力欄やボタンそのものは5-2で作るので、いまは仮のプレースホルダーだけ置きます。

4章と同じく、操作は1つずつ書きません。仕様（サイズ・間隔）を示すので、これまで練習した手順で組み立ててください。

## 完成イメージ

![タスク登録フォーム画面の骨組みの見取り図。task-formフレームの上部に4章と同じheader、その下に薄グレーのcontentエリアがあり、中央に白いform-cardが置かれる。カードの中に見出しの新しいタスクと、入力欄のプレースホルダー3つ、下部に登録ボタンのプレースホルダーが縦に並ぶ](/lessons/5-1/task-form-skeleton.svg)

構造は3階層です。contentの中にカードが1枚入るのが、一覧画面との違いです。

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `task-form` | 画面全体 | Desktop 1440×1024、縦Auto Layout、gap 0 |
| `header` | 上部バー | 幅Fill・高さFixed 64、横Auto Layout、左右padding 24、背景 `surface` |
| `content` | 残りの領域 | 幅Fill・高さFill、縦Auto Layout、padding 32、gap 24、整列は上中央、背景 `bg` |
| `form-card` | 入力欄の器 | 幅Fixed 480・縦Auto Layout、padding 32、gap 20、角丸12、背景 `surface` |

ヘッダーは4章のtask-listとまったく同じ構成です。左にアプリ名、右にアイコンを間隔Autoで両端に振り分け、高さはFixed 64、幅はFillにします。一覧画面のヘッダーをそのまま作り直すつもりで組めば、2画面のトンマナが自然にそろいます。

## フォームカードを中央に置く

一覧画面ではcontentの中身を上から順に縦に積むだけでした。フォームでは、入力欄をまとめた`form-card`を画面の横幅の中央に置きます。中央寄せは2つの設定の組み合わせでできます。

- `form-card` の幅を **Fixed 480** にする。Fillだとcontentの幅いっぱいに広がってしまうので、固定幅にして「広がらない」状態を作る
- 親の `content`（縦Auto Layout）の整列を **上・中央** にする。整列ボックス（9マス）の上段中央を選ぶと、中身が横方向は中央、縦方向は上から並ぶ

子の幅をFixedで止めて広がらないようにし、親の整列で中央に寄せます。この2つの設定を組み合わせるのが、Auto Layoutで横中央寄せをするときの基本パターンです。

## 作る順序

4章と同じく、外側から内側へ作ります。入れ物を先に決めてから中身を足すと、置いた要素が自動で正しい位置に収まります。

1. 画面フレーム `task-form` を作り、縦のAuto Layoutにする
2. ヘッダーを作って上に入れる（4章のtask-listと同じ構成）
3. コンテンツエリアを作り、整列を上中央にする
4. フォームカードをcontentの中に置き、中央に寄るのを確認する
5. カードの中に見出しとプレースホルダーを置く

レイヤー名は作ったその場で3-3の規約どおりに付けます。部品はkebab-case、コンポーネントはPascalCaseです（このレッスンではコンポーネントはまだ出てきません）。

## 演習: フォームの骨組みを組み立てる

### 1. 画面フレームとヘッダーを作る

1. 新しいデザインファイルを作り、`F` でフレームツールから **Desktop（1440×1024）** を作る
2. `Shift + A` で縦のAuto Layout、gap・パディングを 0 にし、名前を `task-form` にする
3. ヘッダーを4章のtask-listと同じ構成で作る: テキスト `My Tasks`（18px、SemiBold程度）と正円 32×32 を横Auto Layout（`Shift + A`）でまとめ、`task-form` の上に入れる
4. ヘッダーを仕様どおりに設定する: 幅 **Fill**・高さ **Fixed 64**、間隔 **Auto**、左右padding 24、整列は上下中央、背景は白
5. 名前を付ける: フレームは `header`、テキストは `app-title`、アイコンは `user-icon`（4章のtask-listと同じ名前）

ヘッダーは一覧画面と見た目をそろえたいので、4-3で登録した色スタイル `surface` を背景に、テキストスタイル `app-title` を文字に当てておきます。同じスタイルを使えば、色や文字が2画面でぴったり一致します。

### 2. コンテンツエリアを作る

1. キャンバスで `Shift + A` で空のAuto Layoutフレームを作り、`task-form` の中、`header` の下へ入れる
2. 仕様どおりに設定する: 幅 **Fill**・高さ **Fill**、フロー縦、gap 24、パディング 32、背景 `bg`
3. 整列ボックス（9マス）で **上段の中央** を選ぶ
4. 名前を `content` にする

背景の `bg` は4-3で登録した薄グレーのスタイルです。ここでも既存スタイルを当てれば、一覧画面と地色がそろいます。

### 3. フォームカードを置く

1. `content` の中に `Shift + A` で空のAuto Layoutフレームを作る
2. 仕様どおりに設定する: 幅 **Fixed 480**・高さ **Hug**、フロー縦、gap 20、パディング 32、角丸 12、背景 `surface`
3. 名前を `form-card` にする

幅をFixed 480にした瞬間、カードが広がるのをやめ、`content` の整列（上中央）に従って画面の横中央に収まります。カードが左に寄ったままなら、`content` の整列が中央になっているか確認してください。

### 4. カードの中身をプレースホルダーで埋める

入力欄とボタンは5-2で作るので、いまは器の中に仮の要素を置いて骨組みを確かめます。

1. カードの中にテキスト `新しいタスク` を作り、名前を `form-title`、テキストスタイル `page-title` を当てる
2. その下に `R` で四角形を2〜3個作る: 高さ 44、角丸 8、白、グレー `#D9D9E0` の枠線。幅を **Fill** にして、名前を `input-placeholder` にする
3. いちばん下に四角形をもう1つ作る: 高さ 44、角丸 8、`brand`（紫）で塗る。幅 **Fill**、名前を `button-placeholder` にする

カードの中で、見出し・入力欄の枠・ボタンの枠がgap 20で縦に並び、幅はカードいっぱいにそろうはずです。

最後に `task-form` 全体の高さをドラッグで変えてみてください。ヘッダーは64のまま動かず、contentが伸縮し、カードは常に横中央にとどまれば骨組みは完成です。

## ゴール確認

- [ ] `task-form` の中に `header`（4章と同じ構成）と `content` が縦に並び、名前を規約どおり付けられた
- [ ] `form-card` を幅Fixed 480、contentの整列を上中央にして、カードを画面の横中央に置けた
- [ ] 見出しとプレースホルダーがカードの中で縦に並び、`bg`・`surface`・`page-title` など既存スタイルを再利用できた
