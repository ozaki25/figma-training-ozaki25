# 5-3 仕上げ・一貫性チェック

5章の最後は、4章のタスク一覧と5章のタスク登録フォームを並べて見比べる作業です。1つの画面としては整っていても、2つ並べたときに初めて気づくズレがあります。

たとえばサイドバーの幅がずれていたり、ヘッダーの高さが違ったり、余白が微妙に狭かったりします。こういった小さなズレを目で見つけ、トークンやスタイルの当て直しで直します。

## キャンバスに2画面を並べる

Figmaのキャンバスは事実上無限に広いので、画面フレームを横に並べて置けます。task-listの右側にtask-formを移動して、`Shift + 1`（Mac/Windows共通）で全体表示にすると、2画面を一度に見渡せます。

![task-listとtask-formを横並びに置いたキャンバス俯瞰図。両画面の左に同じsidebarがあり、上に同じheaderが乗っている](/lessons/5-3/two-screens-side-by-side.png)

`Shift + 2`（Mac/Windows共通）は選択範囲にズームなので、片方の画面だけをじっくり見たいときはそちらを使い、俯瞰したいときは `Shift + 1` に戻ります。

## 一貫性のチェックポイント

次の5観点を上から順に見比べて、どちらか一方だけがズレていないかを確認します。

| 観点 | 見るところ |
| --- | --- |
| サイドバー | 幅240・背景 `surface`・NavItemの並び。activeが一覧は `今日`、フォームは `受信箱` になっているか、オフにし忘れて両方アクティブの項目がないか |
| ヘッダー | 高さ64・背景 `surface`・`app-title` の位置とサイズが2画面で同じか |
| 色 | `bg`・`surface`・`brand`・`border`・`bg-active` を使っているところがトークン経由か、直接カラーコードを指定してしまっていないか |
| タイポ | `page-title`・`card-title`・`section-title`・`body`・`caption` にあたる文字が、それぞれ同じテキストスタイルを使っているか |
| 余白・角丸 | TaskCardの `radius/12` と `space/16`、form-cardの `radius/16`・`space/32`・`space/20` が、それぞれ仕様どおりトークンで当たっているか |

ズレを見つけたら、次のどれかでその場で直します。

- 色や文字にトークン・スタイルが当たっていないなら、4-2でやった3つの当て方（4点アイコン・「⌄」・六角形アイコン）で当て直す
- 余白や角丸が生の数値になっているなら、対応する `space/*`・`radius/*` トークンに置き換える
- 部品の見た目がズレているなら、インスタンスに上書きした箇所を原本と同じ値に戻す

## レイヤー名の最終チェック

見た目が揃ったら、レイヤーパネルの中身も整理します。ここで整えた状態がそのまま6章のコード生成に渡ります。

- 3-3で決めた規約（部品はkebab-case、コンポーネントはPascalCase）どおりの名前になっているか
- 作業の途中で残った `Frame 12` や `Rectangle 5` のような自動命名がないか
- 使っていない空フレームや隠しレイヤーが残っていないか

複数のレイヤーを一括で直したいときは、レイヤーパネルで対象を選んで `Cmd + R`（Windowsは `Ctrl + R`）を押すと一括リネームのダイアログが開きます。使っていない要素は選んで `Delete` で消します。

レイヤー名にここまでこだわる効果は、6章でコード生成をしたときに一気に見えます。いまは「レイヤー名と構造をきれいにしておくと生成コードの品質に直結する」とだけ覚えておいてください。

## 演習: 2画面を並べて仕上げる

### 1. 2画面を並べる

1. `task-list` フレームと `task-form` フレームを、キャンバス上で横に並べて置く
2. `Shift + 1` で全体表示にする。両方の画面が視野に収まる状態にする

### 2. 5つの観点でズレを探して直す

1. 上の表の5観点を上から順に見比べる
2. ズレを見つけたら、原因を「トークン未適用・数値違い・部品不一致」のどれかに切り分け、その場で直す
3. 途中で `Shift + 2` を使って片方の画面にズームし、細部を確認してもよい

とくにサイドバーは、5-1でNavItemの `active` トグルを `今日` から `受信箱` に付け替えました。`今日` のトグルをオフにし忘れて、両方がアクティブになっているケースが多いので重点的に見ます。

### 3. レイヤー名の整理と不要レイヤーの削除

1. レイヤーパネルを上から眺めて、自動命名のまま残っているものがないかを確認する
2. あれば `Cmd + R` で規約どおりに直す
3. 使っていない空フレーム・非表示のままのレイヤーを削除する

最後にもう一度 `Shift + 1` で全体表示にして、2画面の見た目がそろっているかを確かめます。これで5章の完成です。

## この章はここまで

5章で2画面のデザインが揃いました。同じサイドバー・ヘッダー・スタイルを再利用して別の画面に当てはめる流れを経験しました。次の6章では、Figma MCPとClaude Codeを使い、この2画面をコードに変換します。ここまでで整えたレイヤー名・スタイル・コンポーネントが、そのまま生成コードの品質に効いてきます。
