# 5-3 仕上げ・一貫性チェック

5章の最後は、4章のタスク一覧と5章のタスク登録フォームを並べて見比べる作業です。1つの画面としては整っていても、2つ並べたときに初めて気づくズレがあります。

たとえばサイドバーの幅がずれていたり、ヘッダーの高さが違ったり、余白が微妙に狭かったりします。こういった小さなズレを目で見つけ、既存スタイルの再適用や数値の統一で直します。

このレッスンでも操作は逐一書きません。使うのは全部これまで練習した手順です。

## キャンバスに2画面を並べる

Figmaのキャンバスは無限に広いので、画面フレームを横に並べて置けます。task-listの右側にtask-formを移動して、`Shift + 1`（Mac/Windows共通）で全体表示にすると、2画面を一度に見渡せます。

![task-listとtask-formを横並びに置いたキャンバス俯瞰図。両画面の左に同じsidebarがあり、上に同じheaderが乗っている。一貫性のチェックポイントを下部に凡例で示す](/lessons/5-3/two-screens-side-by-side.png)

`Shift + 2`（Mac/Windows共通）は選択範囲にズームなので、片方の画面だけをじっくり見たいときはそちらを使い、俯瞰したいときは `Shift + 1` に戻ります。

## 一貫性のチェックポイント

見比べる観点は5つです。上から順に、どちらか一方だけがズレていないかを確認します。

| 観点 | 見るところ |
| --- | --- |
| サイドバー | 幅240・背景 `surface`・nav-itemの並び。activeが2画面で違う項目（今日 / 受信箱）になっているか、逆に他のnav-itemまでずれていないか |
| ヘッダー | 高さ64・背景 `surface`・`app-title` の位置とサイズが2画面で同じか |
| 色 | `bg`・`surface`・`brand`・`border`・`bg-active` を使っているところがスタイル経由か、直接色を指定してしまっていないか |
| タイポ | `page-title`・`card-title`・`card-desc`・`card-due` にあたる文字が、それぞれ同じテキストスタイルを使っているか |
| 余白・角丸 | TaskCardの角丸12・form-cardの角丸16、カード内のpadding 32・gap 20 が正しくそろっているか |

ズレを見つけたら、その場で直します。直し方は3パターンだけ覚えておけば十分です。

- スタイルが当たっていないなら、右サイドバーの4点アイコンから既存スタイルを当て直す
- 数値が違うなら、Layout セクションで正しい値に上書きする
- 部品として揃えたいなら、片方をコンポーネントの原本に近い形に寄せる

## レイヤー名の最終チェック

見た目が揃ったら、レイヤーパネルの中身も整理します。ここで整えた状態がそのまま6章のコード生成に渡ります。

チェック項目は3つです。

- 3-3で決めた規約（部品はkebab-case、コンポーネントはPascalCase）どおりの名前になっているか
- 作業の途中で残った `Frame 12` や `Rectangle 5` のような自動命名がないか
- 使っていない空フレームや隠しレイヤーが残っていないか

複数のレイヤーを一括で直したいときは、レイヤーパネルで対象を選んで `Cmd + R`（Windowsは `Ctrl + R`）を押すと一括リネームのダイアログが開きます。使っていない要素は選んで `Delete` で消します。

レイヤー名にここまでこだわる効果は、6章でコード生成をしたときに一気に見えます。いまは「レイヤー名と構造をきれいにしておくと生成コードの品質に直結する」とだけ覚えておいてください。

## 演習: 2画面を並べて仕上げる

### 1. 2画面を並べる

1. `task-list` フレームと `task-form` フレームを、キャンバス上で横に並べて置く
2. `Shift + 1` で全体表示にする。両方の画面が視野に収まる状態にする

### 2. 5つの観点でズレを探して直す

1. 上の表の5観点を上から順に見比べる
2. ズレを見つけたら、原因を「スタイル未適用・数値違い・部品不一致」のどれかに切り分け、その場で直す
3. 途中で `Shift + 2` を使って片方の画面にズームし、細部を確認してもよい

とくにサイドバーは5-1で `task-list` からコピペした後にactiveを付け替えたので、その付け替えで他のnav-itemの背景を戻し忘れているケースが多いです。ここは重点的に見ます。

### 3. レイヤー名の整理と不要レイヤーの削除

1. レイヤーパネルを上から眺めて、自動命名のまま残っているものがないかを確認する
2. あれば `Cmd + R` で規約どおりに直す
3. 使っていない空フレーム・非表示のままのレイヤーを削除する

最後にもう一度 `Shift + 1` で全体表示にして、2画面のトンマナがそろって見えるかを確かめます。これで5章の完成です。

## この章はここまで

5章で2画面のデザインが揃いました。同じサイドバー・ヘッダー・スタイルを再利用して別の画面に当てはめる流れを経験しました。次の6章では、Figma MCPとClaude Codeを使い、この2画面をコードに変換します。ここまでで整えたレイヤー名・スタイル・コンポーネントが、そのまま生成コードの品質に効いてきます。
