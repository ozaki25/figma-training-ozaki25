# 1-1 画面構成を知る

Figmaでデザインファイルを開くと、中央の広い作業スペースを囲むようにパネルが並んでいます。最初にそれぞれの役割をつかんでおくと、この先のレッスンで迷わなくなります。

![Figmaエディタの画面構成。中央にキャンバス、左右にサイドバー、下部にツールバーがある](/lessons/1-1/figma-editor-layout.svg)

## 4つのエリアの役割

| エリア | 場所 | 何をするときに見るか |
| --- | --- | --- |
| キャンバス | 中央 | デザインを描く。作業はすべてここで起きる |
| ツールバー | 下部の中央 | フレーム・図形・テキストなど、新しい要素を作るとき |
| 左サイドバー | 左 | ファイル内の全要素（レイヤー）の一覧を確認するとき |
| 右サイドバー | 右 | 選択した要素のサイズや色を確認・変更するとき |

エンジニア向けに言い換えると、こう対応します。

- 左サイドバーはDOMツリー。キャンバス上のすべての要素が階層構造で並び、「レイヤー」と呼ばれます
- 右サイドバーはブラウザ開発者ツールのStylesペイン。選択した要素のプロパティ（width、色、角丸など）を表示・編集します
- キャンバスはレンダリング結果の画面そのものです。ただし見るだけでなく、直接ドラッグして編集できます

ツールバーが画面下部にあるのは2024年のデザイン刷新以降の配置です。古い解説記事では上部にありますが、現在は下部の中央です。

なお、画面の最左端に細い縦バー（ナビゲーションバー）が表示されることがあります。2026年から順次導入されている新しいUIで、レイヤーやアセットの表示切り替えの入口がまとまっています。表示されていてもいなくても、このハンズオンの進行には影響ありません。

## 演習: 四角形を1つ置いて観察する

実際に触って、各エリアの動きを確かめます。

1. Figmaのホーム画面右上の「+ 作成」から「デザイン」を選び、新しいデザインファイルを開く
2. 下部のツールバーから四角形ツールを選ぶ（ショートカットは `R`）
3. キャンバスの好きな場所でドラッグして、四角形を1つ描く

描けたら、次の2点を観察してください。

- **左サイドバー**に「Rectangle 1」という行が現れる。これがいま描いた四角形のレイヤーで、名前をダブルクリックすると変更できる
- **右サイドバー**に四角形のプロパティが表示される。X・Yは位置、W・Hはサイズで、数値を書き換えると四角形が即座に変わる

最後に、右サイドバーのFill（塗り）にある色の四角をクリックして、好きな色に変えてみましょう。CSSで `background-color` を変えるのと同じ操作を、GUIでやっていることになります。

キャンバスの何もない場所をクリックすると選択が外れ、右サイドバーの表示がファイル全体の情報に切り替わります。右サイドバーは「いま選択しているもの」に応じて中身が変わる、と覚えておいてください。
