# 4-5 一覧画面を仕上げて完成させる

4-4で統計カード・フィルタ・ナビ項目までできました。ここではサイドバーにロゴとアカウント表示を足し、タスクを3セクションに分け、完了状態をバリアントにして、タスク一覧画面を完成させます。

## 完成イメージ

![仕上げ後のタスク一覧画面。左は装飾済みsidebar（ロゴ、nav-item 5個、下端にユーザーブロック）、右はheaderとcontent。contentには見出し、統計カード3枚、フィルタチップ4個、3セクションに合計5枚のTaskCardが並ぶ。1枚は完了状態](/lessons/4-5/task-list-final.png)

## 演習

### 1. ロゴとユーザーブロックでサイドバーを仕上げる

1. サイドバー上部をロゴの形にする
   1. アイコン代わりに、`r` で 24×24 の正方形（塗り `brand`、角丸 `radius/8`）を作る
   2. 正方形を `sidebar` の中、`app-brand` の上へ入れる
   3. 正方形と `app-brand` を選択して `Shift + A` で横のオートレイアウトにして、名前を `logo` にする
   4. 間隔 `space/8`、配置は左中央にする
2. サイドバー下端のアカウント表示 `user-block` を作る
   1. `t` を押してクリックし、テキスト `Taro Yamada`（テキストスタイル `body`、色 `text/main`）と `Designer`（テキストスタイル `caption`、色 `text/sub`）を1つずつ作る
   2. 2つを選択して `Shift + A` で縦のオートレイアウトにして、間隔 0 にする
   3. `o` で 24×24 の正円（塗り `placeholder`）を作り、正円と縦積みの2つを選択してもう一度 `Shift + A` で横のオートレイアウトにする
   4. パディング `space/8`、間隔 `space/8`、配置は左中央にする
   5. 名前を `user-block` にして、サイドバーの一番下に入れ、幅を**拡大**にする
3. `NavItem` の5個と `user-block` の間に、空のフレームを1つ入れる
   1. `f` で小さなフレームを描き、`Shift + A` でオートレイアウトにする（中身のない唯一の部品なので、ここだけは空のフレームを直接作る）
   2. 名前を `spacer` にして、サイドバーの中、`user-block` の上へ入れる
4. `spacer` の幅・高さとも**拡大**にする
   - 余った縦スペースを `spacer` が吸収して、`user-block` が下端へ押し出される。オートレイアウトでは特定の1か所だけ間隔を空けられないので、空のフレームで間を空ける

### 2. セクション分けとTaskCardを5枚に増やす

いまcontentにあるTaskCardのインスタンス3枚を「今日」のセクションに入れ、「今週」と「あとで」のセクションを1枚ずつ足して合計5枚にします。既存の3枚は4-3で書き換えたままでよく、新しく書き換えるのは次の2枚です。

| セクション | 優先度 | タイトル | 説明 | カテゴリ | 担当 | 期限 |
| --- | --- | --- | --- | --- | --- | --- |
| 今週 | low | 依存ライブラリ更新 | patch差分のみ | 開発 | HK | 木曜 |
| あとで | high | 本番デプロイ手順の見直し | 手順書v3化 | 運用 | TY | 来週 |

1. `t` を押してクリックし、セクション見出しのテキスト `今日`（テキストスタイル `section-title`、色 `text/sub`）を作り、`Shift + A` で縦のオートレイアウトにする。このフレームが1つ目のセクションになる
2. 間隔 `space/12`、パディング 0 にして、名前を `section-today` にする
3. `content` の中、`filter-bar` の下へ入れ、幅は拡大、高さは内包にする
4. `Cmd + D` で3個にし、増えた2個の名前を `section-week`・`section-later` に、見出しを `今週`・`あとで` に書き換える
5. 既存のTaskCard 3枚を `section-today` の中へ移動する
6. `section-today` のカードを1枚選んで `Cmd + D` で複製し、`section-week` へ1枚、`section-later` へ1枚移す。複製なら幅の拡大がそのまま引き継がれる
7. 表のとおりに2枚のテキストを書き換え、`PriorityTag` の `priority` をドロップダウンで切り替える

レイヤーパネルで、各セクションの中が「見出し → TaskCard×枚数」の縦並びになっていれば正解です（例: `section-today` の中は `今日`・TaskCard・TaskCard・TaskCard）。

### 3. 完了状態をdoneバリアントにする

完了は「タスクカードのもうひとつの状態」なので、これもバリアントにします。

1. 画面の外にある `TaskCard` の原本を選択し、「バリアントの追加」をクリックする
2. 「現在のバリアント」で `プロパティ1` を `done` に、1枚目の値を `false`、2枚目を `true` にする
3. `true` の方を完了の見た目にする
   1. `checkbox` の塗りを `brand` にする
   2. `task-title` の色を `text/sub` にして、「タイポグラフィ」の詳細設定（`⋯`）を開き、装飾で打ち消し線を付ける
4. 画面に戻り、好きなTaskCardのインスタンスを1枚選んで、`done` トグルをオンにする

これでタスク一覧画面は完成です。優先度も完了も、色の上書きではなくプロパティの切り替えで表現できるようになりました。
