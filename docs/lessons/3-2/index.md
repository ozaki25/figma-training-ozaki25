# 3-2 コンポーネントとバリアントを作る

スタイル化まで済ませたプロフィールカード（正円・名前・肩書き、幅は固定320）を、今度は「使い回せる部品」にします。同じカードを10人分並べたいとき、コピーを10個置くだけだと、デザイン変更のたびに10個を直すことになります。それを解決するのがコンポーネントです。

## コンポーネントの仕組み

コンポーネントは、部品の原本を1つ登録して、複製を配る仕組みです。

- **メインコンポーネント**: 原本。デザインを編集できるのはここだけ
- **インスタンス**: 原本から作った複製。原本を変えると全部に反映される

Reactを書いたことがあれば、`ProfileCard` コンポーネントを1回定義して `<ProfileCard />` を何度も呼び出す、あの関係そのままです。関数の定義と呼び出しと言い換えてもかまいません。

レイヤーパネルでは、メインコンポーネントはひし形4つの紫アイコン、インスタンスは輪郭だけのひし形1つの紫アイコンで表示されます。キャンバス上でも紫の枠が付くので、普通のフレームと見分けられます。

## インスタンスの上書き

原本を変えると、その変更が全インスタンスに反映されます。

一方、インスタンス側でも、テキストや色は個別に変更できます。これを上書き（override）と呼びます。名前だけ差し替えた10人分のカード、という使い方ができます。Reactでpropsを渡して表示を変えるのに似ています。

上書きできるのは中身の値だけで、レイヤーを増やしたり消したりといった構造の変更はインスタンス側ではできません。構造を変えたいときはメインコンポーネントを編集します。まぎらわしい挙動があるので注意してください。

- インスタンスの中のレイヤーを `Delete` で消すと、消えたように見えますが実際は**非表示**になっただけです。レイヤーパネルの目のアイコンで戻せます
- 右クリックメニューの「インスタンスの切り離し」（`Option + Cmd + B`）を実行すると、コンポーネントとのつながりが切れて普通のフレームになります。何でも編集できるようになった代わりに、原本の変更が届かなくなります

インスタンスなのに「構造も変えられた」ように見えたときは、たいていこのどちらかが起きています。

## バリアント

1つのコンポーネントに複数の状態を持たせたいことがあります。ボタンの通常時とホバー時、カードのオンライン表示あり・なし、といった場合です。状態ごとに別コンポーネントを作るのではなく、1つのコンポーネントの中の切り替え可能な状態として持たせる仕組みがバリアントです。

バリアントを追加すると、同じ見た目のカードが複製され、2つが紫の破線枠にまとまります。これをコンポーネントセットと呼びます。

切り替えの単位はプロパティ名と値の組です。「何が切り替わるのか」が分かる名前を付けます。オンライン表示の有無なら、プロパティ名を `online`、値を `true` と `false` にする、という具合です。

インスタンス側では、右サイドバーにこのプロパティが表示され、切り替えるとインスタンスの見た目がそのバリアントに入れ替わります。切り替えのUIは値の付け方で変わり、値が `true` / `false` だと**トグルスイッチ**、それ以外の値（3種類以上や任意の文字列）だと**ドロップダウン**になります。propsの型に合わせて入力欄の見た目が変わるのと似ています。

## 演習: プロフィールカードをコンポーネント化する

3-1まで使ってきたカードで進めます。インスタンスを並べる場所が要るので、カードをグレーの下地フレームの外へ出しておきます。

演習を通すと、次のオンライン表示ありとなしを切り替えられるカードになります。

![オンライン表示のバリアント2種。左はバッジなしのカード、右はアバターの右下に緑の丸が付いたカード。どちらも紫の正円と名前・肩書きが並ぶ](/lessons/3-2/profile-card-variants.png)

レイヤーパネルの中身はこうなります。緑のバッジはカードの直下ではなく、アバターの正円を包むフレームの中に入ります。

```
コンポーネントセット（紫の破線枠）
├─ false
│  ├─ アバターを包むフレーム
│  │  └─ アバターの正円
│  └─ 名前と肩書きの縦積み
└─ true
   ├─ アバターを包むフレーム
   │  ├─ アバターの正円
   │  └─ 緑の正円（バッジ）
   └─ 名前と肩書きの縦積み
```

レイヤー名は `Frame 5` や `Ellipse 2` のような自動の名前のままでよく、役割の名前を付けるのは3-3でやります。

### 1. コンポーネント化してインスタンスを2つ作る

1. カードのフレームを選択して `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）でコンポーネント化する
   - 選ぶのは2-2でオートレイアウト化した一番外のフレーム。グレーの下地フレームは含めない
   - 右クリック →「コンポーネントを作成」でも同じ
2. レイヤーパネルのアイコンがひし形4つに変わったのを確認する
3. `Cmd + D`（Windowsは `Ctrl + D`）を2回押して、インスタンスを2つ作り、少しずらして並べる
   - 左サイドバーの「アセット」パネルからキャンバスへドラッグしてもインスタンスを作れる

### 2. インスタンスを上書きする

1. 1つ目のインスタンスで、カードの中の名前のテキスト（山田太郎）をダブルクリックして、別の名前（例: 佐藤花子）に書き換える
2. 肩書きも別のもの（例: デザイナー）に変える
3. 2つ目のインスタンスも同じように書き換える

原本はそのままで、複製ごとに中身だけ差し替えられました。

### 3. 原本の変更が全部に反映されるのを確認する

1. メインコンポーネント（ひし形4つの方）を選択する
2. 「角の半径」を 16 から 32 に変えてみる
3. 2つのインスタンスの角丸も、触っていないのに変わるのを確認する
4. 確認できたら 16 に戻す

手順2で上書きした名前は、原本を変えても消えません。上書きは上書きとして残ります。

### 4. オンラインバッジ付きのバリアントを追加する

アバターの右下に緑の丸が付いた「オンライン中」の状態を、同じコンポーネントにもう1つ持たせます。インスタンス側でオンとオフを切り替えられるようにするのがゴールです。

1. バッジを入れるフレームを先に作る。メインコンポーネントの中でアバターの正円を選択し、`Shift + A` でオートレイアウトにして、パディングを 0 にする
2. メインコンポーネントを選択して、右サイドバー上部のひし形に矢印が刺さったアイコン（ホバーすると「バリアントの追加」と出ます）をクリックする
   - 紫の破線枠の中に同じカードが2枚並ぶ。作り替えるのは2枚目
3. 紫の破線枠の外の空いた場所に、`o` で 16×16 の正円を描き、塗りを `#0ACF83` にする（`Shift` を押しながらドラッグすると正円になる）
4. レイヤーパネルで緑の正円をドラッグして、2枚目のカードにある、アバターを入れたフレームの中へ入れる
   - キャンバス上でドラッグして入れようとすると、狙ったフレームの中に入らないことがある。レイヤーパネルで入れるほうが確実
   - このフレームもオートレイアウトなので、入れた正円はアバターの横に割り込んで並ぶ。位置は次の手順で直す

   ![バッジを入れた直後の状態。緑の丸がアバターの右下ではなく、アバターと名前のあいだに割り込んで並んでいる](/lessons/3-2/badge-inserted.png)

5. 緑の正円を選択したまま、右サイドバー「位置」セクション見出し右の四角いアイコン（ホバーすると「オートレイアウトを無視」と出ます）をクリックする
   - この要素だけ並びから外れて、フレームの中を自由に動かせるようになる
6. 緑の正円をアバターの右下に揃える
   1. レイヤーパネルで緑の正円をクリックし、`Shift` を押しながらアバターの正円もクリックして2つを選択する
   2. 右サイドバー「配置」の6アイコンから右揃え・下揃えをクリックする。緑の正円の右端と下端が、アバターの右端と下端に揃う
   3. 位置を微調整したいときはドラッグで動かす
7. 右サイドバーの「現在のバリアント」でプロパティ名と値を付け替える
   1. プロパティ名の `プロパティ1` を `online` にする
   2. 1枚目のカードをキャンバスで選び、値を `false` にする
   3. 2枚目のカードを選び、値を `true` にする。2枚とも選んだ状態では変えられないので、1枚ずつ選び直す
8. インスタンスを1つ選択すると、右サイドバーに `online` のトグルスイッチが現れる。オンに切り替えて、カードの見た目がバッジ付きに入れ替わるのを確認する
   - 値が `true` / `false` なのでスイッチになる

レイヤーパネルで見ると、紫の破線枠（コンポーネントセット）の下に `true` と `false` の2つが並んでいれば完成です（プロパティ名は表示されず、値だけが出ます）。

## ゴール確認

- [ ] カードをコンポーネント化し、インスタンスの名前・肩書きを上書きできた
- [ ] メインコンポーネントの変更が全インスタンスに反映されるのを確認できた
- [ ] バリアントを追加し、インスタンスのトグルスイッチで状態を切り替えられた
