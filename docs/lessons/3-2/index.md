# 3-2 コンポーネントとバリアントを作る

スタイル化まで済ませたプロフィールカード（正円・名前・肩書き、幅は固定320）を、今度は「使い回せる部品」にします。同じカードを10人分並べたいとき、コピーを10個置くだけだと、デザイン変更のたびに10個を直すことになります。それを解決するのがコンポーネントです。

## コンポーネントの仕組み

コンポーネントは、部品の原本を1つ登録して、複製を配る仕組みです。

- **メインコンポーネント**: 原本。デザインを編集できるのはここだけ
- **インスタンス**: 原本から作った複製。原本を変えると全部に反映される

Reactを書いたことがあれば、`ProfileCard` コンポーネントを1回定義して `<ProfileCard />` を何度も呼び出す、あの関係そのままです。関数の定義と呼び出しと言い換えてもかまいません。

レイヤーパネルでは、メインコンポーネントはひし形4つの紫アイコン、インスタンスは輪郭だけのひし形1つの紫アイコンで表示されます。キャンバス上でも紫の枠が付くので、普通のフレームと見分けられます。

## コンポーネント化の手順

1. 部品にしたい要素を選択する。このレッスンでは、これまで作ってきたカード全体、つまり2-2でオートレイアウト化した外側のフレーム（正円とテキストのグループを含む一番外のフレーム）を選ぶ。2-1で最初に作った練習用の土台フレーム（薄いグレーの400×300）は部品には含めない
2. 右クリック →「コンポーネントを作成」を選ぶ

ショートカットは `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）です。ツールバー中央にもコンポーネント作成ボタン（ひし形4つのアイコン）があります。

インスタンスの作り方は2通りです。

- メインコンポーネントを選択して `Cmd + D`（Windowsは `Ctrl + D`）で複製する。コピー&ペーストでも同じ
- 左サイドバーの「アセット」パネルを開き、コンポーネントをキャンバスへドラッグする

## インスタンスの上書き

原本を変えれば全インスタンスに反映される、が基本の流れです（演習3で確認します）。その逆方向として、インスタンスは原本と同じ見た目で生まれますが、テキストや色は個別に変更できます。これを上書き（override）と呼びます。名前だけ差し替えた10人分のカード、という使い方ができるわけです。Reactでpropsを渡して表示を変えるのに似ています。

上書きできるのは中身の値だけで、レイヤーを増やしたり消したりといった構造の変更はインスタンス側ではできません。構造を変えたいときはメインコンポーネントを編集します。紛らわしい挙動が2つあるので注意してください。

- インスタンスの中のレイヤーを `Delete` すると、消えたように見えますが実際は**非表示**になっただけです。レイヤーパネルの目のアイコンで戻せます
- 右クリックメニューにはインスタンスを切り離す項目（Detach instance）があり、実行するとコンポーネントとのつながりが切れて普通のフレームになります。何でも編集できるようになった代わりに、原本の変更が届かなくなります。「構造も変えられた」ように見えたときは、たいていこのどちらかが起きています

## バリアント

1つのコンポーネントに複数の状態を持たせたいことがあります。ボタンの通常時とホバー時、カードのオンライン表示あり・なし、といった場合です。状態ごとに別コンポーネントを作るのではなく、1つのコンポーネントの中の切り替え可能な状態として持たせる仕組みがバリアントです。

1. メインコンポーネントを選択する
2. 右サイドバー上部、ひし形に矢印が刺さったアイコン（ホバーすると「バリアントの追加」と出ます）をクリックする

同じ見た目のバリアントが複製され、2つが紫の破線枠にまとまります。これをコンポーネントセットと呼びます。

このとき右サイドバーの「現在のバリアント」に、`プロパティ1` という名前と `バリアント2` という値が自動でできます。名前も値も自由に変えられるので、「何が切り替わるのか」が分かる名前を付けます。オンライン表示の有無なら、プロパティ名を `online`、値を `true` と `false` にする、という具合です。

インスタンス側では、右サイドバーにこのプロパティが表示され、切り替えるとインスタンスの見た目がそのバリアントに入れ替わります。切り替えのUIは値の付け方で変わり、値が `true` / `false` だと**トグルスイッチ**、それ以外の値（3種類以上や任意の文字列）だと**ドロップダウン**になります。propsの型に合わせて入力UIが変わる、と考えるとエンジニアにはなじみやすいはずです。

## 演習: プロフィールカードをコンポーネント化する

3-1まで使ってきたカードで進めます。

### 1. コンポーネント化してインスタンスを2つ作る

1. カードのフレームを選択して `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）
2. レイヤーパネルのアイコンがひし形4つに変わったのを確認する
3. `Cmd + D`（Windowsは `Ctrl + D`）を2回押して、インスタンスを2つ作り、少しずらして並べる

### 2. インスタンスを上書きする

1. 1つ目のインスタンスの名前をダブルクリックして、別の名前（例: 佐藤花子）に書き換える
2. 肩書きも別のもの（例: デザイナー）に変える
3. 2つ目のインスタンスも同じように書き換える

原本はそのままで、複製ごとに中身だけ差し替えられました。

### 3. 原本の変更が全部に反映されるのを確認する

1. メインコンポーネント（ひし形4つの方）を選択する
2. 「角の半径」を 16 から 32 に変えてみる
3. 2つのインスタンスの角丸も、触っていないのに変わるのを確認する
4. 確認できたら 16 に戻す

手順2で上書きした名前は、原本を変えても消えません。上書きは上書きとして残ります。

### 4. バリアントを追加する

1. メインコンポーネントを選択して、右サイドバー上部のひし形に矢印が刺さったアイコン（ホバーすると「バリアントの追加」と出ます）をクリックする
2. 紫の破線枠の中に、同じカードが2枚並んだのを確認する
3. 2枚目のカードの正円の右下に、小さな緑の正円（例: 16×16、`#0ACF83`）を重ねて、オンラインバッジにする。オートレイアウトの中の要素はそのままだと横に並んでしまうので、緑の正円を選択し、右サイドバー「位置」セクション見出し右の四角いアイコン（ホバーすると「オートレイアウトを無視」と出ます）をクリックする。これでこの要素だけオートレイアウトの流れから外れて自由に動かせるようになる
4. アバターの正円と緑の正円の両方を選択し、右サイドバー「配置」の6アイコンから右揃え・下揃えをクリックする。緑の正円の右端・下端がアバターの右端・下端に揃い、右下の角にぴったり重なる。見た目を見て、少し内側に食い込ませたいならドラッグで微調整する
5. 右サイドバーの「現在のバリアント」で、`プロパティ1` を `online` に、1枚目・2枚目の値をそれぞれ `false`・`true` に変える。値を変えるときは、変えたいカード自身をキャンバスで選び直してから「現在のバリアント」の値を書き換える（2枚とも選んだまま両方は変えられない）
6. インスタンスを1つ選択すると、右サイドバーに `online` のトグルスイッチが現れる（値がtrue/falseなのでスイッチになる）。オンに切り替えて、カードの見た目がバッジ付きに入れ替わるのを確認する

レイヤーパネルで見ると、`カード`（コンポーネントセット）の下に `online=true` と `online=false` の2つが並んでいれば完成です。

## ゴール確認

- [ ] カードをコンポーネント化し、インスタンスの名前・肩書きを上書きできた
- [ ] メインコンポーネントの変更が全インスタンスに反映されるのを確認できた
- [ ] バリアントを追加し、インスタンスのトグルスイッチで状態を切り替えられた
