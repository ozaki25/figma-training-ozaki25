# 4-2 デザイントークンとスタイルを定義する

4-1で骨組みができました。カードや装飾を作り始める前に、この画面で使う色・余白・角丸・文字を、ぜんぶトークンとスタイルとして定義します。実務でも、部品を量産する前にこの土台を固めます。CSSでコンポーネントを書き始める前に `--color-brand` や `--spacing-4` を定義するのと同じ段取りです。

3-4で作ったコレクションを、ここで本番のトークン一式に育てます。色は3-4で練習した2層（プリミティブとセマンティック）、余白と角丸は数値バリアブル、文字はテキストスタイルで管理します。

コレクションは2つに分けます。`primitives` に色の値そのもの、`tokens` にセマンティックと数値を入れます。要素から参照するのは `tokens` だけです。

1つにまとめると、42個が名前順に交ざって並びます。色を当てるときのピッカーにもプリミティブが出てくるので、どれを使ってよいのか見分けがつきません。

このレッスンは定義の登録が中心で、同じ追加操作の繰り返しです。表を見ながら淡々と進めてください。

## 演習

### 1. 練習ぶんを片付ける

1. 左端のナビゲーションバーから「バリアブル」パネルを開き、練習用の `gray/700` を右クリックして「バリアブルを削除」を選ぶ。同じように `gray/400` も消す
2. `brand` も消す。セマンティックなので `tokens` に作り直す（プリミティブの `purple/500` は残す）
3. コレクション名 `コレクション1` をダブルクリックして、`primitives` にする

### 2. 色のプリミティブトークンを作る

値そのものに機械的な名前を付けた層です。`primitives` を開いた状態で、パネル最下部の「+ バリアブルを作成」から「色」を選び、次の色を追加します。`purple/500` は3-4で作成済みなので、残り13個です。

| 名前 | 値 |
| --- | --- |
| `purple/50` | `#F3EEFF` |
| `gray/50` | `#F5F5F5` |
| `gray/100` | `#EEEEEE` |
| `gray/200` | `#E5E5EA` |
| `gray/300` | `#D9D9E0` |
| `gray/500` | `#6E6E76` |
| `gray/600` | `#4B5563` |
| `gray/900` | `#2A2A31` |
| `white` | `#FFFFFF` |
| `red/100` | `#FEE2E2` |
| `red/700` | `#B91C1C` |
| `amber/100` | `#FEF3C7` |
| `amber/700` | `#B45309` |

グレーの数字は明るさの段階です。数字が小さいほど明るい、というWebのデザインシステムでよく使われる付け方に合わせています。

### 3. 色のセマンティックトークンを作る

「何に使う値か」を表す層です。ここからは `tokens` コレクションに作ります。

1. コレクション名の右にある「+」（コレクションを作成）から新しいコレクションを作り、名前を `tokens` にする
2. 色バリアブルを追加し、値は入力せず、値のスウォッチを右クリックして「エイリアスを作成」でプリミティブを参照させる（3-4の `brand` と同じ作り方）
   - 参照先の一覧に `primitives` のバリアブルが並ぶ

| 名前 | 参照先 | 用途 |
| --- | --- | --- |
| `brand` | `purple/500` | ブランド色。ボタン・アクティブ状態 |
| `text/main` | `gray/900` | 見出し・本文の文字 |
| `text/sub` | `gray/500` | 補助テキスト |
| `text/inverse` | `white` | 色付き背景の上の白文字 |
| `bg` | `gray/50` | contentエリアの背景 |
| `surface` | `white` | ヘッダー・カード・サイドバーの地色 |
| `border` | `gray/200` | 罫線・枠線 |
| `bg-active` | `purple/50` | サイドバーのアクティブ背景 |
| `placeholder` | `gray/300` | アバターやアイコンの仮置き図形 |
| `priority/high/bg` | `red/100` | 優先度タグHighの背景 |
| `priority/high/text` | `red/700` | 優先度タグHighの文字 |
| `priority/mid/bg` | `amber/100` | 優先度タグMidの背景 |
| `priority/mid/text` | `amber/700` | 優先度タグMidの文字 |
| `priority/low/bg` | `gray/100` | 優先度タグLowの背景 |
| `priority/low/text` | `gray/600` | 優先度タグLowの文字 |

全部で15個になります。要素に当てるのはこのセマンティックだけです。プリミティブを直接当てたくなったら、それは足りないセマンティックがあるサインです。

### 4. 余白と角丸のトークンを作る

数値バリアブルを `tokens` に追加します。「+ バリアブルを作成」を押すと種類の選択肢が出るので「数値」を選びます。名前が `数値` のまま選択状態で行が作られるので、そのまま書き換えます。次を登録します。

| 名前 | 値 |
| --- | --- |
| `space/4` | 4 |
| `space/8` | 8 |
| `space/12` | 12 |
| `space/16` | 16 |
| `space/20` | 20 |
| `space/24` | 24 |
| `space/32` | 32 |
| `space/48` | 48 |
| `radius/4` | 4 |
| `radius/8` | 8 |
| `radius/12` | 12 |
| `radius/16` | 16 |
| `radius/full` | 999 |

`space/*` は名前がそのままpx値です。`radius/full` の999は「十分大きくして常に完全な丸にする」ための慣用値で、チップやバッジのピル形状に使います。

ここまでで、`primitives` に色14個、`tokens` に色15個と数値13個の合計42個が並んでいれば正解です。

### 5. テキストスタイルを登録する

フォント・サイズ・ウェイトのセットは、バリアブルではなくテキストスタイルで管理します（3-4の使い分け表のとおり）。何も選択していない状態で「スタイル」セクション右上の「+」を押し、出てきたメニューから「テキスト」を選んで作り、次の8つを登録します。フォントは既定の Inter のままにします。

| スタイル名 | 指定 | 用途 |
| --- | --- | --- |
| `app-title` | 18 SemiBold | ロゴ、ヘッダーのアプリ名 |
| `page-title` | 24 Bold | 画面の見出し |
| `section-title` | 14 SemiBold | セクション見出し |
| `button-label` | 14 SemiBold | ボタンの文字 |
| `card-title` | 14 Medium | タスク名 |
| `body` | 14 Regular | navラベル・入力文字・ユーザー名 |
| `caption` | 12 Regular | 説明・期限・ラベル・チップ |
| `stat-value` | 28 Bold | 統計カードの数値 |

`section-title` と `button-label` は同じ14 SemiBoldですが、意味が違うので別名にします。コードにしたとき `.section-title` と `.button-label` が別のクラスになるのと同じ理屈です。

### 6. 骨組みに当てる

4-1の骨組みに、定義したトークンとスタイルを当てます。当てる操作は場所ごとに違います。

- 色: 「塗り」の4点アイコンを開き、バリアブルのチップから選ぶ（3-4と同じ）
- 間隔・パディング: 入力欄右の「⌄」を押して「バリアブルを適用...」を選ぶ
- 角の半径: 入力欄右の六角形アイコンを押す

一覧はコレクションごとに分かれて表示されます。Figma標準ライブラリのバリアブルも並びますが、選ぶのは `tokens` のものだけです。見つからなければ名前で検索します。

1. `sidebar` に当てる: 背景に `surface`、間隔に `space/8`、パディングに `space/24`
2. `nav-item` の四角形5個をまとめて選択して当てる: 塗りに `placeholder`、角の半径に `radius/8`
3. `header` に当てる: 背景に `surface`、左右パディングに `space/24`
4. `content` に当てる: 背景に `bg`、間隔に `space/24`、パディングに `space/32`
5. `placeholder` の四角形3個に当てる: 塗りに `surface`、角の半径に `radius/8`
6. `user-icon` の正円の塗りに `placeholder` を当てる
7. テキストに当てる。レイヤー名とスタイル名が同じで紛らわしいですが、当てるのは「タイポグラフィ」のスタイルです
   - `app-brand` と `app-title` に `app-title` スタイルを当て、色を `text/main` にする
   - `page-title` に `page-title` スタイルを当て、色を `text/main` にする

見た目は4-1の完成時とほぼ変わりません。変わったのは中身で、右サイドバーの表示が数値やカラーコードからトークン名に置き換わっています。試しに `space/24` の値を40に変えると、サイドバーとヘッダーのパディング、contentの間隔が一斉に動きます（確認したら24に戻してください）。
