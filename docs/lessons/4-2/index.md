# 4-2 タスクカードをコンポーネント化して並べる

4-1で作った骨組みの、仮置きの四角形を本物のタスクカードに置き換えます。カードをコンポーネント化してインスタンスを並べる流れは、3-2でプロフィールカードを使って練習したものと同じです。今回はそれを本番のデータでやります。

このレッスンも操作手順は逐一書きません。仕様を示すので、既習の操作（`Shift + A`、Hug/Fill、コンポーネント化、Assetsパネル）で組み立ててください。

## 完成イメージ

![タスク一覧画面の完成イメージ。薄グレーのcontentエリアに白いタスクカードのインスタンスが4枚縦に並ぶ。各カードは左にチェック用の正円、中央にタスク名、右端に期限。画面フレームの外にメインコンポーネントのTaskCardが置かれている](/lessons/4-2/task-list-cards.svg)

作るのはカード1種類だけです。

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `TaskCard` | カード本体（コンポーネント） | 横Auto Layout、gap 12、padding 16、背景白、角丸8、上下中央揃え |
| `checkbox` | 完了チェック | 20×20の正円。白塗り、グレーの枠線 |
| `task-title` | タスク名 | テキスト14px、幅Fill |
| `task-due` | 期限 | テキスト12px、薄いグレー |

レイヤー名は3-3の規約どおり、コンポーネントはPascalCase、中の部品はkebab-caseで作った時点で付けます。

task-dueを右端に寄せるのに、右寄せの設定は要りません。間にあるtask-titleの幅をFillにすれば、余った幅をタイトルが全部引き受けて、期限は自然と右端に押し出されます。

## 作る順序

1. 画面フレームの外の空いた場所で、カードを1枚組む
2. コンポーネント化して、レイヤー名を整える
3. contentのプレースホルダーを消し、インスタンスを3〜4枚並べる
4. 各インスタンスのタイトルと期限を上書きして、別々のタスクにする

カードを画面の外で組むのには理由があります。メインコンポーネント（原本）は画面には置かず、画面にはインスタンスだけを並べるのが定石です。原本が画面に混ざっていると、どれが原本か分からなくなり、うっかり原本を直接編集してしまいます。

もう1つ注意点があります。幅Fillは親がAuto Layoutのときしか選べないので、画面の外にある原本の幅はFixed（600程度）で作っておき、contentに入れたインスタンス側でFillにします。

## 演習: タスクカードを作って並べる

### 1. カードを1枚組む

1. `task-list` フレームの外の空いた場所に部品を作る: `O` で正円 20×20（白塗り、グレー `#D9D9E0` の枠線）、`T` でテキスト「デザインレビューの準備」（14px）と「7/3」（12px、薄いグレー）
2. 3つを選択して `Shift + A` で横並びのAuto Layoutにする
3. 仕様どおりに設定する: gap 12、padding 16、整列は上下中央、背景白、角丸8、幅はFixed 600
4. タイトルの幅を **Fill** にして、期限が右端に寄るのを確認する

### 2. コンポーネント化して名前を整える

1. カードのフレームを選択して `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）
2. レイヤーパネルのアイコンがひし形4つに変わったのを確認する
3. `Cmd + R`（Windowsは `Ctrl + R`）で名前を付ける: コンポーネントは `TaskCard`、中の部品は `checkbox`・`task-title`・`task-due`

### 3. インスタンスをcontentに並べる

1. `content` の中の `placeholder` をすべて選択して `Delete` で消す
2. 左サイドバーの **Assets パネル**から `TaskCard` を `content` の中へドラッグする
3. インスタンスの幅を **Fill**、高さを **Hug** にする
4. 同じ要領で合計3〜4枚にする。contentに入れたインスタンスを `Cmd + D`（Windowsは `Ctrl + D`）で複製してもかまいません

4-1の骨組みができていれば、カードはgap 16で縦に整列し、幅は画面いっぱいに揃います。

### 4. 中身を上書きする

1. 2枚目以降のインスタンスの `task-title` をダブルクリックして書き換える（例: 会議資料の作成、APIエラーの調査、リリースノートの下書き）
2. `task-due` も別の日付にする（例: 7/4、7/5、7/7）
3. 余裕があれば、1枚だけ `checkbox` の塗りを紫 `#7C3AED` にして、完了済みのタスクにする。完了と未完了はバリアントにせず、この色の上書きだけで表せば十分です

最後に、画面の外のメインコンポーネントで角丸やpaddingを少し変えてみてください。画面の中の全カードが一斉に変わり、上書きしたタイトルはそのまま残ります。確認できたら元に戻して完成です。

- [ ] インスタンス3〜4枚が幅Fillでcontentに並び、タイトルと期限をそれぞれ上書きできた
