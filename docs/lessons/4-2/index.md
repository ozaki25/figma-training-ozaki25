# 4-2 タスクカードをコンポーネント化して並べる

4-1で作った骨組みの、仮置きの四角形を本物のタスクカードに置き換えます。今回のタスクカードは、優先度・タスク名・説明・カテゴリ・担当者・期限まで読み取れる中身のあるカードにします。

カードをコンポーネント化してインスタンスを並べる流れは、3-2でプロフィールカードを使って練習したものと同じです。今回は中の要素が6つに増え、優先度タグは別の小さなコンポーネントとして切り出します。1つのレッスンで2つコンポーネント化する形になります。

コンポーネント化とアセットパネルの使い方は3-2で練習したとおりです。迷ったら3-2に戻って確認してください。

## 完成イメージ

![タスク一覧画面のcontentにTaskCardのインスタンスが3枚縦に並ぶ。各カードは左からチェック用の正円、優先度タグ、タスク名と説明の縦2行、カテゴリバッジ、担当者アイコン、右端に期限。画面外にTaskCardとPriorityTagの原本がある](/lessons/4-2/task-list-cards.png)

作るのはTaskCardとPriorityTagの2つです。仕様は次のとおり。パディングの「4/8」のような2値表記は、CSSの `padding: 4px 8px` と同じ**上下/左右**の順です。

```
TaskCard
├─ checkbox
├─ PriorityTag
├─ task-body
│  ├─ task-title
│  └─ task-desc
├─ CategoryBadge
├─ assignee
└─ task-due
```

| 部品 | 役割 | 仕様 |
| --- | --- | --- |
| `TaskCard` | カード本体（コンポーネント） | 横オートレイアウト、間隔 16、パディング 16、背景白、角丸12、上下中央揃え |
| `checkbox` | 完了チェック | 20×20の正円。白塗り、グレーの枠線 |
| `PriorityTag` | 優先度タグ（別コンポーネント） | 幅は内包、パディング 4/8、角丸4、テキスト12 Medium |
| `task-body` | タイトルと説明の縦積み | 縦オートレイアウト、間隔 4、幅は拡大 |
| `task-title` | タスク名 | 14px Medium |
| `task-desc` | 説明 | 12px Regular、薄グレー `#6E6E76` |
| `CategoryBadge` | カテゴリ | フレーム、幅は内包、パディング 4/10、角丸4、テキスト12 |
| `assignee` | 担当者 | 24×24のオートレイアウトフレーム、角丸12、薄グレー `#D9D9E0` 塗り、文字12 `#4B5563` |
| `task-due` | 期限 | 12px Regular、薄グレー `#6E6E76` |

TaskCardは横並びのカードですが、真ん中の `task-body` だけは中で縦にタイトルと説明を積みます。**オートレイアウトの入れ子（横の中に縦）** が初めて出てきます。CSSでいえば `flex-direction: row` の中に `flex-direction: column` のブロックを入れる形です。

`task-body` の幅を拡大にしておくと、余った幅をここが全部引き受けるので、右側の3要素（カテゴリ・担当者・期限）は自然と右端に押し出されます。

## PriorityTagを別コンポーネントにする理由

優先度タグは「High / Mid / Low」の3種類あります。TaskCardの中に直接置くと、インスタンスごとに文字と色を上書きする必要があります。1つの小さなコンポーネントにしておけば、TaskCardの中のPriorityTagインスタンスを差し替えるだけで済み、後で色や大きさを揃えて変えるのも楽になります。

このレッスンではPriorityTagにバリアントは付けません。値ごとに背景色と文字色を**インスタンスで上書き**します。バリアントは5-2のButtonで扱います。

## 表示するダミータスク

8件のうち、このレッスンでは3枚だけ並べます。残りは4-3のセクション分けで並べます。

| 優先度 | タイトル | 説明 | カテゴリ | 担当 | 期限 |
| --- | --- | --- | --- | --- | --- |
| High | デザインレビューの準備 | 一覧画面のデザインを共有 | デザイン | TY | 今日 |
| Mid | 会議資料の作成 | 定例向けサマリ | ドキュメント | HK | 今日 |
| High | APIエラーの調査 | 500系の再現手順 | 開発 | ST | 今日 |

担当の列は架空のメンバーのイニシャルです。`TY` は、完成イメージのサイドバー下部にいる Taro Yamada を指しています。

優先度の色は次のとおり。

| 値 | 背景 | 文字 |
| --- | --- | --- |
| High | `#FEE2E2` | `#B91C1C` |
| Mid | `#FEF3C7` | `#B45309` |
| Low | `#EEEEEE` | `#4B5563` |

## 作る順序

1. 画面フレームの外の空いた場所で `PriorityTag` を1つ作り、コンポーネント化する
2. その隣で `TaskCard` を組み、PriorityTagインスタンスを中に入れてからコンポーネント化する
3. 4-1の `content` からプレースホルダーを消し、TaskCardインスタンスを3枚並べる
4. 各インスタンスのテキストとPriorityTagの色を上書きして、別々のタスクにする

原本（メインコンポーネント）は画面には置かず、画面にはインスタンスだけを並べます。原本の幅は固定（600程度）で作っておき、contentに入れたインスタンス側で拡大にします。

## 演習

### 1. PriorityTagを作る

1. `task-list` フレームの外の空いた場所で、テキスト `High`（12px、Medium、`#B91C1C`）を作る
2. `Shift + A` でオートレイアウトにする。パディング 4/8、角丸4、背景 `#FEE2E2`、幅は内包
3. `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）でコンポーネント化する
4. `Cmd + R` で名前を `PriorityTag` にする

### 2. TaskCardを1枚組む

カードの入れ物を先に作り、部品を中に足していきます。4-1と同じ「外側から内側へ」の順です。

テキストはどれも、`t` を押したら**キャンバスをクリックしてから**入力してください。ドラッグで箱を描いてから入力すると幅が固定になり、文字が折り返されて崩れます。

1. PriorityTagを作ったのと同じ、`task-list` フレームの外の空いた場所に、空の横オートレイアウトフレームを作る。間隔 16、パディング 16、配置は上下中央、背景白、角丸12、幅は**固定600**・高さは内包。これがカード本体になる
2. 完了チェックの丸を入れる。`o` でカードの中に正円を描き、W/Hを 20×20 にする。白塗り、グレー `#D9D9E0` の枠線
3. 優先度タグを入れる。アセットパネルから `PriorityTag` のインスタンスを、丸の右へドラッグする
4. タスク名と説明のブロックを入れる。カードの中に空の縦オートレイアウトフレームを作って間隔 4 にし、名前を `task-body` にする。その中に `t` でテキスト `デザインレビューの準備`（14px、Medium）と `一覧画面のデザインを共有`（12px、Regular、薄グレー `#6E6E76`）を入れる
5. カテゴリのバッジを入れる。`t` でカードの中にテキスト `デザイン`（12px）を作り、`Shift + A` で包む。パディング 4/10、角丸4、薄グレー `#F5F5F5` 塗り、幅は内包
6. 担当者のアイコンを入れる。イニシャルが入った丸で、正円の図形の中にはテキストを入れられないので、角丸のフレームで円形を作る
   1. `t` でカードの中にイニシャルのテキスト `TY`（12px、`#4B5563`）を作り、`Shift + A` で包む
   2. 幅・高さを固定24、パディング 0、配置は中央にする
   3. 角丸12、塗りを薄グレー `#D9D9E0` にすると円形のアイコンになる
7. 期限を入れる。`t` でカードの中にテキスト `今日`（12px、Regular、薄グレー `#6E6E76`）を作る
8. 並び順を確認する。左から「丸・PriorityTag・task-body・バッジ・アイコン・期限」。違っていたら、カードの中で要素をドラッグして入れ替える
9. `task-body` の幅を**拡大**にして、カテゴリ・担当者・期限が右端に寄るのを確認する

### 3. コンポーネント化して名前を整える

1. TaskCardのフレームを選択して `Cmd + Option + K` でコンポーネント化
2. レイヤーパネルのアイコンがひし形4つに変わったのを確認する
3. `Cmd + R` で、コンポーネントの名前を `TaskCard` に、中の部品を `checkbox`・`task-title`・`task-desc`・`CategoryBadge`・`assignee`・`task-due` にする。`task-body` と `PriorityTag` は名前が付いているのでそのまま

### 4. インスタンスをcontentに3枚並べる

1. `content` の中の `placeholder` をすべて選択して `Delete` で消す
2. 左サイドバーの**アセットパネル**から `TaskCard` を `content` の中へドラッグする
3. インスタンスの幅を**拡大**、高さを**内包**にする
4. `Cmd + D` で3枚に複製する

3枚が間隔24で縦に並び、幅は右カラムいっぱいに揃うはずです。

### 5. 各インスタンスの中身を上書きする

上のダミータスク3件のとおりに、タイトル・説明・カテゴリ・担当のイニシャル・期限を書き換えます。カードの中の要素は、ダブルクリックするたびに1階層ずつ中に入って選べます。テキストは中に入ってもう一度ダブルクリックすると編集できます。

2枚目のカードは優先度がMidなので、`PriorityTag` インスタンスを選んで背景を `#FEF3C7`、文字色を `#B45309` に上書きし、文字も `High` から `Mid` に書き換えます。

最後に、画面の外のTaskCardの原本でパディングや角丸を少し変えてみてください。画面の中の3枚すべてが一斉に変わり、上書きしたタイトルはそのまま残ります。確認できたら元に戻します。
