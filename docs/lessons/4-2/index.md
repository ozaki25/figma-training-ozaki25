# 4-2 タスクカードをコンポーネント化して並べる

4-1で作った骨組みの、仮置きの四角形を本物のタスクカードに置き換えます。今回のタスクカードは、優先度・タスク名・説明・カテゴリ・担当者・期限まで読み取れる中身のあるカードにします。

カードをコンポーネント化してインスタンスを並べる流れは、3-2でプロフィールカードを使って練習したものと同じです。今回は中の要素が6つに増え、優先度タグは別の小さなコンポーネントとして切り出します。1つのレッスンで2つコンポーネント化する形になります。

このレッスンも操作手順は逐一書きません。仕様を示すので、既習の操作（`Shift + A`、Hug/Fill、コンポーネント化、Assetsパネル）で組み立ててください。

作るのはTaskCardとPriorityTagの2つです。仕様は次のとおり。

| 部品 | 役割 | 仕様 |
| --- | --- | --- |
| `TaskCard` | カード本体（コンポーネント） | 横Auto Layout、gap 16、padding 16、背景白、角丸12、上下中央揃え |
| └ `checkbox` | 完了チェック | 20×20の正円。白塗り、グレーの枠線 |
| └ `PriorityTag` | 優先度タグ（別コンポーネント） | 幅Hug、padding 4/8、角丸4、テキスト12 Medium |
| └ `task-body` | タイトルと説明の縦積み | 縦Auto Layout、gap 4、幅Fill |
| 　　├ `task-title` | タスク名 | 14px Medium |
| 　　└ `task-desc` | 説明 | 12px Regular、薄グレー |
| └ `CategoryBadge` | カテゴリ | フレーム、幅Hug、padding 4/10、角丸4、テキスト12 |
| └ `assignee` | 担当者 | 24×24 正円、薄グレー塗り、白抜き文字 12 |
| └ `task-due` | 期限 | 12px Regular、薄グレー |

TaskCardは横並びのカードですが、真ん中の `task-body` だけは中で縦にタイトルと説明を積みます。**Auto Layoutの入れ子（横の中に縦）** が初めて出てきます。CSSでいえば `flex-direction: row` の中に `flex-direction: column` のブロックを入れる形です。

`task-body` の幅をFillにしておくと、余った幅をここが全部引き受けるので、右側の3要素（カテゴリ・担当者・期限）は自然と右端に押し出されます。

## PriorityTagを別コンポーネントにする理由

優先度タグは「High / Mid / Low」の3種類あります。TaskCardの中に直接置くと、インスタンスごとに文字と色を上書きする必要があります。1つの小さなコンポーネントにしておけば、TaskCardの中のPriorityTagインスタンスを差し替えるだけで済み、後で色や大きさを揃えて変えるのも楽になります。

このレッスンではPriorityTagにバリアントは付けません。値ごとに背景色と文字色を**インスタンスで上書き**します。バリアントは5-2のButtonで扱います。

## 表示するダミータスク

8件のうち、このレッスンでは3枚だけ並べます。残りは4-3のセクション分けで並べます。

| 優先度 | タイトル | 説明 | カテゴリ | 担当 | 期限 |
| --- | --- | --- | --- | --- | --- |
| High | デザインレビューの準備 | 一覧画面のFigを共有 | デザイン | YO | 今日 |
| Mid | 会議資料の作成 | 定例向けサマリ | ドキュメント | HK | 今日 |
| High | APIエラーの調査 | 500系の再現手順 | 開発 | ST | 今日 |

優先度の色は次のとおり。

| 値 | 背景 | 文字 |
| --- | --- | --- |
| High | `#FEE2E2` | `#B91C1C` |
| Mid | `#FEF3C7` | `#B45309` |
| Low | `#EEEEEE` | `#4B5563` |

## 作る順序

1. 画面フレームの外の空いた場所で `PriorityTag` を1つ作り、コンポーネント化する
2. その隣で `TaskCard` を組み、PriorityTagインスタンスを中に入れてからコンポーネント化する
3. 4-1の `content` からプレースホルダーを消し、TaskCardインスタンスを3枚並べる
4. 各インスタンスのテキストとPriorityTagの色を上書きして、別々のタスクにする

原本（メインコンポーネント）は画面には置かず、画面にはインスタンスだけを並べます。原本の幅はFixed（600程度）で作っておき、contentに入れたインスタンス側でFillにします。

## 演習

### 1. PriorityTagを作る

1. `task-list` フレームの外の空いた場所で、テキスト `High`（12px、Medium、`#B91C1C`）を作る
2. `Shift + A` でAuto Layoutにする。padding 4/8、角丸4、背景 `#FEE2E2`、幅Hug
3. `Cmd + Option + K`（Windowsは `Ctrl + Alt + K`）でコンポーネント化する
4. `Cmd + R` で名前を `PriorityTag` にする

### 2. TaskCardを1枚組む

1. 同じ場所に部品を作る:
   - `O` で正円 20×20（白塗り、グレー `#D9D9E0` の枠線）
   - `PriorityTag` のインスタンス1つ（Assetsパネルからドラッグ）
   - `T` でテキスト `デザインレビューの準備`（14px、Medium）と `一覧画面のFigを共有`（12px、Regular、薄グレー）
   - `T` でテキスト `デザイン`（12px）。`Shift + A` でAuto Layoutにして padding 4/10、角丸4、薄グレー塗り、幅Hug
   - `O` で正円 24×24（薄グレー塗り）+ 中にテキスト `YO`（12px、白）
   - `T` でテキスト `今日`（12px、Regular、薄グレー）
2. タイトルと説明の2つを選択して `Shift + A` で縦Auto Layout、gap 4、幅は後でFillにする
3. すべてを選択して `Shift + A` で横Auto Layoutにする。gap 16、padding 16、整列は上下中央、背景白、角丸12、幅はFixed 600
4. 真ん中のタイトル+説明ブロックの幅を **Fill** にして、カテゴリ・担当者・期限が右端に寄るのを確認する

### 3. コンポーネント化して名前を整える

1. TaskCardのフレームを選択して `Cmd + Option + K` でコンポーネント化
2. レイヤーパネルのアイコンがひし形4つに変わったのを確認する
3. `Cmd + R` で名前を付ける: コンポーネントは `TaskCard`、中の部品は `checkbox`・`task-body`・`task-title`・`task-desc`・`CategoryBadge`・`assignee`・`task-due`（PriorityTagはインスタンス名なのでそのまま）

### 4. インスタンスをcontentに3枚並べる

1. `content` の中の `placeholder` をすべて選択して `Delete` で消す
2. 左サイドバーの **Assets パネル**から `TaskCard` を `content` の中へドラッグする
3. インスタンスの幅を **Fill**、高さを **Hug** にする
4. `Cmd + D` で3枚に複製する

3枚がgap 24で縦に並び、幅は右カラムいっぱいに揃うはずです。

### 5. 各インスタンスの中身を上書きする

上のダミータスク3件のとおりに、タイトル・説明・カテゴリ・担当のイニシャル・期限をダブルクリックで書き換えます。

`PriorityTag` インスタンスは、High以外にしたい行では**インスタンスの背景色と文字色を上書き**します（Midは背景 `#FEF3C7` / 文字 `#B45309`）。文字も `High` → `Mid` に書き換えます。

最後に、画面の外のTaskCardの原本でpaddingや角丸を少し変えてみてください。画面の中の3枚すべてが一斉に変わり、上書きしたタイトルはそのまま残ります。確認できたら元に戻します。
