# 4-1 レイアウトの骨組みを作る

ここからは本番です。1〜3章で練習したプロフィールカードは使いません。新しいデザインファイルを作り、タスク管理ツールの「タスク一覧画面」をゼロから作っていきます。

このレッスンで作るのは画面の骨組みだけです。ヘッダーとコンテンツエリアを配置し、リサイズ挙動まで整えます。タスクカードの中身は4-2で作ります。

4章からは、操作手順を1つずつ書きません。「何をどの順で作るか」と仕様（サイズ・間隔）を示すので、操作自体はこれまで練習した手順（フレーム作成、`Shift + A`、Hug/Fill、リネーム）でやってみてください。新しく出てくる操作だけはその場で説明します。

## 完成イメージ

![タスク一覧画面の骨組みの見取り図。task-listフレームの上部にheader（My Tasksとuser-icon）、その下に薄グレーのcontentエリアがあり、見出しとプレースホルダーの四角形3つが縦に並ぶ](/lessons/4-1/task-list-skeleton.svg)

構造は2階層だけです。

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `task-list` | 画面全体 | Desktop 1440×1024、縦Auto Layout、gap 0 |
| `header` | 上部バー | 幅Fill・高さFixed 64、横Auto Layout、左右padding 24、背景白 |
| `content` | 残りの領域 | 幅Fill・高さFill、縦Auto Layout、padding 32、gap 16、背景 #F5F5F5 |

ヘッダーの高さをFixedにするのは、画面が縦に伸びてもバーの太さは変わらないからです。逆にコンテンツエリアは「残りの高さ全部」を埋めたいのでFillにします。2-3で見たリサイズ挙動を、実際の画面設計に当てはめる場面です。

## 作る順序

外側から内側へ作ります。先に入れ物（フレームとAuto Layout）を決めてから中身を足すと、置いた要素が自動で正しい位置に収まるので、手戻りがありません。

1. 画面フレーム `task-list` を作り、縦のAuto Layoutにする
2. ヘッダーを作って上に入れる
3. コンテンツエリアを作って下に入れる
4. プレースホルダーを置いて、骨組みが機能するか確かめる

レイヤー名は後でまとめて直すのではなく、作ったその場で3-3の規約どおりに付けます。部品はkebab-case、コンポーネントはPascalCaseです（このレッスンではコンポーネントはまだ出てきません）。

## 新出の操作: 間隔「Auto」

ヘッダーでは「左にアプリ名、右にアイコン」と両端に振り分けます。これにはAuto Layoutの要素間の間隔を数値ではなく **Auto** にします。CSSの `justify-content: space-between` に相当し、要素同士ができるだけ離れて配置されます。

設定は右サイドバーのLayoutセクションで、間隔の入力欄のドロップダウンから「Auto」を選びます。入力欄に `Auto` と直接入力しても同じです。

## 演習: 骨組みを組み立てる

### 1. 画面フレームを作る

1. 新しいデザインファイルを作る
2. `F` でフレームツールを選び、右サイドバーのプリセットから **Desktop（1440×1024）** を選ぶ
3. フレームを選択したまま `Shift + A` でAuto Layoutを付け、フローを縦、gap・パディングをすべて 0 にする
4. 名前を `task-list` にする（`Cmd + R`、Windowsは `Ctrl + R`）

### 2. ヘッダーを作る

1. キャンバスの空いた場所に、テキスト `My Tasks`（18px、Semi Bold程度）と、正円 32×32（薄いグレー）を作る
2. 2つを選択して `Shift + A` で横並びのAuto Layoutにする
3. `task-list` の中へドラッグして入れる
4. 仕様どおりに設定する: 幅 **Fill**・高さ **Fixed 64**、間隔 **Auto**、左右パディング 24（上下は0）、整列は上下中央、背景白
5. 名前を付ける: フレームは `header`、テキストは `app-title`、正円は `user-icon`

`task-list` に入れた瞬間、ヘッダーが画面の上端にピタッと収まります。入れ物のAuto Layoutを先に作った効果です。

### 3. コンテンツエリアを作る

1. キャンバスにテキスト `今日のタスク`（24px、Bold）を作る
2. テキストを選択して `Shift + A`。要素が1つでもAuto Layoutフレームにできます
3. できたフレームを `task-list` の中、`header` の下へ入れる
4. 仕様どおりに設定する: 幅 **Fill**・高さ **Fill**、フロー縦、gap 16、パディング 32、背景 `#F5F5F5`
5. 名前を付ける: フレームは `content`、テキストは `page-title`

高さをFillにした時点で、コンテンツエリアが画面の残り全部に広がるのを確認してください。

### 4. プレースホルダーで骨組みを確かめる

タスクカードは4-2で作るので、いまは仮の四角形で骨組みの動きだけ確認します。

1. `content` の中に `R` で四角形を作る: 高さ 72、角丸 8、白
2. 幅を **Fill** にして、名前を `placeholder` にする
3. `Cmd + D`（Windowsは `Ctrl + D`）で2〜3個に複製する

四角形がgap 16で縦に並び、幅は画面いっぱいに揃うはずです。最後に `task-list` 全体の高さをドラッグで変えてみてください。ヘッダーは64のまま動かず、コンテンツエリアだけが伸び縮みすれば、骨組みは完成です。

## ゴール確認

- [ ] ヘッダーは間隔Autoで両端寄せになり、幅Fill・高さFixed 64で設定できた
