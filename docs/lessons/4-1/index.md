# 4-1 レイアウトの骨組みを作る

ここからは本番です。1〜3章で練習したプロフィールカードは使いません。タスク管理ツールの「タスク一覧画面」をゼロから作っていきます。

このレッスンで作るのは画面の骨組みだけです。左のサイドバーと、右の上下2段（ヘッダーとコンテンツ）を配置し、リサイズ挙動まで整えます。この後、4-2でデザイントークンを整え、4-3でタスクカードを作ります。

使う操作は1〜3章で練習したものが中心です。手順の途中で迷ったら、フレームは1-2、オートレイアウトは2-2、内包/拡大/固定は2-3に戻って確認してください。

## 完成イメージ

![タスク一覧画面の骨組みの見取り図。左に幅240のsidebarフレーム、右にmainフレーム。mainの上部にheader、その下に薄グレーのcontentエリアがあり、見出しとプレースホルダーの四角形3つが縦に並ぶ](/lessons/4-1/task-list-skeleton.png)

構造は3階層です。一番外側を横に2つに分け、右側をさらに上下に分けます。

```
task-list
├─ sidebar
└─ main
   ├─ header
   └─ content
```

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `task-list` | 画面全体 | Desktop 1440×1024、横オートレイアウト、間隔 0 |
| `sidebar` | 左ナビ | 幅は固定240・高さは拡大、縦オートレイアウト、パディング 24、間隔 8、背景白 |
| `main` | 右カラム | 幅・高さとも拡大、縦オートレイアウト、間隔 0 |
| `header` | 上部バー | 幅は拡大・高さは固定64、横オートレイアウト、左右パディング 24、背景白 |
| `content` | 中身 | 幅・高さとも拡大、縦オートレイアウト、パディング 32、間隔 24、背景 `#F5F5F5` |

サイドバーの幅は固定240、右カラムのmainは幅を拡大にします。CSSでいえば `display: flex` の中で片方だけ幅固定、もう片方が `flex: 1` で残りを埋める構図と同じです。mainの中は縦に、ヘッダーは高さを固定64、コンテンツは拡大で残りの高さを取ります。

サイドバーの中身は今回はプレースホルダーだけにします。アイコンやユーザーブロックなどの装飾は4-4の仕上げに回して、ここでは骨組みに集中します。

## 作る順序

中身を先に作り、`Shift + A` で包んで塊にして、外の枠に入れていきます。

1. 練習の成果物を `practice` ページへ移して、本番用のページを用意する
2. 画面フレーム `task-list` を作り、横のオートレイアウトにする
3. サイドバーを組んで、task-listの左に入れる
4. ヘッダーとコンテンツエリアを組む
5. 2つをmainにまとめて、task-listの右に入れる
6. プレースホルダーを置いて、骨組みが機能するか確かめる

レイヤー名は後でまとめて直すのではなく、作ったその場で3-3の規約どおりに付けます。部品はkebab-case、コンポーネントはPascalCaseです（このレッスンではコンポーネントはまだ出てきません）。

## 演習: 骨組みを組み立てる

### 1. 練習の成果物を片付ける

本番のページを、練習の成果物と分けてきれいにしておきます。

1. ページ一覧で、いま作業しているページの名前を `task-app` にする（名前の変え方は1-2と同じ）
2. もう1枚のページの名前を `practice` にする（1-2でページを追加していない場合は「+」で追加する）
3. `task-app` に残っている練習の成果物（プロフィールカード一式・コンポーネント・土台のフレーム）をすべて選択して `Cmd + X` で切り取り、`practice` ページに `Cmd + V` で貼り付ける

### 2. 画面フレームを作る

1. `f` でフレームツールを選び、右サイドバーのプリセットから **Desktop（1440×1024）** を選ぶ
2. フレームを選択したまま `Shift + A` でオートレイアウトにして、フローを横、間隔 0、パディング 0 にする
3. 名前を `task-list` にする（`Cmd + R`、Windowsは `Ctrl + R`）

### 3. サイドバーを作る

1. 中身から作る。アプリのロゴ部分として、`t` でテキスト `TaskFlow`（18px、SemiBold程度）をキャンバスで作る
2. このとき3-1で登録したテキストスタイルが勝手に当たっていることがある。新しいテキストは直前に使ったテキストの設定を引き継ぐ仕様で、止める設定はない
   - スタイルは、「タイポグラフィ」のスタイル名にホバーすると出る切り離しアイコンで外す
   - 毎回外すのが面倒なら、外した後の素のテキストを1つ手元に残し、以降は `t` の代わりにそれを `Cmd + D` で複製して文字を打ち替える
3. ナビゲーションのメニュー項目の仮置きとして、`r` で高さ32の四角形を作り、角丸8、薄グレー `#E5E5EA` 塗りにする。完成イメージの左側にある「受信箱」「今日」などのメニューになる部分で、テキスト入りにするのは4-4でやる
4. `TaskFlow` と四角形の2つを選択して `Shift + A` で縦に包む。このフレームがサイドバーになる（並びが縦にならなかったら、「オートレイアウト」セクションのフローで縦を選ぶ）
5. 間隔 8、パディング 24、背景白にする
6. `task-list` の中へ入れ、幅を**固定240**、高さを**拡大**にする
7. 四角形の幅を**拡大**にして、`Cmd + D` で5個にする
8. テキストの名前を `app-brand`、四角形を `nav-item`、フレームを `sidebar` にする

### 4. ヘッダーを作る

ヘッダーの中身は「左にアプリ名、右にログイン中ユーザーのアイコン」の2つです。

1. キャンバスで、アプリ名のテキスト `My Tasks`（18px、SemiBold程度）と、ユーザーアイコンの仮置きの正円 32×32（薄グレー `#E5E5EA`）を作る
2. 2つを選択して `Shift + A` で横に包む。このフレームがヘッダーになる（並びが横にならなかったら、フローで横を選ぶ）
   - 左右パディング 24、配置は上下中央
   - 背景白
   - 高さは**固定64**（幅はmainに入れてから拡大にする）
3. フレームの名前を `header`、テキストを `app-title`、正円を `user-icon` にする

### 5. コンテンツエリアを作る

タスク一覧が並ぶ場所です。いまは見出しだけ入れます。

1. `t` で見出しのテキスト `今日のタスク`（24px、Bold）を作り、`Shift + A` で包む。このフレームがコンテンツエリアになる
2. フロー縦、間隔 24、パディング 32 にする
3. フレームの名前を `content`、テキストを `page-title` にする

### 6. mainにまとめる

1. `header` と `content` の2つを選択して `Shift + A` で縦に包む。このフレームが右カラムのmainになる
2. 間隔 0、パディング 0 にして、名前を `main` にする
3. `main` を `task-list` の中、`sidebar` の右へ入れ、幅・高さとも**拡大**にする
4. `header` の幅を**拡大**にする
5. `header` の間隔を**自動**にする。間隔の入力欄のドロップダウンから「自動」を選ぶ
   - アプリ名とアイコンが左右の両端に振り分けられる。CSSの `justify-content: space-between` に当たる設定
6. `content` の幅・高さとも**拡大**にする
7. `content` の背景を `#F5F5F5` にする
   - この色はキャンバスの背景色と同じ。mainの外で塗るとキャンバスと同化して見えなくなるので、必ずmainに入れてから塗る

サイドバーの幅が固定240で止まっているので、`main` の幅を拡大にすると残りの1200を埋めます。ヘッダーは固定64で高さを固定、contentは拡大で残りの高さ全部を取ります。

### 7. プレースホルダーで骨組みを確かめる

タスクカードは4-3で作るので、いまは仮の四角形で骨組みの動きだけ確認します。

1. `r` で高さ72・角丸8・白の四角形をキャンバスで作り、`content` の中へ入れる
2. 幅を**拡大**にして、名前を `placeholder` にする
3. `Cmd + D`（Windowsは `Ctrl + D`）で3個にする

四角形が間隔24で縦に並び、幅は右カラムの幅いっぱいにそろうはずです。最後に `task-list` 全体の幅と高さをドラッグで変えてみてください。幅を変えると、サイドバーは240のままmainだけが伸び縮みする。高さを変えると、ヘッダーは64のままcontentだけが伸び縮みする。この2つが確認できれば骨組みは完成です。

## ゴール確認

- [ ] `task-list` が横オートレイアウトで `sidebar` と `main` に分かれ、mainの中にheaderとcontentが縦に並んだ
- [ ] サイドバーは幅を固定240、mainは幅を拡大、ヘッダーは高さを固定64、contentは高さを拡大に設定できた
- [ ] 画面の幅を変えるとmainだけ、高さを変えるとcontentだけが伸縮することを確認できた
