# 4-1 レイアウトの骨組みを作る

ここからは本番です。1〜3章で練習したプロフィールカードは使いません。新しいデザインファイルを作り、タスク管理ツールの「タスク一覧画面」をゼロから作っていきます。

このレッスンで作るのは画面の骨組みだけです。左のサイドバーと、右の上下2段（ヘッダーとコンテンツ）を配置し、リサイズ挙動まで整えます。タスクカードの中身は4-2で作ります。

4章からは、操作手順を1つずつ書きません。「何をどの順で作るか」と仕様（サイズ・間隔）を示すので、操作自体はこれまで練習した手順（フレーム作成、`Shift + A`、Hug/Fill、リネーム）でやってみてください。新しく出てくる操作だけはその場で説明します。

構造は3階層です。一番外側を横に2つに分け、右側をさらに上下に分けます。

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `task-list` | 画面全体 | Desktop 1440×1024、横Auto Layout、gap 0 |
| ├ `sidebar` | 左ナビ | 幅Fixed 240・高さFill、縦Auto Layout、padding 24、gap 8、背景白 |
| └ `main` | 右カラム | 幅Fill・高さFill、縦Auto Layout、gap 0 |
| 　　├ `header` | 上部バー | 幅Fill・高さFixed 64、横Auto Layout、左右padding 24、背景白 |
| 　　└ `content` | 中身 | 幅Fill・高さFill、縦Auto Layout、padding 32、gap 24、背景 `#F5F5F5` |

サイドバーの幅はFixed 240、右カラムのmainは幅Fillです。CSSでいえば `display: flex` の中で片方だけ幅固定、もう片方が `flex: 1` で残りを埋める構図と同じです。mainの中は縦に、ヘッダーはFixed 64、コンテンツはFillで残りの高さを取ります。

サイドバーの中身は今回はプレースホルダーだけにします。アイコンやユーザーブロックなどの装飾は4-3の仕上げに回して、ここでは骨組みに集中します。

## 作る順序

外側から内側へ作ります。先に入れ物を決めてから中身を足すと、置いた要素が自動で正しい位置に収まります。

1. 画面フレーム `task-list` を作り、横のAuto Layoutにする
2. サイドバーを左に入れる
3. mainを右に入れ、縦Auto Layoutにする
4. mainの中にheaderとcontentを積む
5. contentに見出しとプレースホルダーを置いて、骨組みが機能するか確かめる

レイヤー名は後でまとめて直すのではなく、作ったその場で3-3の規約どおりに付けます。部品はkebab-case、コンポーネントはPascalCaseです（このレッスンではコンポーネントはまだ出てきません）。

## 新出の操作: 間隔「Auto」

ヘッダーでは「左にアプリ名、右にアイコン」と両端に振り分けます。これにはAuto Layoutの要素間の間隔を数値ではなく **Auto** にします。CSSの `justify-content: space-between` に相当し、要素同士ができるだけ離れて配置されます。

設定は右サイドバーのLayoutセクションで、間隔の入力欄のドロップダウンから「Auto」を選びます。入力欄に `Auto` と直接入力しても同じです。

## 演習: 骨組みを組み立てる

### 1. 画面フレームを作る

1. 新しいデザインファイルを作る
2. `F` でフレームツールを選び、右サイドバーのプリセットから **Desktop（1440×1024）** を選ぶ
3. フレームを選択したまま `Shift + A` でAuto Layoutを付け、フローを**横**、gap・パディングをすべて 0 にする
4. 名前を `task-list` にする（`Cmd + R`、Windowsは `Ctrl + R`）

### 2. サイドバーを作る

1. キャンバスの空いた場所に `Shift + A` で空の縦Auto Layoutフレームを作り、`task-list` の中へドラッグして入れる
2. 仕様どおりに設定する: 幅 **Fixed 240**・高さ **Fill**、フロー縦、gap 8、パディング 24、背景白
3. 名前を `sidebar` にする
4. 中にテキスト `TaskFlow`（18px、SemiBold程度）を置き、その下に `R` で高さ32の四角形を5個並べる（幅 **Fill**、角丸8、薄グレー塗り）
5. テキストの名前を `app-brand`、四角形の名前を `nav-item` にする

`nav-item` を5個並べると、サイドバーがナビゲーションの雰囲気になります。中身の装飾は4-3で仕上げるので、いまはこの状態で十分です。

### 3. mainを作る

1. キャンバスで `Shift + A` で空の縦Auto Layoutフレームを作り、`task-list` の中、`sidebar` の右へ入れる
2. 仕様どおりに設定する: 幅 **Fill**・高さ **Fill**、フロー縦、gap 0、パディング 0
3. 名前を `main` にする

サイドバーの幅がFixed 240で止まっているので、`main` を幅Fillにすると残りの1200を埋めます。

### 4. mainの中にheaderとcontentを積む

1. キャンバスで、テキスト `My Tasks`（18px、SemiBold程度）と正円 32×32（薄グレー）を作り、2つを選択して `Shift + A` で横Auto Layoutにする
2. `main` の中へ入れて、仕様どおりに設定する: 幅 **Fill**・高さ **Fixed 64**、間隔 **Auto**、左右padding 24、整列は上下中央、背景白
3. 名前を付ける: フレームは `header`、テキストは `app-title`、正円は `user-icon`
4. 続けてキャンバスにテキスト `今日のタスク`（24px、Bold）を作り、`Shift + A` でAuto Layoutにしてから `main` の中、`header` の下へ入れる
5. 仕様どおりに設定する: 幅 **Fill**・高さ **Fill**、フロー縦、gap 24、パディング 32、背景 `#F5F5F5`
6. 名前を付ける: フレームは `content`、テキストは `page-title`

ヘッダーはFixed 64で高さを固定、contentはFillで残りの高さ全部を取ります。

### 5. プレースホルダーで骨組みを確かめる

タスクカードは4-2で作るので、いまは仮の四角形で骨組みの動きだけ確認します。

1. `content` の中に `R` で四角形を作る: 高さ 72、角丸 8、白
2. 幅を **Fill** にして、名前を `placeholder` にする
3. `Cmd + D`（Windowsは `Ctrl + D`）で2〜3個に複製する

四角形がgap 24で縦に並び、幅は右カラムの幅いっぱいにそろうはずです。最後に `task-list` 全体の高さをドラッグで変えてみてください。ヘッダーは64のまま、サイドバーは幅240のまま、contentだけが伸び縮みすれば骨組みは完成です。

## ゴール確認

- [ ] サイドバーは幅Fixed 240、mainは幅Fill、ヘッダーは高さFixed 64、contentは高さFillに設定できた
- [ ] 画面の高さを変えるとcontentだけが伸縮することを確認できた
