# 4-1 レイアウトの骨組みを作る

ここからは本番です。1〜3章で練習したプロフィールカードは使いません。タスク管理ツールの「タスク一覧画面」をゼロから作っていきます。

このレッスンで作るのは画面の骨組みだけです。左のサイドバーと、右の上下2段（ヘッダーとコンテンツ）を配置し、リサイズ挙動まで整えます。この後、4-2でデザイントークンを整え、4-3でタスクカードを作ります。

使う操作は1〜3章で練習したものが中心です。手順の途中で迷ったら、フレームは1-2、オートレイアウトは2-2、内包/拡大/固定は2-3に戻って確認してください。

## 完成イメージ

![タスク一覧画面の骨組み。左に幅240のsidebarがあり、TaskFlowのロゴとメニューの仮置き5個が縦に並ぶ。右はmainで、上部にアプリ名入りのheader、その下に薄グレーのcontentがあり、タスク一覧の見出しと白いプレースホルダー3つが縦に並ぶ](/lessons/4-1/task-list-skeleton.png)

構造は3階層です。一番外側を横に2つに分け、右側をさらに上下に分けます。

```
task-list
├─ sidebar
└─ main
   ├─ header
   └─ content
```

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `task-list` | 画面全体 | デスクトップ 1440×1024、横オートレイアウト、間隔 0 |
| `sidebar` | 左ナビ | 幅は固定240・高さは拡大、縦オートレイアウト、パディング 24、間隔 8、背景白 |
| `main` | 右カラム | 幅・高さとも拡大、縦オートレイアウト、間隔 0 |
| `header` | 上部バー | 幅は拡大・高さは固定64、横オートレイアウト、左右パディング 24、背景白 |
| `content` | 中身 | 幅・高さとも拡大、縦オートレイアウト、パディング 32、間隔 24、背景 `#F5F5F5` |

サイドバーの中身は今回はプレースホルダーだけにします。アイコンやユーザーブロックなどの装飾は4-4の仕上げに回して、ここでは骨組みに集中します。

## 演習: 骨組みを組み立てる

### 1. 練習の成果物を片付ける

本番のページを、練習の成果物と分けてきれいにしておきます。

1. ページ一覧で、いま練習の成果物が乗っているページの名前を `practice` にする（名前の変え方は1-2と同じ）
2. もう1枚のページを `task-app` にする（1-2でページを追加していない場合は「+」で追加してから名前を付ける）
3. `task-app` ページに切り替える。練習の成果物には触れず、ここから空のキャンバスで本番を組み立てる
4. 何も選択していない状態で右サイドバーの「スタイル」セクションを開き、3-1で登録した `surface` を右クリックして「削除」を選ぶ。同じように `text/main`・`text/sub`・`name`・`caption` も消す
   - 消す理由: 残しておくと、これから作るテキストや図形にこのスタイルが勝手に当たる。色と文字は4-2でバリアブルとテキストスタイルとして作り直す
   - 適用先のプロフィールカードの色や文字はそのまま残り、スタイルとの紐付けだけが外れる
   - バリアブルの `purple/500` と `brand` は4-2でそのまま使うので消さない

### 2. 画面フレームを作る

1. `f` でフレームツールを選び、右サイドバーのプリセットから **デスクトップ（1440×1024）** を選ぶ
2. フレームを選択したまま `Shift + A` でオートレイアウトにして、フローを横、間隔 0、パディング 0 にする
3. 名前を `task-list` にする（`Cmd + R`、Windowsは `Ctrl + R`）

### 3. サイドバーを作る

1. 中身から作る。アプリのロゴになる部分として、`t` でテキスト `TaskFlow`（18px、SemiBold程度）を作る
2. `r` で高さ32の四角形を作り、角丸8、薄グレー `#D9D9E0` 塗りにする。「受信箱」「今日」などのメニュー項目になる仮置きで、テキスト入りにするのは4-4でやる
3. `TaskFlow` と四角形の2つを選択して `Shift + A` で縦に包む。このフレームがサイドバーになる（並びが縦にならなかったら、「オートレイアウト」セクションのフローで縦を選ぶ）
4. 間隔 8、パディング 24、背景白にする
5. `task-list` の中へ入れ、幅を**固定240**、高さを**拡大**にする
6. 四角形の幅を**拡大**にして、`Cmd + D` で5個にする
7. テキストの名前を `app-brand`、四角形を `nav-item`、フレームを `sidebar` にする

### 4. ヘッダーを作る

ヘッダーの中身は「左にアプリ名、右にログイン中ユーザーのアイコン」の2つです。サイドバーのロゴと同じ `TaskFlow` という文字になりますが、別のレイヤーです（サイドバー側は `app-brand`、ヘッダー側は `app-title`）。4-2でこの2つに同じテキストスタイルを当てます。

1. `t` でアプリ名のテキスト `TaskFlow`（18px、SemiBold程度）と、`o` でユーザーアイコン仮置きの正円 32×32（薄グレー `#D9D9E0`）を作る
2. 2つを選択して `Shift + A` で横に包む。このフレームがヘッダーになる（並びが横にならなかったら、フローで横を選ぶ）
   - 左右パディング 24、配置は上下中央
   - 背景白
   - 高さは**固定64**（幅はmainに入れてから拡大にする）
3. フレームの名前を `header`、テキストを `app-title`、正円を `user-icon` にする

### 5. コンテンツエリアを作る

タスク一覧が並ぶ場所です。いまは見出しだけ入れます。

1. `t` で見出しのテキスト `タスク一覧`（24px、Bold）を作り、`Shift + A` で包む。このフレームがコンテンツエリアになる
2. フロー縦、間隔 24、パディング 32 にする
3. フレームの名前を `content`、テキストを `page-title` にする

### 6. mainにまとめる

1. `header` と `content` の2つを選択して `Shift + A` で縦に包む。このフレームが右カラムのmainになる
2. 間隔 0、パディング 0 にして、名前を `main` にする
3. `main` を `task-list` の中、`sidebar` の右へ入れ、幅・高さとも**拡大**にする
4. `header` の幅を**拡大**にする
5. `header` の間隔を**自動**にする。間隔の入力欄のドロップダウンから「自動」を選ぶ
   - アプリ名とアイコンが左右の両端に振り分けられる。CSSの `justify-content: space-between` に当たる設定
6. `content` の幅・高さとも**拡大**にする
7. `content` の背景を `#F5F5F5` にする
   - キャンバスの背景も薄いグレーで、mainの外で塗ると見分けがつかない。必ずmainに入れてから塗る

サイドバーの幅が240で止まっているので、`main` の幅を拡大にすると残りの1200を埋めます。同じように、ヘッダーの高さが64で止まっているぶん、contentが残りの高さ全部を取ります。

### 7. プレースホルダーで骨組みを確かめる

タスクカードは4-3で作るので、いまは仮の四角形で骨組みの動きだけ確認します。

1. `r` で高さ72・角丸8・白の四角形をキャンバスで作り、`content` の中へ入れる
2. 幅を**拡大**にして、名前を `placeholder` にする
3. `Cmd + D`（Windowsは `Ctrl + D`）で3個にする

四角形が間隔24で縦に並び、幅は右カラムの幅いっぱいにそろうはずです。

最後に `task-list` 全体の幅と高さをドラッグで変えて、次の2つを確認してください。

- 幅を変えると、サイドバーは240のままmainだけが伸び縮みする
- 高さを変えると、ヘッダーは64のままcontentだけが伸び縮みする

確認できたらサイズを1440×1024に戻して、骨組みは完成です。

- [ ] サイドバーは幅を固定240、mainは幅を拡大、ヘッダーは高さを固定64、contentは高さを拡大に設定できた
