# 4-1 レイアウトの骨組みを作る

ここからは本番です。1〜3章で練習したプロフィールカードは使いません。タスク管理ツールの「タスク一覧画面」をゼロから作っていきます。

このレッスンで作るのは画面の骨組みだけです。左のサイドバーと、右の上下2段（ヘッダーとコンテンツ）を配置し、リサイズ挙動まで整えます。この後、4-2でデザイントークンを整え、4-3でタスクカードを作ります。

使う操作は1〜3章で練習したものが中心です。手順の途中で迷ったら、フレームは1-2、オートレイアウトは2-2、内包/拡大/固定は2-3に戻って確認してください。

## 完成イメージ

![タスク一覧画面の骨組み。左に幅240のsidebarがあり、TaskFlowのロゴとメニューの仮置き5個が縦に並ぶ。右はmainで、上部にアプリ名入りのheader、その下に薄グレーのcontentがあり、タスク一覧の見出しと白いプレースホルダー3つが縦に並ぶ](/lessons/4-1/task-list-skeleton.png)

構造は3階層です。一番外側を横に2つに分け、右側をさらに上下に分けます。

```
task-list
├─ sidebar
└─ main
   ├─ header
   └─ content
```

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `task-list` | 画面全体 | デスクトップ 1440×1024、横オートレイアウト、間隔 0 |
| `sidebar` | 左ナビ | 幅は固定240・高さは拡大、縦オートレイアウト、パディング 24、間隔 8、背景白 |
| `main` | 右カラム | 幅・高さとも拡大、縦オートレイアウト、間隔 0 |
| `header` | 上部バー | 幅は拡大・高さは固定64、横オートレイアウト、左右パディング 24、背景白 |
| `content` | 中身 | 幅・高さとも拡大、縦オートレイアウト、パディング 32、間隔 24、背景 `#F5F5F5` |

サイドバーの中身は今回はプレースホルダーだけにします。アイコンやユーザーブロックなどの装飾は4-4の仕上げに回して、ここでは骨組みに集中します。

## 演習: 骨組みを組み立てる

### 1. 練習の成果物を片付ける

本番のページを、練習の成果物と分けてきれいにしておきます。

1. ページ一覧で、いま練習の成果物が乗っているページの名前を `practice` にする（名前の変え方は1-2と同じ）
2. もう1枚のページを `task-app` にする（1-2でページを追加していない場合は「+」で追加してから名前を付ける）
3. `task-app` ページに切り替える。練習の成果物には触れず、ここから空のキャンバスで本番を組み立てる
4. 何も選択していない状態で右サイドバーの「スタイル」セクションを開き、3-1で登録したスタイルを右クリック →「削除」で全部消す

### 2. 画面フレームを作る

1. `f` でフレームツールを選び、右サイドバーのプリセットから **デスクトップ（1440×1024）** を選ぶ
2. フレームを選択したまま `Shift + A` でオートレイアウトにして、フローを横、間隔 0、パディング 0 にする
3. 名前を `task-list` にする（`Cmd + R`、Windowsは `Ctrl + R`）

### 3. サイドバーを作る

1. `f` でフレームツールを選び、`task-list` の中にドラッグでフレームを描いて、名前を `sidebar` にする
2. `Shift + A` でオートレイアウトを付ける
   - フロー縦、間隔 8、パディング 24
   - 背景は白
3. 幅を**固定240**、高さを**拡大**にする
4. `sidebar` の中に `t` でアプリのロゴになるテキスト `TaskFlow`（18px、SemiBold程度）を作り、名前を `app-brand` にする
5. `sidebar` の中に `r` で高さ32の四角形を作り、名前を `nav-item` にする
   - 角丸 8、薄グレー `#D9D9E0` 塗り
   - 幅を**拡大**にする
   - 「受信箱」「今日」などのメニュー項目になる仮置きで、テキスト入りにするのは4-4でやる
6. `nav-item` を選択して `Cmd + D` で5個にする（複製は名前を引き継ぐので、5個とも `nav-item` になる）

### 4. mainを作る

サイドバーの右側です。ヘッダーとコンテンツをこの中に縦に積みます。

1. `f` で `task-list` の中、`sidebar` の右にフレームを描いて、名前を `main` にする
2. `Shift + A` でオートレイアウトを付ける
   - フロー縦、間隔 0、パディング 0
3. 幅・高さとも**拡大**にする
   - サイドバーの幅が240で止まっているので、残りの1200を `main` が埋める

### 5. ヘッダーを作る

ヘッダーの中身は「左にアプリ名、右にログイン中ユーザーのアイコン」の2つです。

1. `f` で `main` の中にフレームを描いて、名前を `header` にする
2. `Shift + A` でオートレイアウトを付ける
   - フロー横、左右パディング 24
   - 配置は上下中央
   - 背景は白
3. 幅を**拡大**、高さを**固定64**にする
4. `header` の中に `t` でアプリ名のテキスト `TaskFlow`（18px、SemiBold程度）を作り、名前を `app-title` にする
5. `header` の中に `o` でユーザーアイコン仮置きの正円 32×32（薄グレー `#D9D9E0`）を作り、名前を `user-icon` にする
6. `header` の間隔を**自動**にする。間隔の入力欄のドロップダウンから「自動」を選ぶ
   - アプリ名とアイコンが左右の両端に振り分けられる。CSSの `justify-content: space-between` に当たる設定

### 6. コンテンツエリアを作る

タスク一覧が並ぶ場所です。いまは見出しだけ入れます。

1. `f` で `main` の中、`header` の下にフレームを描いて、名前を `content` にする
2. `Shift + A` でオートレイアウトを付ける
   - フロー縦、間隔 24、パディング 32
   - 背景は `#F5F5F5`
3. 幅・高さとも**拡大**にする
   - ヘッダーの高さが64で止まっているので、残りの高さ全部を `content` が取る
4. `content` の中に `t` で見出しのテキスト `タスク一覧`（24px、Bold）を作り、名前を `page-title` にする

### 7. プレースホルダーで骨組みを確かめる

タスクカードは4-3で作るので、いまは仮の四角形で骨組みの動きだけ確認します。

1. `content` の中に `r` で高さ72・角丸8・白の四角形を作り、幅を**拡大**にして、名前を `placeholder` にする
2. `Cmd + D`（Windowsは `Ctrl + D`）で3個にする

四角形が間隔24で縦に並び、幅は右カラムの幅いっぱいにそろうはずです。

最後に `task-list` 全体の幅と高さをドラッグで変えて、次の2つを確認してください。

- 幅を変えると、サイドバーは240のままmainだけが伸び縮みする
- 高さを変えると、ヘッダーは64のままcontentだけが伸び縮みする

確認できたらサイズを1440×1024に戻して、骨組みは完成です。

## ゴール確認

- [ ] 練習の成果物を `practice` ページに分け、3-1のスタイルを削除して `task-app` ページを用意できた
- [ ] `task-list` が横オートレイアウトで `sidebar` と `main` に分かれ、mainの中にheaderとcontentが縦に並んだ
- [ ] サイドバーは幅を固定240、mainは幅を拡大、ヘッダーは高さを固定64、contentは高さを拡大に設定できた
- [ ] 画面の幅を変えるとmainだけ、高さを変えるとcontentだけが伸縮することを確認できた
