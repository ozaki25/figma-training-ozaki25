# 4-1 レイアウトの骨組みを作る

ここからは本番です。1〜3章で練習したプロフィールカードは使いません。タスク管理ツールの「タスク一覧画面」をゼロから作っていきます。

このレッスンで作るのは画面の骨組みだけです。左のサイドバーと、右の上下2段（ヘッダーとコンテンツ）を配置し、リサイズ挙動まで整えます。タスクカードの中身は4-2で作ります。

使う操作は1〜3章で練習したものが中心です。手順の途中で迷ったら、フレームは1-2、オートレイアウトは2-2、内包/拡大/固定は2-3に戻って確認してください。

## 完成イメージ

![タスク一覧画面の骨組みの見取り図。左に幅240のsidebarフレーム、右にmainフレーム。mainの上部にheader、その下に薄グレーのcontentエリアがあり、見出しとプレースホルダーの四角形3つが縦に並ぶ](/lessons/4-1/task-list-skeleton.png)

構造は3階層です。一番外側を横に2つに分け、右側をさらに上下に分けます。

```
task-list
├─ sidebar
└─ main
   ├─ header
   └─ content
```

| レイヤー | 役割 | 仕様 |
| --- | --- | --- |
| `task-list` | 画面全体 | Desktop 1440×1024、横オートレイアウト、間隔 0 |
| `sidebar` | 左ナビ | 幅は固定240・高さは拡大、縦オートレイアウト、パディング 24、間隔 8、背景白 |
| `main` | 右カラム | 幅・高さとも拡大、縦オートレイアウト、間隔 0 |
| `header` | 上部バー | 幅は拡大・高さは固定64、横オートレイアウト、左右パディング 24、背景白 |
| `content` | 中身 | 幅・高さとも拡大、縦オートレイアウト、パディング 32、間隔 24、背景 `#F5F5F5` |

サイドバーの幅は固定240、右カラムのmainは幅を拡大にします。CSSでいえば `display: flex` の中で片方だけ幅固定、もう片方が `flex: 1` で残りを埋める構図と同じです。mainの中は縦に、ヘッダーは高さを固定64、コンテンツは拡大で残りの高さを取ります。

サイドバーの中身は今回はプレースホルダーだけにします。アイコンやユーザーブロックなどの装飾は4-3の仕上げに回して、ここでは骨組みに集中します。

## 作る順序

外側から内側へ作ります。先に入れ物を決めてから中身を足すと、置いた要素が自動で正しい位置に収まります。

1. 画面フレーム `task-list` を作り、横のオートレイアウトにする
2. サイドバーを左に入れる
3. mainを右に入れ、縦オートレイアウトにする
4. mainの中にheaderとcontentを積む
5. contentに見出しとプレースホルダーを置いて、骨組みが機能するか確かめる

レイヤー名は後でまとめて直すのではなく、作ったその場で3-3の規約どおりに付けます。部品はkebab-case、コンポーネントはPascalCaseです（このレッスンではコンポーネントはまだ出てきません）。

## 演習: 骨組みを組み立てる

### 1. 画面フレームを作る

1. `f` でフレームツールを選び、右サイドバーのプリセットから **Desktop（1440×1024）** を選ぶ
2. フレームを選択したまま `Shift + A` でオートレイアウトを付け、フローを**横**、間隔・パディングをすべて 0 にする
3. 名前を `task-list` にする（`Cmd + R`、Windowsは `Ctrl + R`）

### 2. サイドバーを作る

1. `f` を押して、キャンバスの空いた場所をドラッグし、適当な大きさのフレームを描く（大きさは後でオートレイアウトが決めるので適当でよい）
2. そのフレームを選択したまま `Shift + A` でオートレイアウトにする。何も選択していない状態で `Shift + A` を押しても何も起きないので、必ず先にフレームを描いてから押す。この「`f` で描いて `Shift + A`」の2手を、以降は「空のオートレイアウトフレームを作る」と書きます
3. できたフレームを `task-list` の中へドラッグして入れる
4. 仕様どおりに設定する: 幅は**固定240**・高さは**拡大**、フロー縦、間隔 8、パディング 24、背景白
5. 名前を `sidebar` にする
6. 中にテキスト `TaskFlow`（18px、SemiBold程度）を置き、その下に `r` で高さ32の四角形を5個並べる（幅は**拡大**、角丸8、薄グレー塗り）
7. テキストの名前を `app-brand`、四角形の名前を `nav-item` にする

`nav-item` を5個並べると、サイドバーがナビゲーションの雰囲気になります。中身の装飾は4-3で仕上げるので、いまはこの状態で十分です。

### 3. mainを作る

1. 同じように空の縦オートレイアウトフレームを作り、`task-list` の中、`sidebar` の右へ入れる
2. 仕様どおりに設定する: 幅・高さとも**拡大**、フロー縦、間隔 0、パディング 0
3. 名前を `main` にする

サイドバーの幅が固定240で止まっているので、`main` の幅を拡大にすると残りの1200を埋めます。

### 4. mainの中にheaderとcontentを積む

1. キャンバスで、テキスト `My Tasks`（18px、SemiBold程度）と正円 32×32（薄グレー）を作り、2つを選択して `Shift + A` で横オートレイアウトにする
2. `main` の中へ入れて、仕様どおりに設定する: 幅は**拡大**・高さは**固定64**、左右パディング 24、配置は上下中央、背景白
3. 間隔は数値ではなく**自動**にする。「オートレイアウト」セクションの間隔の入力欄のドロップダウンから自動（英語表示ではAuto）を選ぶ。CSSの `justify-content: space-between` に当たる設定で、アプリ名とアイコンが左右の両端に振り分けられる
4. 名前を付ける: フレームは `header`、テキストは `app-title`、正円は `user-icon`
5. 続けてキャンバスにテキスト `今日のタスク`（24px、Bold）を作り、`Shift + A` でオートレイアウトにしてから `main` の中、`header` の下へ入れる
6. 仕様どおりに設定する: 幅・高さとも**拡大**、フロー縦、間隔 24、パディング 32、背景 `#F5F5F5`
7. 名前を付ける: フレームは `content`、テキストは `page-title`

ヘッダーは固定64で高さを固定、contentは拡大で残りの高さ全部を取ります。

### 5. プレースホルダーで骨組みを確かめる

タスクカードは4-2で作るので、いまは仮の四角形で骨組みの動きだけ確認します。

1. `content` の中に `r` で四角形を作る: 高さ 72、角丸 8、白
2. 幅を**拡大**にして、名前を `placeholder` にする
3. `Cmd + D`（Windowsは `Ctrl + D`）で2〜3個に複製する

四角形が間隔24で縦に並び、幅は右カラムの幅いっぱいにそろうはずです。最後に `task-list` 全体の高さをドラッグで変えてみてください。ヘッダーは64のまま、サイドバーは幅240のまま、contentだけが伸び縮みすれば骨組みは完成です。

## ゴール確認

- [ ] `task-list` が横オートレイアウトで `sidebar` と `main` に分かれ、mainの中にheaderとcontentが縦に並んだ
- [ ] サイドバーは幅を固定240、mainは幅を拡大、ヘッダーは高さを固定64、contentは高さを拡大に設定できた
- [ ] 画面の高さを変えるとcontentだけが伸縮することを確認できた
