# 追加課題3 エージェントに共通コンポーネントを整備させる

2日間で作ったファイルには、2画面に複製されたままの `sidebar` と `header`、コンポーネントになっていないチップ4個が残っています。これをFigmaのエージェントと相談しながら共通コンポーネントにします。

**自分ではマウスで整備しません。**やるのはバリアント設計を決めて伝えることと、できあがりを確かめることです。

## 使う前に

キャンバスでエージェントのプロンプト欄を開きます。見つからないときは、下書きのファイルに複製すると使えることがあります。それでも出てこなければ、プランやシートの都合で使えないので、末尾のClaude Codeでのやり方に進んでください。

プロンプト欄で `@` を打つと、このファイルのコンポーネント・バリアブル・スタイルの一覧が出ます。名前で直接指せるので、指示に書くときに使えます。

## 1. バックアップを取る

変更はチャットのUndoか `Cmd + Z`（Windowsは `Ctrl + Z`）で戻せますが、何度も往復すると戻しきれなくなります。先にページを複製しておきます。

1. ページ一覧で `task-app` を右クリックして「ページを複製」を選ぶ
2. 複製したページの名前を `task-app-backup` にする
3. 以降は元の `task-app` ページで作業する

## 2. バリアント設計を相談する

作らせる前に設計を詰めます。

```text
このページの task-list と task-form で、共通コンポーネントにできていない
ところを挙げてください。
sidebar は2画面でアクティブな項目とバッジの有無が違います。
どうバリアントを設計するか案を出してください。まだ作らないでください。
```

出てきた案を読んで、自分の判断を決めます。

- `sidebar` をまるごと1つのコンポーネントにするのか、枠は各画面に置いたままにして中の `NavItem` だけを使い回すのか
- アクティブの違いをバリアントで持たせるのか、インスタンス側の上書きで済ませるのか

`header` は画面によって変わるところがないので迷いません。同じ「2画面に複製されているもの」でも、共通化しやすいものとそうでないものが混ざっています。

## 3. 判断を伝えて作らせる

決めたことを条件として渡します。次は「`sidebar` も共通化して、アクティブな項目をバリアントで切り替える」と決めた場合の例です。

```text
次の方針で共通コンポーネントに整備してください。

- header は1つのコンポーネントにして、両画面をインスタンスに置き換える
- sidebar も1つのコンポーネントにして、アクティブな項目を active プロパティで
  切り替えられるようにする。バッジの表示も同じプロパティで切り替える
- チップ4個を Chip コンポーネントにして、active=true/false のバリアントを持たせる
- 色・余白・角丸は @tokens のトークンだけを使う
- レイヤー名は kebab-case、コンポーネント名は PascalCase
```

## 4. バリアントで2画面を再現する

作らせたコンポーネントで、元の2画面が再現できるかを確かめます。

1. `task-list` の `sidebar` のインスタンスを選び、アクティブを `今日` にする。バッジが出る
2. `task-form` の `sidebar` のインスタンスを選び、アクティブを `受信箱` にする。バッジが消える
3. `header` の原本でアプリ名を書き換えて、両画面が一緒に変わるのを確認する。確認したら戻す

3で両方が変わらなければ、インスタンスになっていません。1と2ができなければ、バリアントの設計が足りていません。どちらも、何が足りないかを伝えて作り直させます。収まらなくなったら `task-app-backup` から戻してやり直せます。

## 詰まったときに戻る場所

- バリアントの作り方と切り替え方 → 3-2
- どこが複製されているか思い出せない → 6-1（`sidebar` と `header` のコピー）、4-4（チップ）
- レイヤー名の規約 → 3-3
- トークンの一覧 → 4-2

## Claude Codeでやる場合

エージェントが使えないときは、5-1で入れたFigmaプラグインで同じことができます。Claude Codeに「このFigmaファイルを〜してください」と頼むと、キャンバスに書き込まれます。URLは4章から使っているファイルのものを渡します。

`@` は使えないので、トークン名とコンポーネント名は指示文に書き出します。チャットのUndoもないので、戻すときはFigma側で `Cmd + Z` を押します。
