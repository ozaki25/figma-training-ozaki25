# 追加課題3 エージェントに共通コンポーネントを整備させる

2日間で作ったファイルには、2画面に複製されたままのものや、コンポーネントになっていない部品が残っています。これをエージェントに共通コンポーネントへ整備させます。

**整備そのものはエージェントがやります。**やるのは、できあがったコンポーネントを1つずつ見て、足りないところを足させることです。

## 使う前に

キャンバスでエージェントのプロンプト欄を開きます。見つからないときは、下書きのファイルに複製すると使えることがあります。それでも出てこなければ、プランやシートの都合で使えないので、末尾のClaude Codeでのやり方に進んでください。

プロンプト欄で `@` を打つと、このファイルのコンポーネント・バリアブル・スタイルの一覧が出ます。名前で直接指せます。

## 1. バックアップを取る

変更はチャットのUndoか `Cmd + Z`（Windowsは `Ctrl + Z`）で戻せますが、何度も往復すると戻しきれなくなります。先にページを複製しておきます。

1. ページ一覧で `task-app` を右クリックして「ページを複製」を選ぶ
2. 複製したページの名前を `task-app-backup` にする
3. 以降は元の `task-app` ページで作業する

## 2. 整備させる

次をそのまま送ります。何を共通化するかはエージェントに決めさせます。

```text
このページの task-list と task-form を見て、共通コンポーネントにできるところを
整備してください。

- 2画面に複製されている部品は1つのコンポーネントにして、両画面をインスタンスに
  置き換える
- 画面ごとに違うところは、インスタンス側で切り替えられるようにプロパティを作る
- プロパティ名と値の付け方は、既存の priority=high/mid/low や active=true/false に
  そろえる。プロパティ1 のような自動名は残さない
- 性質の違う切り替えは別のプロパティに分けて、組み合わせが掛け算で増えないようにする
- テキストや数字の差はプロパティにしない。インスタンス側の書き換えで表す
- 色・余白・角丸は @tokens のトークンだけを使う
- コンポーネント名は PascalCase、レイヤー名は kebab-case
- 画面の見た目は変えない
```

## 3. コンポーネントを1つずつチェックする

できたコンポーネントの原本を選んで、右サイドバーのプロパティ一覧を見ます。見るのは1つです。**元の2画面で使っていた見た目が、全部作れるか。**

たとえば `sidebar` が1つのコンポーネントになったなら、アクティブな項目を5つの中から選べて、バッジの表示も切り替えられる必要があります。どちらかが固定されていたら、片方の画面が再現できません。

足りなければ、そのコンポーネントを指して足させます。

```text
@Sidebar に、アクティブな項目を切り替えるプロパティを足してください。
値は受信箱・今日・今週・完了・アーカイブの5つです。
```

全部のコンポーネントについて、これを1つずつやります。プロパティ名が自動名のまま残っていたら、それも直させます。

## 4. 画面に正しく適用されているか見る

コンポーネントが揃ったら、2つの画面を開いて元の見た目と比べます。

- インスタンスに置き換わっているか（レイヤーパネルのアイコンがひし形）
- プロパティの選び方が合っているか。`task-list` はアクティブが `今日` でバッジあり、`task-form` は `受信箱` でバッジなし
- 余白や幅が変わっていないか

ずれているところは、インスタンスを選んでプロパティを選び直せば直ります。数が多ければエージェントに頼んでも構いません。

最後に `header` の原本でアプリ名を書き換えて、両画面が一緒に変わるのを確認します。確認したら戻します。ここが変わらなければ、まだインスタンスになっていません。

収まらなくなったら `task-app-backup` から戻してやり直せます。

## 詰まったときに戻る場所

- バリアントの作り方と切り替え方 → 3-2
- どこが複製されているか → 6-1（`sidebar` と `header` をコピーした箇所）、4-4（チップをコンポーネント化しなかった箇所）
- レイヤー名の規約 → 3-3
- トークンの一覧 → 4-2

## Claude Codeでやる場合

エージェントが使えないときは、5-1で入れたFigmaプラグインで同じことができます。Claude Codeに上のプロンプトを送ると、キャンバスに書き込まれます。URLは4章から使っているファイルのものを渡します。

`@` は使えないので、コンポーネント名は指示文に書き出します。チャットのUndoもないので、戻すときはFigma側で `Cmd + Z` を押します。

## ゴール確認

- [ ] 共通コンポーネントを作らせて、2画面がインスタンスに置き換わった
- [ ] コンポーネントを1つずつ見て、足りないバリアントを追加させられた
- [ ] 2画面が元の見た目のまま再現されていることを確認できた
